検索順位が下がったのはアップデートか｜公式記録で確認

Web制作検索順位が下がったのはアップデートかNORTIQ LABS · COLUMN

順位が下がったとき、最初に確認する3つのこと

まずGoogleの更新履歴で該当期間にアップデートがあったかを確認し、次にSearch Consoleで下落した日と対象を特定し、最後に自社側の変更履歴と突き合わせます。この3つを終えるまでは、本文の書き直しやページの削除といった手は動かさないでください。原因が自社の外にある場合、手を動かすほど状況が読めなくなります。

確認は次の順番で進めます。

  1. Googleの更新履歴を見る (目安5分): 該当期間にランキングの更新が行われていたか、行われていたならその期間を確認します。手順は後述します。
  2. Search Consoleで下落した日と対象を特定する (目安30分): どの日から、どのページの、どのクエリが下がったのかを押さえます。
  3. 自社側の変更履歴と突き合わせる (目安30分): サイトの更新、サーバやCMSの変更、公開を止めたページの有無を時系列で並べます。

あなたのホームページは、いま何点ですか？

URLを入れるだけで、SEO・セキュリティ設定・表示速度・AI対応をその場で採点します。登録は不要、無料です。

確認の順番を間違えると直す場所を間違える

順番が大事なのは、原因の切り分けが「自社の外か内か」の二択から始まるためです。Google側の更新と下落した日が重なっていれば、まず評価の基準が変わった可能性を疑います。重なっていなければ、自社側の変更か、技術的な不具合を疑う順番になります。この最初の分岐を飛ばして本文の改善から入ると、評価の基準が変わっただけの場合でも、関係のないページを触ってしまいます。

自社側の変更が無いことを先に確かめる

「サイトを触っていない」という前提は、思っているより崩れやすい点に注意してください。制作会社による軽微な修正、CMSやプラグインの自動更新、サーバの設定変更、他部署によるページの公開や削除は、Web担当者の把握の外で起きていることがあります。下落に気づいた時点で、直近1か月の変更を関係者に確認しておくと、後の切り分けが早くなります。

つまずきやすい点: 順位の下落と表示回数の下落は原因が違う

Search Consoleで最初に目に入るのは表示回数やクリック数の減少ですが、これは掲載順位の下落とは別の事象として扱う必要があります。順位が変わっていないのに表示回数だけが減っている場合、検索する人の数が減った、季節要因で検索語そのものが使われなくなった、検索結果の見え方が変わったといった説明が付きます。逆に、順位は下がっているのに表示回数が横ばいという場合もあります。どちらが起きているのかを先に見分けておくと、確認すべき対象が絞れます。

Googleの更新履歴でアップデートの有無と期間を確認する

コアアップデートはGoogleのランキング更新の一覧に掲載され、ロールアウトが終わったかはSearch Status Dashboardで開始日と終了日を確認します。これはGoogle検索セントラルの「Google 検索のコア アップデートとウェブサイト」に書かれている案内で、推測ではなく公式に示されている確認先です。

Search Status Dashboardの開き方と見る場所

手順は次の3つです。

  1. Search Status Dashboard (status.search.google.com) を開く (目安1分): Googleが検索の障害とランキング更新を記録している公式のページです。
  2. ランキング更新の履歴を開く (目安2分): 更新ごとに名称、開始日、所要期間が並んでいます。つまずきやすい点として、ここに記載されているのは開始日と所要期間で、終了日時そのものは書かれていません。終わった時刻を知りたい場合は、開始日に所要期間を足して見当を付けることになります。
  3. 自社の順位が動いた日と照らす (目安2分): 開始日と所要期間から求めた期間の内側に下落した日が入るかを見ます。期間の外であれば、アップデート以外の原因を先に疑う順番になります。

たとえば直近では、September 2026 spam update が2026年9月24日の開始で所要期間13日16時間と記録されています (出典: Google Search Status Dashboard ランキング更新の履歴)。9月下旬から10月上旬にかけて順位が動いていれば、この期間と重なっていた可能性を確認する価値があります。2026年に記録された他の更新とその期間は次のセクションでまとめます。

旧URLのランキング更新一覧はダッシュボードの履歴へ転送される

社内の手順書や過去の記事に developers.google.com/search/updates/ranking というURLが残っている場合があります。このランキング更新の一覧は、現在はSearch Status Dashboardの履歴ページへ転送されます。リンクが切れているわけではないので、ブックマークはそのままでも開けますが、転送先の画面構成は一覧とは異なります。参照先を書き換えておくと、次に見るときに迷いません。

所要時間の目安: 5分

この確認自体は5分程度で終わります。先に済ませる理由は、結果によって次に見る場所が変わるためです。期間が重なっていればSearch Consoleでの比較へ進み、重なっていなければ自社側の変更履歴と技術的な不具合の確認へ進みます。順位が下がったという報告を受けた時点で、まずこの5分を使ってください。

更新にかかる期間は数時間から3週間まで幅がある

2026年のランキング更新は、短いものが19時間30分、長いものが21日17時間と幅が大きいため、下落した日が期間の内側に入るかを開始日と所要期間で判断します。「アップデートは数日で終わるもの」という前提で見ると、長い更新の途中で判断を下してしまいます。

2026年に記録されたランキング更新の開始日と所要期間

Google Search Status Dashboard のランキング更新の履歴に記録されている2026年の更新は、次のとおりです (出典: Google Search Status Dashboard ランキング更新の履歴)。

更新の名称 開始日 所要期間
September 2026 spam update 2026年9月24日 13日16時間
August 2026 spam update 2026年8月18日 2日16時間
June 2026 spam update 2026年6月24日 2日1時間
May 2026 core update 2026年5月21日 11日21時間
March 2026 core update 2026年3月27日 12日4時間
March 2026 spam update 2026年3月24日 19時間30分
February 2026 Discover update 2026年2月5日 21日17時間

同じ年の更新でも、March 2026 spam update の19時間30分から February 2026 Discover update の21日17時間まで開いています。コアアップデートに限って見ても、May 2026 core update が11日21時間、March 2026 core update が12日4時間で、おおむね2週間弱という読み方になります。

ダッシュボードに書かれているのは開始日と所要期間で、終了日時は明示されない

照合するときは、終了日を自分で求める必要があります。たとえば September 2026 spam update は2026年9月24日の開始で13日16時間ですから、10月上旬まで続いていたという見当が付きます。ここで注意したいのは、開始の時刻がダッシュボードの一覧には出ていない点です。日付の境目に下落している場合、重なっているかどうかを1日単位で断定はできません。重なっている可能性があるという扱いにして、次のSearch Consoleでの比較に進むのが実務的です。

つまずきやすい点: ロールアウト中の順位はまだ動く

所要期間の幅が大きいことが実務に効くのは、「いつ判断してよいか」が変わるためです。ロールアウトが進んでいる間は順位が動き続けるため、その途中で見た数字は確定した結果ではありません。2日で終わる更新なら数日待てば済みますが、3週間近くかかる更新では、下落に気づいてから結論を出せるまでに1か月近くかかることになります。

この間に慌てて本文を書き換えると、順位の変化がアップデートによるものか自分の変更によるものか分からなくなります。期間が長い更新だと分かった時点で、社内には「結論が出るのはいつ頃になる」と先に伝えておくと、途中で対応を求められずに済みます。実際にいつの期間を比べるかは、次のセクションで扱います。

Search Consoleでどの期間を比べるか

アップデートの完了後に少なくとも1週間待ち、その1週間とロールアウト開始前の1週間を比較します。これはGoogle検索セントラルの「Google 検索のコア アップデートとウェブサイト」が示している手順で、完了直後の数日ではなく、落ち着いた後の1週間を見るという考え方です。

比較の手順と、ウェブ検索・画像・動画・ニュースを分けて見る理由

  1. ロールアウトの完了日を確定させる (目安5分): 前のセクションの表から、開始日に所要期間を足して完了の時期を求めます。
  2. 完了から1週間待つ (目安7日): 同ページは完了後に少なくとも1週間はそのまま待つよう示しています。
  3. その1週間と、開始前の1週間を比較する (目安30分): 検索パフォーマンスレポートの日付フィルタで2つの期間を指定します。つまずきやすい点として、一度に保持できる期間比較は1件のみで、新しい比較を追加すると既存の比較が置き換わると公式ヘルプに記載されています (出典: パフォーマンス レポート 高度なフィルタリングと比較 Search Console ヘルプ)。比べた結果はその場で書き出してください。
  4. 検索の種類ごとに分けて見る (目安30分): 同ページは、ウェブ検索、Google画像検索、動画、ニュースをそれぞれ分けて分析し、どこで下落が起きたかを特定するよう案内しています。画像や動画だけが下がっている場合、本文の見直しは的を外します。

データの保持期間と比較機能の制約を先に知っておく

比較できる範囲には限りがあります。公式ヘルプによると、Search Consoleで保持されるデータは過去16か月間で、Googleアナリティクスに接続した場合のレポートも最大16か月分の表示です (出典: Search Console を Google アナリティクスに接続する アナリティクス ヘルプ)。16か月より前とは比較できないため、1年以上前との比較を考えているなら、先にデータを書き出しておく必要があります。

また、検索パフォーマンスレポートの既定の表示期間は過去3か月です (出典: 検索パフォーマンス レポート Search Console ヘルプ)。開いたままの画面で見ていると、直近3か月の中だけで判断してしまいます。日付フィルタで期間を指定し直してください。

直近のデータが暫定値である点も、比較期間の決め方に影響します。最新のデータはグラフ上に点線で表示され、その後数時間で変動することがあり、暫定データの日付は通常は当日、場合によっては前日です。完了直後の数日を比較に含めると、後から数字が動きます。

つまずきやすい点: 平均掲載順位の数え方を誤解すると下落幅を読み違える

平均掲載順位は、表示のたびにそのプロパティまたはページのリンクに付いた最上位の順位を記録し、表示されたすべてのクエリにわたって平均した値です。公式ヘルプの例では、クエリ1が2位・4位・6位で2位、クエリ2が3位・5位・9位で3位と数えられ、2つのクエリの平均は2.5位になると説明されています (出典: 表示回数、掲載順位、クリック数とは Search Console ヘルプ)。

ここで問題になるのは、期間によって順位の母集団となるクエリの顔ぶれが変わる点です。新しいクエリで表示されるようになった結果として平均が下がることもあり、平均掲載順位の増減だけで順位が上がったか下がったかを決めることはできません。個別のクエリとページの単位まで降りて比べてください。

集計の単位にも違いがあります。グラフの表示回数はプロパティごとに集計され、同じクエリで同一サイトの2件が検索結果に出た場合でも表示回数は1回と数えられます。表のうちクエリ、国、デバイス、日付はプロパティごと、ページと検索での見え方はページごとの集計です。ページ単位で前後を比べるときは、この違いを踏まえて読む必要があります。

下落幅で対応を切り分ける

小さな下落であれば大きな対応は不要で、大きな下落が続いている場合にだけサイト全体の見直しに進みます。Google検索セントラルの「Google 検索のコア アップデートとウェブサイト」は、この切り分けを掲載順位の変化の例で示しています。

Googleが例示する小さな下落と大きな下落の境目

同ページが挙げている例は次のとおりです (出典: Google 検索のコア アップデートとウェブサイト)。

下落の大きさ 公式が挙げる例 示されている対応
小さな下落 掲載順位が2位から4位 大きな対応は不要。成果が出ているコンテンツはそのままにしておく
大きな下落 掲載順位が4位から29位 より踏み込んだ評価が必要

2位から4位という変化は、検索結果の同じ画面の中での移動です。これに対して4位から29位は、1ページ目から3ページ目付近への移動にあたり、流入の有無が変わります。同じ「順位が下がった」という報告でも、対応の重さが違うという整理です。

継続して大きく下落している場合について、同ページはサイト全体を有用で信頼性の高いコンテンツの自己評価の観点で確認すること、影響の大きいページを見直すこと、第三者の意見を得ることを挙げています。自社だけで判断すると、どのページが読者の役に立っていないかの評価が甘くなるためです。

成果が出ているページは触らない

小さな下落のときに成果が出ているコンテンツをそのままにしておくという案内は、実務では守りにくい点です。社内で順位の下落が共有されると、下がったページから順に手を入れたくなります。ただ、2位から4位の移動のために本文を書き換えると、次の更新でさらに動いたときに、原因が自分の変更なのか評価の基準なのか分からなくなります。

対応を決めるときは、下落幅とあわせて、そのページが実際に問い合わせや資料請求につながっているかを見てください。流入が残っていて成果も出ているページは、順位の数字だけを理由に触らない判断ができます。

所要時間の目安: 対象ページの洗い出しに半日

手順は次の3つです。

  1. 下落幅でページを3つに分ける (目安2時間): 小さな下落、大きな下落、変化なしに分類します。前のセクションの比較結果をそのまま使います。
  2. 大きな下落のページだけを対象にする (目安2時間): 対象を絞ってから中身を読みます。全ページを一度に見ようとすると終わりません。
  3. 成果の有無を重ねる (目安1時間): 問い合わせにつながっていたページが大きく下落している場合を最優先にします。

つまずきやすい点は、ページ数が多いサイトで分類を手作業で行うと半日では終わらないことです。先に表示回数の多い上位のページに限って分類し、残りは後日に回すと進みます。なお、下落がアルゴリズムの変動ではなくポリシー違反への対応による場合は、この切り分け自体が当てはまりません。その見分け方は次のセクションで扱います。

アルゴリズムの変動か、ポリシー違反による手動の対策かを分ける

Search Consoleの手動による対策のレポートに記載があるかどうかで、アルゴリズムの変動とポリシー違反への対応は切り分けられます。ここまで見てきた更新履歴との照合は、アルゴリズム側の話です。ポリシー違反として個別に対応が行われている場合は、更新の期間と重なっていなくても順位が落ちます。

手動による対策のレポートを確認する

手順は次の2つです。

  1. Search Consoleの手動による対策のレポートを開く (目安3分): 記載があれば、そこに対象と理由が書かれています。この場合、更新履歴との照合は意味を持ちません。記載された内容を直し、再審査を申請する流れになります。
  2. 記載が無ければアルゴリズム側として扱う (目安1分): 前のセクションまでの手順に戻ります。つまずきやすい点として、記載が無いことは問題が無いことの証明にはなりません。アルゴリズムによる評価の変化は、このレポートには出ません。

第三者コンテンツを載せているサイトで注意する点

自社サイトの一部を外部のパートナーや広告主に貸している場合は、サイト評判の不正使用ポリシーの対象になっていないかを確認してください。このポリシーは2024年3月のコアアップデートで導入され、サイトのテーマと無関係な第三者作成のコンテンツを、既存サイトの評判を利用してランキング操作の目的で掲載する行為を対象としています (出典: Googleの新ルール「サイト評判の不正使用」とは何か、NTT東日本)。

中小企業のサイトでも、サブディレクトリに外部の記事やキャンペーン用のページを置いている例があります。順位が下がったページがそうした区画と同じディレクトリにある場合は、更新履歴との照合より先にこちらを疑ってください。

2026年のポリシー改定で適用の扱いが地域によって分かれた点

Googleは公式ブログ「Update to the Site Reputation Policy」で、2026年8月30日からこのポリシーの運用を検索地域によって分けると発表しました (出典: Update to the Site Reputation Policy、Google Search Central Blog)。EEA域外からの検索については従来どおり手動による対策が該当区画の検索順位に直接影響し、EEA域内からの検索については、欧州委員会からの要請を受けて直接的な順位への影響を適用せず、該当区画をサイトの他の部分から切り離して独自に評価する仕組みに切り替わります。

日本から検索した場合はEEA域外の扱いになるため、国内向けのサイトでは従来どおりの影響を前提に考えることになります。多言語で欧州向けのページも持っている場合は、地域によって見え方が変わる可能性がある点を踏まえてください。

なお同じ時期の2026年8月コアスパムアップデートは、2026年8月18日に展開を開始して8月21日に完了し、所要時間は約64時間、全言語と全地域が対象で、新しいスパムポリシーの追加はありませんでした (出典: Google、2026年8月のスパムアップデートの展開を開始)。この約64時間は、Search Status Dashboardに記録されている2日16時間という所要期間と一致します。8月下旬に順位が動いていた場合、ポリシーの運用変更とスパムアップデートのどちらとも時期が近いため、手動による対策のレポートを先に確認して切り分けてください。

直した後、どれくらい待つか

変更が数日で反映されることもありますが、長期的な品質の確認には数か月かかる場合があり、数か月変化がなければ次のコアアップデートを待つ判断になります。Google検索セントラルの「Google 検索のコア アップデートとウェブサイト」に、この期間の見込みが明記されています。

すぐ効く変更と、時間がかかる変更の違い

同ページは、変更が数日で反映されることもある一方で、サイトの長期的な品質をGoogleのシステムが確認するには数か月かかる場合があるとしています (出典: Google 検索のコア アップデートとウェブサイト)。数か月経っても変化がない場合は次のコアアップデートを待つことが案内されており、告知されない小規模なコアアップデートも行われていて、それによって順位が上がることもあると記載されています。

社内への報告では、この2つの時間軸を分けて伝えてください。

  1. 直した直後に見る (目安数日): インデックスの登録状況や表示の崩れといった、技術的に直したことが反映されたかを確認します。
  2. 評価の変化を見る (目安数か月): 順位への反映はここで判断します。つまずきやすい点として、1か月で結論を出そうとすると、効果が無かったと誤って判断することになります。

避けるべき場当たり的な対応

同ページは、場当たり的な対応を避け、意味のある形でコンテンツを改善すること、コンテンツの削除は最後の手段として扱うことを示しています。順位が下がったページをまとめて削除したり、キーワードを増やして本文を膨らませたりする対応は、評価の基準が変わったことへの答えになっていません。

数か月単位で待つ前提に立つと、やるべきことは一度に大きく変えないことです。変更の内容と日付を記録し、次の更新が来たときにどの変更が効いたのかを読めるようにしておいてください。記録が無いと、順位が戻ったときにも理由が分からず、次に活かせません。

つまずきやすい点: 効果が出る保証はないと公式に明記されている

同ページには、変更によって目に見える効果が出る保証はないことも明記されています。これは手を抜いてよいという話ではなく、社内での期待値の置き方に関わる点です。「直せば戻る」という前提で予算や工数を確保すると、戻らなかったときに次の打ち手が立てられなくなります。

現実的な進め方は、順位の回復を目的にするのではなく、読者の役に立つ状態に近づける作業として進めることです。そのうえで、回復するかどうかは次のコアアップデートを待って判断します。なお、リニューアルを行った直後に順位が下がった場合は、URLの移行やリダイレクトの不備という別の原因があり得ます。その切り分けは、サイトリニューアル後の順位低下を扱った記事を参照してください。

よくあるご質問

この記事に関して多い質問と回答をまとめます。

Googleのアップデートがあったかどうかは、どこで確認できますか

Search Status Dashboard のランキング更新の履歴で確認します。更新ごとに名称、開始日、所要期間が記録されています。Google検索セントラルの「Google 検索のコア アップデートとウェブサイト」も、ロールアウトが終わったかを確かめるにはこのダッシュボードで開始日と終了日を確認するよう案内しています。かつてのランキング更新の一覧のURLは、現在このダッシュボードの履歴ページへ転送されます。

コアアップデートとスパムアップデートは何が違いますか

ダッシュボードの履歴では、名称に core update と付くものと spam update と付くものが別の更新として記録されています。コアアップデートは検索結果全体の評価の仕組みの更新で、スパムアップデートはスパムポリシーへの対応に関わる更新です。実務上の違いは、確認する場所に出ます。スパムポリシーに触れている心当たりがある場合は、更新履歴の照合より先に、Search Consoleの手動による対策のレポートを見てください。なお、2026年8月コアスパムアップデートでは新しいスパムポリシーの追加はありませんでした (出典: Google、2026年8月のスパムアップデートの展開を開始)。

アップデートのロールアウト中に順位が戻ることはありますか

ロールアウトが進んでいる間は順位が動き続けるため、途中で見た数字は確定した結果ではありません。Google検索セントラルの同ページは、アップデートの完了後に少なくとも1週間はそのまま待ち、その1週間とロールアウト開始前の1週間を比較するよう示しています。2026年の記録では所要期間が19時間30分から21日17時間まで開いていますので、結論を出せる時期は更新ごとに変わります。

順位が下がった後、いつからSearch Consoleで比較すればよいですか

ロールアウトの完了から1週間以上経ってからです。開始日に所要期間を足して完了の時期を求め、そこから1週間待ちます。直近のデータは暫定値で、最新のデータはグラフ上に点線で表示され、その後数時間で変動することがあるため、完了直後の数日を比較に含めないようにしてください。

手動による対策とアルゴリズムの変動は、どう見分けますか

Search Consoleの手動による対策のレポートに記載があるかどうかで見分けます。記載があればポリシー違反への個別の対応で、内容を直して再審査を申請する流れになります。記載が無ければアルゴリズム側として扱い、更新履歴との照合に戻ります。ただし、記載が無いことは問題が無いことの証明にはなりません。アルゴリズムによる評価の変化は、このレポートには表示されません。
