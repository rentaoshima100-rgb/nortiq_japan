デジタル化・AI導入補助金で業務システムは対象？

技術デジタル化・AI導入補助金で業務システムは対象？NORTIQ LABS · COLUMN

デジタル化・AI導入補助金とは？旧IT導入補助金から何が変わった？

デジタル化・AI導入補助金2026とは、旧IT導入補助金が名称を変えた中小企業庁の補助事業です。令和7年度補正予算事業として実施されています。

名称が変わっただけで、制度の骨格は旧IT導入補助金を引き継いでいます。事務局に登録されたITツールの導入費用を補助する仕組みも同じです。御社が検索で見つけた古い記事と条件が食い違う場合は、名称と年度を手がかりに読み替えてください。

名称変更の経緯と実施年度

旧「IT導入補助金」は、中小企業庁の「中小企業デジタル化・AI導入支援事業」のもとで「デジタル化・AI導入補助金2026」という名称になりました。令和7年度補正予算事業として実施されています。出典: 中小企業庁「中小企業デジタル化・AI導入支援事業『デジタル化・AI導入補助金2026』の概要」（令和8年4月）。

年度ごとに締切が複数回設けられる点も従来どおりです。公式サイトでは6次締切分として、申請期間の終了が2026年10月30日17時、交付決定日が2026年12月10日の予定と示されています。出典: デジタル化・AI導入補助金2026 公式サイト 通常枠。2026年10月1日時点の情報です。最新は公式サイトで確認してください。

補助の対象者

補助の対象になるのは、原則として中小企業・小規模事業者等です。そして補助の対象になる「もの」は、事務局に登録されたITツールに限られます。この2つは別の条件なので、分けて確認する必要があります。

自社が中小企業に該当していても、導入しようとしているものが登録されたITツールでなければ対象になりません。業務システムの開発を考えている御社にとっては、こちらの条件のほうが実務上の分かれ目になります。詳しくは次のセクションで整理します。

申請は、御社だけでは完結しません。事務局に登録されたIT導入支援事業者と共同で行う形になっています。制作会社やベンダがその登録を持っているかどうかは、相談の最初に確認しておくとやり直しが減ります。

業務システムの開発費は補助の対象になる？

対象になるのは事務局に登録されたITツールです。開発費という名目ではなく、対象経費の区分に当てはまるかどうかで判断します。

ここが旧IT導入補助金から変わっていない、いちばん誤解されやすい点です。見積書に「開発費」と書かれていても、それ自体で対象かどうかは決まりません。以下は2026年10月1日時点の情報です。最新は公式サイトで確認してください。

対象経費の区分 (必須・オプション・役務)

通常枠の補助対象経費は、次の3区分で決まっています。

区分 含まれるもの
必須 ソフトウェア購入費、クラウド利用料 (最大2年分)
オプション 機能拡張、データ連携ツール、セキュリティ
役務 導入コンサルティング、導入設定・マニュアル作成・導入研修、保守サポート

出典: デジタル化・AI導入補助金2026 公式サイト 通常枠。必須区分にソフトウェアが入っているため、ソフトウェアを含まない申請は成立しません。クラウド利用料は最大2年分までが対象です。

1種類以上の業務プロセスという条件

公式サイトの通常枠の説明では、1種類以上の業務プロセスを保有するソフトウェアを申請することが条件とされています。汎用プロセスのみの申請は認められないと記載されています。

対象となるプロセスは、顧客対応・販売支援や決済・債権債務・資金回収管理等の共通プロセス、または業種特化型プロセスです。出典: 同公式サイト。つまり、御社の業務のどの工程を担うソフトウェアなのかを言えることが前提になります。

対象になりにくいケースの見分け方

発注前に確認すべき点を、優先順に挙げます。

  1. 導入しようとしているものが、事務局に登録されたITツールに該当するか
  2. そのITツールが、対象となる業務プロセスを1つ以上持っているか
  3. 依頼先が、事務局に登録されたIT導入支援事業者か
  4. 見積もりの各項目が、必須・オプション・役務のどこに当たるか

オーダーメイドで個別に開発した業務システムについては、公式サイトで確認できるのは「補助対象は事務局に登録されたITツールに限られる」という条件までです。個別開発を対象外と明記した公式の記述は確認できていません。したがって、断定で判断せず、登録済みのITツールに該当するかをIT導入支援事業者に確認する形になります。

補助率と補助額の上限はいくら？

通常枠は補助率1/2以内です。補助額は1プロセス以上の申請で5万円以上150万円未満、4プロセス以上の申請で150万円以上450万円以下です。

前のセクションで見た業務プロセスの数が、そのまま補助額の区分に効いてきます。以下は2026年10月1日時点の情報です。最新は公式サイトで確認してください。

通常枠の補助率と補助額

項目 内容
補助率 (原則) 1/2以内
補助率 (低賃金雇用従業員が全従業員の30%以上の場合) 2/3以内
補助額 (1プロセス以上) 5万円以上150万円未満
補助額 (4プロセス以上) 150万円以上450万円以下

出典: デジタル化・AI導入補助金2026 公式サイト 通常枠。

読み方で気をつける点が2つあります。1つは、補助率が「以内」と書かれている点です。上限が1/2であって、必ず半額が戻るという意味ではありません。

もう1つは、補助額に下限がある点です。1プロセス以上の区分では5万円以上という下限があり、小さすぎる導入は申請の形になりません。4プロセス以上で150万円以上という区分に移るため、プロセス数と金額の両方が条件を満たす必要があります。

インボイス枠の補助率と上限

インボイス対応を含む導入では、別の枠が用意されています。公式情報を整理した解説では、次のように示されています。

対象金額の部分 補助率
50万円以下の部分 3/4 (小規模事業者は4/5)
50万円超から350万円までの部分 2/3

補助上限は350万円までです。出典: 補助金ポータル「デジタル化・AI導入補助金 (旧IT導入補助金) とは」。通常枠より補助率が高い区分があるため、受発注や請求の電子化を含む案件では、どちらの枠で出すかを先に決めると見積もりの組み方が変わります。

枠の選択は、IT導入支援事業者と相談しながら決める部分です。御社の導入内容がどの枠の要件を満たすかは、ツールの登録内容によっても変わります。申請の順番については、次のセクションで整理します。

申請の流れと締切はどうなっている？

GビズIDプライムとSECURITY ACTIONを先に用意します。そのうえでIT導入支援事業者と共同で申請し、交付決定の通知を受けてから発注します。

順番を間違えると、補助の対象から外れます。以下は2026年10月1日時点の情報です。最新は公式サイトで確認してください。

申請前に準備するもの

  1. GビズIDプライムを取得する。マイナンバーカードを用いたオンライン申請なら最短即日、書類の郵送による申請では2週間程度かかります
  2. SECURITY ACTION (情報セキュリティ対策の自己宣言) を行う
  3. 事務局に登録されたIT導入支援事業者を選び、導入するITツールを決める
  4. 事業計画を作り、IT導入支援事業者と共同で申請する

出典: IPA「SECURITY ACTION 補助金申請での取り扱い」、および申請の流れとGビズIDプライムの所要日数に関する解説。

SECURITY ACTIONは2026年4月1日から申込方法が変わりました。「SECURITY ACTION管理システム」の利用に、GビズIDプライムまたはメンバーのアカウントが必要になっています。出典: IPA「SECURITY ACTION 補助金申請での取り扱い」。つまり、GビズIDの取得が実務上の最初の一歩になります。

郵送で2週間かかる場合、締切の直前に動き出すと間に合いません。ここは御社の社内手続きの速さに関わらず、外部の処理時間が固定でかかる部分です。

締切と事業実施期間

公式サイトでは、6次締切分のスケジュールが次のように示されています。

項目 日時
申請期間の終了 2026年10月30日17時
交付決定日 (予定) 2026年12月10日
事業実施期間の終了 (予定) 2027年5月31日17時

出典: デジタル化・AI導入補助金2026 公式サイト 通常枠。

読み取れるのは、申請から交付決定までに約6週間、そこから事業実施期間の終了までに約5か月半という時間の配分です。システムの導入と検収をこの期間に収める必要があります。

交付決定前に契約すると対象外になる

交付決定の通知を受けた後に発注・契約・支払いを行う流れです。先に契約を済ませた経費は対象になりません。出典: 同公式サイト。

実務では、ここが最も多い取りこぼしです。見積もりと要件の詰めは交付決定の前に進めてよい一方、発注書や契約書の日付が交付決定より前になると、その経費は補助の対象から外れます。社内の決裁を通す段取りと、契約の日付の管理を分けて考えてください。

相見積もりはどう出せばよい？取適法で変わった点

相見積もりは、同じ要件書を全社に渡して条件をそろえます。価格交渉では、取適法で禁止された行為に触れない形で進めます。

補助金の申請では、経費の妥当性を示すために複数社の見積もりを求められる場面があります。条件がそろっていない見積もりは、比較の役に立ちません。

同じRFPを渡して比較条件をそろえる

複数の開発会社に同じ要件を記載したRFP (提案依頼書) を提示して提案を依頼すると、各社の提案書と見積もりを同一条件で比較できます。評価基準を統一しやすくなります。

RFPが無いまま個別に相談すると、会社ごとに前提条件の説明がぶれます。提案書同士を並べても、矛盾や抜け漏れに気づきにくくなります。当社が提案を作る側として見ても、要件書がある案件は見積もりの粒度がそろい、比較の土台になります。

提案書と見積もりの矛盾を見つける

システム開発の見積書は一般に「開発費用」「PM費」「インフラ費」「ライセンス費」「保守費」の5要素で構成されるとされています。初期費用の金額だけでなく、運用期間を通じたTCO (総保有コスト) の視点で内訳を比較することが実務上推奨されています。

確認する順番は次のとおりです。

  1. 見積書の備考欄の前提条件 (対応OSやブラウザのバージョン、開発体制、役割分担) を読む
  2. その前提が提案書の記述と一致しているかを照合する
  3. 契約方式が請負か準委任かをそろえて読む
  4. 補助金の対象経費の区分に当てはめ、対象外になる項目を分けておく

契約方式の違いは見積もりの起点を変えます。IPAは2020年3月31日に「情報システム・モデル取引・契約書 (アジャイル開発版)」を公開しており、このモデル契約が前提とする準委任のアジャイル開発では、成果物の完成ではなく「チームの稼働コスト×期間」で費用を見積もる方式が採られます。出典: IPA「情報システム・モデル取引・契約書 (アジャイル開発版)」。請負の見積もりと並べる場合は、この違いを踏まえて読む必要があります。

取適法の改正で注意が増えた点

下請代金支払遅延等防止法 (下請法) 及び下請中小企業振興法の一部を改正する法律は、令和7年5月16日に成立し、同月23日に公布されました。施行日は令和8年 (2026年) 1月1日です。出典: 公正取引委員会企業取引課「中小受託取引適正化法 (下請法改正法)」、公正取引委員会「中小受託取引適正化法 (取適法) 関係」。

改正では、価格転嫁のための協議に応じずに代金を一方的に決定することの禁止など、価格交渉に関する義務が新設されました。相見積もりで得た他社の金額を示して一方的に値下げを求める進め方は、この趣旨に照らして避けるべきです。詳しくは当社の「相見積もりの注意点、下請法・独占禁止法の基本」で解説しています。

補助金を前提に発注するときの進め方と当社の支援範囲

補助金は採択されるまで確定しません。採択されなかった場合の進め方まで決めてから発注してください。

ここを決めずに進めると、不採択の連絡が来た時点で計画そのものが止まります。業務の課題は残っているのに、半年を失うことになります。

採択前提で設計しない

発注の前に、社内で次の3点を決めておくと止まりません。

  1. 補助金が使えなかった場合に、自己資金で進める範囲はどこまでか
  2. 不採択のときに、次の締切を待つのか、規模を縮めて進めるのか
  3. 交付決定を待つ期間に、要件定義のどこまでを進めておくか

交付決定の前に契約はできませんが、要件の整理と見積もりの精査は進められます。待ち時間を要件定義に充てると、採択後の着手が早くなります。

スコープを分けておくことも有効です。業務のどの工程から効果が出るかを並べ、補助の対象になりそうな部分と、対象外でも自社で進める部分を分けておくと、どちらの結果でも動けます。

当社が支援できる範囲

当社は実装者として、要件定義から開発、公開後の運用までを請けています。業務システムの開発は500,000円から、Webサイトの制作は300,000円から、AIチャットボットの構築は100,000円からの料金体系です。

補助金については、当社がIT導入支援事業者としての登録を持っているかどうかで、できることが変わります。登録が必要な申請の代行や共同申請は、登録を持つ事業者に限られます。当社に相談いただく場合は、まず御社の導入内容が登録ITツールの枠に収まるのか、個別開発として自己資金で進めるほうが早いのかを、正直に切り分けてお伝えします。

制度の都合で要件を曲げると、使われないシステムが残ります。補助の対象に合わせて機能を足すより、業務のどこが詰まっているかから設計したほうが、結果として費用が下がることが多いです。

どの制度が使えそうかを含めて整理したい場合は、無料診断からご相談ください。補助金の情報は補助金ページでもまとめています。

よくある質問

業務システムの導入で補助金を検討する際に、相談の場でよく出る質問をまとめます。以下は2026年10月1日時点の情報です。最新は公式サイトで確認してください。

オーダーメイドで開発した業務システムは補助の対象になりますか？

公式サイトで確認できるのは「補助対象は事務局に登録されたITツールに限られる」という条件までです。個別開発を対象外と明記した公式の記述は確認できていません。したがって、断定はできず、導入するものが登録済みのITツールに該当するかをIT導入支援事業者に確認する形になります。出典: デジタル化・AI導入補助金2026 公式サイト 通常枠。

交付決定の前に契約してしまった場合はどうなりますか？

その経費は補助の対象になりません。交付決定の通知を受けた後に発注・契約・支払いを行う流れが前提です。出典: 同公式サイト。契約書や発注書の日付が交付決定より前になっていないかを、社内の決裁手続きとは別に管理してください。

GビズIDプライムの取得にはどれくらいかかりますか？

マイナンバーカードを用いたオンライン申請なら最短即日、書類の郵送による申請では2週間程度かかります。出典: 申請の流れとGビズIDプライムの所要日数に関する解説。締切の直前に動き出すと間に合わないため、最初に着手する項目として扱ってください。

クラウドの利用料は何年分まで対象になりますか？

通常枠では、クラウド利用料は最大2年分までが対象経費に含まれます。ソフトウェア購入費と合わせて必須の区分に入っています。出典: デジタル化・AI導入補助金2026 公式サイト 通常枠。3年目以降の利用料は自社の負担になるため、運用費の見通しは補助の期間を超えて立てる必要があります。

業務システムの申請で、業務プロセスの数はどう数えますか？

公式サイトでは、1種類以上の業務プロセスを保有するソフトウェアを申請することが条件とされ、汎用プロセスのみの申請は認められないと記載されています。対象となるプロセスは、顧客対応・販売支援や決済・債権債務・資金回収管理等の共通プロセス、または業種特化型プロセスです。出典: 同公式サイト。プロセスの数は補助額の区分にも効くため、IT導入支援事業者と登録内容を確認しながら決めることになります。

ホームページ制作とシステム開発を同時に申請できますか？

申請できる内容は、登録されたITツールの範囲で決まります。ホームページ制作が対象になるかどうかは枠と登録内容によって変わるため、当社の「IT導入補助金でホームページ制作は対象？補助率・申請方法を解説」も併せて確認してください。
