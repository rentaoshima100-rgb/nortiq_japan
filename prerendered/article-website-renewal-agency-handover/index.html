制作会社を変えるリニューアル、引き継ぐもの一覧

Web制作制作会社を変えるリニューアル、引き継ぐもの一覧NORTIQ LABS · COLUMN

前の制作会社から何を引き継げばよいのか

引き継ぐものは6つに整理できます。ドメイン名、DNSの設定、サーバとCMSの管理権限、原稿と画像の原本、計測ツールの権限、制作物の権利です。この6つを一覧にしておけば、抜けに気づけます。

6つの区分と、抜けたときに起きること

区分 具体的に受け取るもの 抜けたときに起きること
ドメイン名 管理指定事業者の変更、登録者情報の確認 更新の通知が届かず、失効の危険がある
DNSの設定 現在のレコードの一覧 切り替え時にメールが届かなくなる
サーバとCMSの管理権限 管理画面のアカウント、FTPやSSHの情報 公開作業ができない
原稿と画像の原本 編集可能な形式のファイル 新しい制作会社が作り直し、費用が増える
計測ツールの権限 Search Console、アナリティクスの所有権 過去の検索データを参照できない
制作物の権利 契約書の該当条項の確認 デザインを改変して使えない可能性がある

とくに見落とされやすいのがDNSの設定です。サイトの引っ越しにばかり目が向き、メールの設定が同じDNSにぶら下がっていることを忘れると、切り替えた日にメールが止まります。

着手の順番: 日数がかかるものから手を付ける

6つを同時に進める必要はありません。次の順序で着手してください。

  1. ドメイン名の状況を確認する (所要時間の目安: 確認は30分、手続きは数日)。登録者が誰になっているか、管理している事業者はどこかを調べます。相手の対応を待つため、最も早く動き出す必要があります。
  2. 契約書を探して権利の条項を確認する (所要時間の目安: 60分)。制作物の権利は、交渉が必要になる場合があります。早く気づくほど選択肢が残ります。
  3. 計測ツールの権限を確認する (所要時間の目安: 30分)。自社のアカウントで所有権を持てているかを見ます。
  4. 原稿と画像の原本を依頼する (所要時間の目安: 依頼は30分、受領まで1週間程度)。つまずきやすい点として、公開中のファイルを渡されて原本だと思ってしまうことがあります。
  5. サーバとCMSの権限を受け取る (所要時間の目安: 30分)。実際の切り替え直前でも間に合います。

順番を守る理由は単純で、1番と2番が相手の都合に左右されるからです。新しい制作会社との打ち合わせが始まってから動くと、公開の予定が押します。次章では、その中でも最も日数が読みにくいドメイン名の移管を扱います。

ドメイン名の移管は、どのくらい日数がかかるのか

JPRSの「ドメイン名の管理指定事業者の変更」によれば、手続きは開始から終了まで数日程度かかる場合があります。JPRSは、日程に余裕をもって手続きすることを案内しています。公開日から逆算して、最初に動かす項目です。

認証コードを使う手続きの流れ

JPドメイン名の管理指定事業者の変更は、認証コード (AuthCode) を使って行います。JPRSによれば、JPドメイン名での認証コードの利用は2022年11月13日から開始されています。

流れは次のとおりです。

  1. 登録者が変更元の指定事業者へ認証コードを確認する (所要時間の目安: 依頼は15分、回答待ちに数日)。ここが最も待たされる工程です。
  2. 変更元の指定事業者からJPRSへ認証コードの発行依頼が行われる (所要時間の目安: 事業者の対応次第)。自社では進められません。
  3. 登録者が認証コードの通知を受け取る (所要時間の目安: 通知を待つ)。
  4. 変更先の指定事業者へ認証コードを渡して手続きを進める (所要時間の目安: 30分)。具体的な方法は変更先の指定事業者に確認してください。

つまずきやすい点は、変更元へ連絡する窓口がわからないことです。まず年次の更新料を誰に払っているかを確認してください。請求元が、現在の管理事業者につながる手がかりになります。

指定事業者変更ロックの解除

ドメイン名に指定事業者変更ロックが設定されている場合、手続きの前にロックを解除する必要があります。ロックは不正な移管を防ぐための仕組みで、設定されていること自体は問題ではありません。

解除も変更元の指定事業者を通じて行います。ロックがかかっていることに気づくのが手続きの途中になると、そのぶん日数が延びます。認証コードを依頼するときに、ロックの状態もあわせて確認してください。

つまずきやすい点: 登録者情報が制作会社名のままになっている

移管の前に、登録者が誰になっているかを確認してください。制作時に制作会社が取得したドメイン名では、登録者が制作会社の名義のままになっていることがあります。

この場合、管理事業者を変えるだけでは自社の資産になりません。登録者の変更という別の手続きが必要です。手続きの内容は指定事業者によって異なるため、変更元と変更先の両方に確認してください。

次章では、同じく相手の協力が要る計測ツールの権限を扱います。

Search Consoleとアナリティクスの権限は、どう移せばよいのか

Search Consoleは、自社側で新たに所有権を確認したうえで、不要になった権限を削除するという順序で進めます。前の制作会社のアカウントを引き継ぐのではありません。自社のアカウントで所有権を持ち直す作業です。

所有者とユーザという2つの役割

Googleの「所有者、ユーザー、権限の管理」によれば、Search Consoleのプロパティに対する役割は所有者とユーザの2種類です。他のユーザに権限を付与できるのは、プロパティの所有者だけです。

つまり、自社が所有者になっていない状態では、誰かに権限を渡すことも外すこともできません。まず自社が所有者になることが出発点になります。

確認済み所有者と委任された所有者の違い

所有者には2つの種類があります。

種類 所有権の得方 特徴
確認済み所有者 所有権を証明するトークンを使って自分で確認した 他の所有者に外されない
委任された所有者 確認済み所有者から所有権ステータスを付与された 付与した側が外せる

Googleの「サイトの所有権を確認する」によれば、所有権の確認とは、そのサイトを所有していることをSearch Console上で証明する手続きです。確認済み所有者は、Search Consoleで最高レベルの権限を持ちます。

目指すのは確認済み所有者です。委任された所有者のままだと、前の制作会社が権限を外した時点で見られなくなります。

過去データを失わないための注意点

作業の順序を間違えると、データを見られなくなります。次の点に注意してください。

  1. 自社が確認済み所有者になってから、他を外す (つまずきやすい点: 先に前の制作会社の権限を削除すると、誰も所有者でない状態になる)。
  2. 所有権の確認方法をDNSレコード以外にも用意する (所要時間の目安: 30分)。HTMLファイルやタグでの確認も併用しておくと、DNSの切り替え時に外れません。
  3. アナリティクスは管理者権限を自社アカウントに付ける (つまずきやすい点: 制作会社のアカウントでプロパティが作られていると、その会社を外した瞬間に管理者が不在になる)。

なお、Search Consoleの過去のデータはプロパティに紐づいています。所有権を移しても、データそのものは残ります。一方でアナリティクスは、プロパティごと別アカウントへ移す必要がある場合があります。どちらも、リニューアルの公開作業より前に済ませてください。

原稿と画像の原本は、どこまで求めてよいのか

求めるのは、公開されているファイルではなく編集可能な原本です。ここが揃わないと、新しい制作会社の側で作り直しになり、追加費用が発生します。

原本として受け取るものの一覧

種類 公開されているもの 受け取りたい原本
写真 Webに合わせて縮小されたJPEG 撮影時の元データ
ロゴ PNGやJPEG AIやSVGなどのベクタ形式
図版・バナー 書き出された画像 レイヤが分かれた編集可能ファイル
原稿 ページに組み込まれた文章 テキストファイルや文書ファイル
動画 圧縮された配信用ファイル 編集前の素材と書き出し設定

依頼するときは「サイトのデータ一式をください」ではなく、この表の右側を名指しで求めてください。曖昧な依頼だと、公開中のファイルをまとめたものが届きます。

素材の準備が追加費用につながる構造

素材が揃わないと、そのぶんの作業が新しい制作会社の見積もりに乗ります。文章の執筆やプロによる撮影を制作会社に別途依頼すると、追加費用が発生します。自社で準備できる素材をあらかじめ洗い出し、該当する項目を見積もりから外してもらうよう事前に相談しておくことが、想定外の追加費用を避ける対策として挙げられています。

契約範囲が曖昧なまま進めることも同じ結果になります。契約時点でどこまでが基本料金に含まれるのかを具体的に取り決めていないことが、想定外の追加費用が発生する典型的な原因のひとつです。

なお、不足分を補助金で賄おうと考える場合は注意が必要です。中小企業庁が公開する「IT導入補助金2024」の公募要領によれば、通常枠の対象は会計ソフトや顧客管理システム、在庫管理システムなどのITツールであり、ホームページの制作費・デザイン費・コーディング費は補助対象に含まれていません。素材の作り直しを補助金で吸収する想定は立てないほうが安全です。

つまずきやすい点: 写真の使用期限が切れている

原本を受け取っても、そのまま使えるとは限りません。次の2点を確認してください。

  • 有料のストック写真は、契約しているのが制作会社か自社か
  • 人物が写っている写真は、撮影時の許諾がどの範囲まで取れているか

制作会社が自社の契約で購入したストック写真は、その会社との取引が終わると使えなくなる場合があります。人物写真も、掲載する媒体や期間を限って許諾を得ていることがあります。

引き継ぎの依頼時に、素材ごとの出どころと契約の有無を一覧でもらってください。制作物そのものの権利については、次章で扱います。

デザインとソースコードは、そのまま使い続けてよいのか

契約書に著作権法第27条と第28条の権利が特掲されているかどうかで、改変して使い続けられるかの扱いが変わります。著作権を譲り受けたと思っていても、改変の権利は残っていない場合があります。

著作権法第61条第2項が定める推定

e-Gov法令検索で確認できる著作権法第61条第2項は、次のように定めています。著作権を譲渡する契約において、第27条または第28条に規定する権利が譲渡の目的として特掲されていないときは、これらの権利は譲渡した者に留保されたものと推定する、という内容です。

第27条は翻訳権や翻案権など、第28条は二次的著作物の利用に関する原著作者の権利にあたります。リニューアルで既存のデザインを部分的に作り替える作業は、この翻案にあたる可能性があります。

つまり、契約書に「著作権を譲渡する」とだけ書かれている場合、改変の権利は前の制作会社に残っていると推定される形になります。

契約書で確認する3つの条項

手元の契約書で、次の3点を確認してください。

  1. 著作権の譲渡について書かれた条項があるか (所要時間の目安: 30分)。無い場合、制作物の著作権は制作会社に残っているのが通常です。
  2. 第27条・第28条という条番号が明記されているか (つまずきやすい点: 「一切の著作権」という表現だけでは特掲にあたらないと判断される可能性がある)。
  3. 著作者人格権を行使しない旨の定めがあるか (所要時間の目安: 15分)。この定めがないと、改変について異議を述べられる余地が残ります。

3点とも書かれていれば、改変して使い続ける前提で進められます。なお、最終的な法的判断は個別の契約内容によります。金額の大きい案件や争いが予想される場合は、弁護士に確認してください。

特掲がない場合に取れる選択肢

条番号の記載がなくても、道が閉ざされるわけではありません。次の3つが現実的な選択肢です。

選択肢 内容 向いている場面
追加で合意する 第27条・第28条の権利について覚書を交わす 前の制作会社と関係が良好な場合
利用の許諾を得る 譲渡ではなく、改変して使う許諾をもらう 譲渡に応じてもらえない場合
作り直す 既存デザインを引き継がず新しく作る 交渉に時間をかけたくない場合

リニューアルでデザインを全面的に作り替えるなら、3番目でも実害は小さくなります。一方、ロゴや既存のページを一部残す計画であれば、1番目か2番目を先に済ませてください。公開直前に気づくと、予定が動きます。

社内に詳しい担当者がいない場合は、どう進めればよいのか

新しい制作会社に引き継ぎの窓口を任せる方法があります。ただし、契約と権限の名義だけは自社に置いてください。ここを任せると、次に制作会社を変えるときに同じ問題が繰り返されます。

担当者がいないのは珍しいことではありません。株式会社kubellの調査によれば、システム担当者が不在の中小企業は全体で3割弱にのぼります。従業員10から29人規模に限ると、約5割弱が担当者はいないと回答しています。背景には業界全体の人材不足があり、経済産業省「IT人材需給に関する調査 (概要)」(平成31年4月公表) では、2030年に最大で約79万人のIT人材が不足すると推計されています。

新しい制作会社へ任せてよい範囲

任せてよいのは、手続きの実務と技術的な確認です。

  • 前の制作会社との、DNSレコードやサーバ設定に関するやり取り
  • Search Consoleの所有権の確認作業の代行
  • 受け取った素材が原本として足りているかの判断
  • 引き継ぎ内容の一覧化と、不足分の洗い出し

これらは専門的な判断を伴うため、詳しい人に見てもらったほうが早く終わります。

自社の名義で持ち続けるもの

一方で、次の3つは自社の名義のままにしてください。

対象 自社名義にする理由
ドメイン名の登録者 制作会社を変えても自社の資産として残る
Search Consoleとアナリティクスのアカウント 契約が終わっても過去のデータを参照できる
サーバやCMSの契約 支払いと解約の判断を自社で行える

制作会社には、自社のアカウントへ作業用の権限を付与する形にします。つまずきやすい点は、任せたほうが楽だからと名義ごと預けてしまうことです。それが今回の引き継ぎを難しくしている原因でもあります。

引き継ぎ依頼の文面に入れる項目

前の制作会社へ依頼する際は、次の項目を箇条書きで並べた文面を送ってください。口頭や電話だけで進めると、何を頼んだかの記録が残りません。

  1. ドメイン名の認証コードの発行と、変更ロックの状態 (所要時間の目安: 文面の作成に15分)。
  2. DNSレコードの現在の設定一覧。
  3. サーバとCMSの管理アカウント、および解約の予定日。
  4. 原稿と画像の原本、および素材ごとの出どころと契約の有無。
  5. Search Consoleとアナリティクスの権限の現状。
  6. 制作物の著作権に関する契約書の該当条項の確認依頼。

希望する回答期限も添えてください。前章までで見たとおり、ドメイン名の手続きには日数がかかります。依頼の時点で期限を示しておくと、公開の予定を立てやすくなります。

よくあるご質問

この記事に関して多い質問と回答をまとめます。

前の制作会社が引き継ぎに応じてくれない場合はどうすればよいですか。

まず、何を求めているかを書面で送ってください。口頭の依頼だと、対応の記録が残りません。前章の6項目を並べた文面と、希望する回答期限を添えます。

それでも応じてもらえない場合、項目ごとに代替の道があります。ドメイン名は、登録者が自社であれば指定事業者を通じて手続きを進められます。原稿と画像は、公開中のページから再取得できる範囲で作り直すことになります。契約書に引き継ぎの定めがある場合は、その条項を示して依頼してください。

ドメイン名を移管せずに、制作会社だけ変えることはできますか。

できます。管理事業者はそのままにして、DNSレコードの向き先だけを新しいサーバへ変えるという方法です。移管の日数を待たずに進められます。

ただし、更新の手続きと支払いは前の制作会社を経由したままになります。更新の通知が自社に届かず、失効してしまう危険が残ります。当面は移管せずに進めるとしても、登録者が自社になっているかだけは必ず確認してください。

Search Consoleの過去のデータは引き継げますか。

データはプロパティに紐づいているため、所有権を移しても残ります。自社が確認済み所有者になれば、そのまま過去の検索データを参照できます。

一方でアナリティクスは、プロパティが制作会社のアカウント内に作られている場合があります。この場合はプロパティごと自社のアカウントへ移す手続きが必要です。どちらも公開作業の前に済ませてください。

デザインデータがもらえない場合、同じ見た目のまま作り直せますか。

技術的には、公開中のページから再現することは可能です。ただし、著作権の扱いは別の問題です。見た目をそのまま再現する行為が翻案にあたる場合、前章で触れた第27条と第28条の権利が関わります。

契約書に特掲がない場合は、覚書を交わすか、許諾を得るか、デザインを変えて作り直すかのいずれかを選ぶことになります。判断に迷う場合は弁護士に確認してください。

引き継ぎにかかる費用は誰が負担するのでしょうか。

契約書に定めがなければ、当事者間の話し合いになります。前の制作会社に作業が発生する場合、実費や作業費を請求されることがあります。

新しい制作会社に窓口を任せる場合も、その作業は見積もりに含まれます。見積もりを取る段階で、引き継ぎの範囲が含まれているかを確認してください。範囲が書かれていない見積もりは、後から追加になりやすい項目です。
