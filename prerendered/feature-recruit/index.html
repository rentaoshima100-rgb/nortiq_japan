FEATURE / 採用

採用専門サイト。

求める人材像の言語化から、ブランドサイト/採用LP/エントリーフォームまで、応募の獲得を一貫設計します。写真ディレクション・社員インタビューも対応可。

採用サイトに必要な要素

REQUIRED ELEMENTS

/ 01

ペルソナ言語化

ターゲット人材を、職務経歴・志向性・年収レンジまで Nortiq チームと協働で言語化。

/ 02

ブランド・トーン設計

競合と差別化するメッセージング、ビジュアル方針を確定。

/ 03

社員インタビュー

代表 + 主要ポジション3名の撮影&取材代行。リアルな言葉を引き出します。

/ 04

応募フォーム最適化

離脱率を下げるフォーム設計 (項目絞り込み + ATS 連携)。

/ 05

選考プロセス可視化

応募者に「次に何が起こるか」を明示し、辞退を減らす情報設計。

/ 06

ATS 連携

HERP / Greenhouse / Workday などの ATS と連携、応募者管理を自動化。

採用サイトの必須コンテンツ

MUST-HAVE CONTENTS

社員インタビュー

候補者が最も読むコンテンツ。読了・離脱をヒートマップで分析し改善します。

数字で見る会社

平均年齢・残業・有給取得率など、事実の数字は抽象的な言葉より伝わります。

選考フロー・FAQ

応募前の不安を解消し、応募のハードルを下げます。

求人検索エンジン対応

1求人1URL設計と JobPosting 構造化データで、Indeed・Googleしごと検索からの流入を作ります。
