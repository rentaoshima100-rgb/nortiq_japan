PROBLEMS / こんな課題ありませんか

「作っただけ」のサイトで止まっていませんか?

PAIN — 01

問い合わせが、来ない

ヒーローに何を載せるか・どこに CTA を置くかが設計されていないと、訪問者は迷って離脱します。

PAIN — 02

ブログの更新が、止まる

WordPress を導入したが結局誰も更新できない、結果 SEO 流入も伸びない。

PAIN — 03

デザインが、古臭い

5〜10年前のテンプレートのまま。スマホで見づらく、競合と比較した時に見劣りします。

PAIN — 04

公開後、何も伸びない

運用設計がなく、Google Analytics を見ても何を改善すべきか判断できない。

FEATURES / Nortiq Labs の Web 制作

ただの Web 制作会社では、ありません。

3 段階ファネルを設計に組み込みつつ、Web 制作単体の発注も歓迎しています。

/ 01

段階的 DX 視野での設計

「公開して終わり」ではなく、AIチャットボット / DX 実装への接続を最初から見据えた構造で設計します。

/ 02

WordPress と Next.js、両方プロ

更新性重視なら WordPress、パフォーマンス・拡張性重視なら Next.js。プロジェクトに合わせて選定。

/ 03

集客導線の組み込み

ヒアリングでターゲットと検索キーワードを言語化し、コンテンツ構成 / 内部リンク / SEO までを一気通貫設計。

/ 04

Core Web Vitals Good 全域

LCP 1.5s 以下を標準目標として実装。フッターにスコアバッジを表示するレベルで、技術的に妥協しません。

/ 05

アクセシビリティ WCAG 2.1 AA

業界標準準拠。コンプライアンス重視の企業の選定基準もクリアします。

/ 06

バイリンガル対応可

必要に応じて日本語 × 英語の二言語サイトも構築。米国チームの強みを活かしたコピーライティングも。

PROCESS / 制作プロセス

6 ステップで、確実に。

  1. ヒアリング

    現状の課題、ターゲット、目標。30〜60分のオンライン MTG。

  2. 情報設計・ワイヤフレーム

    サイトマップ、ページ別ワイヤ、コピーの方向性をドキュメントで提示。

  3. デザイン

    ヒーロー含む主要ページの hi-fi デザイン。レビュー2回まで含む。

  4. 開発・実装

    WordPress または Next.js での実装。ステージング環境でのレビューを並行。

  5. 公開・移行

    DNS 切替、旧 URL からの 301 リダイレクト、GA4 / GSC 設定。

  6. 運用・改善

    公開後 3 ヶ月のサポート期間中、月次レビュー会で改善施策を実行。

FAQ / よくある質問

不安は、先に解消。

Light プランで 4〜6 週間、Standard で 8〜12 週間、Premium で 12〜16 週間を目安にしています。コンテンツの準備状況によって変動します。
ブログ更新を社内で頻繁に行いたい場合は WordPress、更新頻度よりパフォーマンスや拡張性を重視する場合は Next.js を推奨します。初回ヒアリングで一緒に決定します。
ブランドガイドラインから一緒に整える形でも対応可能です。必要に応じてデザイナーをアサインします。
Light は1ヶ月、Standard は3ヶ月、Premium は6ヶ月のサポートを含みます。それ以降は月次保守契約 (月2〜5万円〜) で継続可能です。
請負契約が基本ですが、長期の改善伴走をご希望の場合は準委任契約 (月額) もご相談いただけます。
IT導入補助金などの活用を視野に入れた DX 投資のご相談を承っています。なお、補助金申請の手続きサポート（登録 IT 導入支援事業者としての対応）は現在準備中です。
