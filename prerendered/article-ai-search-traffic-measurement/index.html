AI検索の流入を計測する方法｜GA4と参照元の確認

AI活用AI検索の流入を計測する方法NORTIQ LABS · COLUMN

AI検索からの流入は、どこで確認できますか？

Search Consoleで表示回数を、Googleアナリティクス4で遷移を確認します。どちらも御社がすでに使っている可能性が高い無料の画面です。

新しいツールを契約する必要はありません。まずこの2つで、何が分かって何が分からないかを整理します。

2つの画面で見るものが違う

見ている対象が違います。整理すると次のとおりです。

画面 分かること 分からないこと
Search Console 生成AIパフォーマンスレポート Googleの生成AI機能でサイトへのリンクが表示された回数 クリック数、CTR、検索クエリ
Googleアナリティクス4 トラフィック獲得レポート AIサービスから実際に遷移してきたセッション 表示されたが遷移しなかった分

Search Consoleの生成AIパフォーマンスレポートは、2026年6月3日に追加されました。AI OverviewsやAIモードでの表示回数を、公式のデータとして確認できるようになっています。

出典: Search Consoleヘルプ「生成 AI パフォーマンス レポート（検索）」、海外SEO情報ブログの解説

Googleアナリティクス4の側では、AIサービスからの遷移を参照元で見分けます。こちらは2026年6月に、デフォルトチャネルグループへ「AI Assistant」が追加されています。

出典: 株式会社仁頼「GA4でAI検索の流入を計測する3つの設定【2026】」

片方だけでは判断できない理由

片方だけを見ると、原因の切り分けができません。

たとえばAI検索からの流入が0件だったとします。考えられる状態は2つあります。

  1. そもそも生成AI機能に表示されていない。この場合はSearch Console側の表示回数も0です。
  2. 表示はされているが、遷移が起きていない。この場合はSearch Console側に表示回数が立ちます。

1番と2番では、次に打つ手が変わります。1番は表示されるための施策の話です。2番は、AIの回答内で自社の名前が出ていても、そこから先へ進む理由が示せていないという話になります。

両方の数字を並べて初めて、どちらの状態かが分かります。次のセクションから、それぞれの画面の見方を順に説明します。

Search Consoleでは何が分かりますか？

生成AIパフォーマンスレポートで、AI OverviewsとAIモードでの表示回数を確認できます。Googleが公式に出しているデータです。

このレポートは2026年6月3日に追加されました。外部ツールの推定値ではなく、Google側の集計値である点が特徴です。

見られる5つの項目

確認できる項目は5つです。インプレッション、ページ、国、デバイス、日付で構成されます。

出典: 海外SEO情報ブログ「Google、Search ConsoleにAI検索パフォーマンスレポートをリリース！」

ここでのインプレッションは、Google検索の生成AI機能でユーザにサイトへのリンクが表示された回数を指します。ページ別に見られるため、どの記事が引用されているかを把握できます。

御社での使い方としては、ページ別の表示回数を月次で控えておく形が実務的です。所要時間は1回5分ほどです。

クリックと検索クエリは未対応

現時点では、クリック、CTR、検索クエリには対応していません。

出典: 海外SEO情報ブログの解説

検索クエリが見られないため、「どんな質問で引用されたか」は分かりません。ページ単位の表示回数から推測する形になります。

クリック数が出ないことも、読み方に影響します。表示回数だけでは、そこから遷移が起きたかどうかが判断できません。遷移の確認はGoogleアナリティクス4側で行います。詳しくは次のセクションで説明します。

従来のレポートとの二重計上に注意

つまずきやすい点がここです。生成AI機能ぶんの数値は、従来の検索パフォーマンスレポートに含まれたまま合算されています。

新しく追加されたのは、そこから生成AI機能ぶんだけを抜き出して見るビューです。

出典: 海外SEO情報ブログの解説

つまり、従来の表示回数と生成AIパフォーマンスレポートの表示回数を足し算すると、二重に数えることになります。月次の報告資料を作る際は、この点にご注意ください。

正しい読み方は、従来の表示回数を全体として置き、そのうち生成AI機能ぶんがいくつかという形で見ることです。次の形で控えておくと混乱しません。

指標 意味
検索パフォーマンスの表示回数 生成AI機能ぶんを含む全体の数値
生成AIパフォーマンスの表示回数 上記のうち生成AI機能による分
差分 従来の検索結果による分

GA4ではAIサービスからの流入をどう見分けますか？

トラフィック獲得レポートの参照元/メディアで、chatgpt.comなどのドメインを確認します。AIサービスからの遷移は、通常の外部サイトからの流入と同じ仕組みで記録されます。

特別な設定を入れなくても、既定の状態で参照元として残っています。

主なAIサービスの参照元表記

代表的なサービスの表記は次のとおりです。

サービス 参照元/メディアの表記
ChatGPT chatgpt.com / referral
Gemini gemini.google.com / referral
Perplexity perplexity.ai / referral

出典: LLMOナビ「ChatGPT経由のアクセスはGA4で測れる？計測手順と精度向上策｜2026年版」

確認の手順は次のとおりです。所要時間は5分ほどです。

  1. Googleアナリティクス4を開き、レポートからトラフィック獲得を選ぶ。
  2. 表の行の項目を「セッションの参照元/メディア」に切り替える。
  3. 検索欄にchatgptと入力して絞り込む。他のサービスも同様に絞り込みます。

つまずきやすい点は、行の項目が既定では「セッションのデフォルトチャネルグループ」になっていることです。参照元/メディアに切り替えないと、個別のドメインが見えません。

AI Assistantチャネルとその限界

2026年6月には、デフォルトチャネルグループに「AI Assistant」が追加されました。同月上旬からデータへの反映が確認されています。

出典: 株式会社仁頼「GA4でAI検索の流入を計測する3つの設定【2026】」

このチャネルを使うと、複数のAIサービスをまとめて見られます。ただし限界が2つあります。

  1. 定義に含まれない参照元は、ReferralやOrganic Searchに散らばります。新しいサービスや、あまり知られていないサービスは拾いきれません。
  2. 追加された2026年6月より前のデータは、遡って再分類されません。過去との比較をする場合は、この点を踏まえて読みます。

出典: 株式会社仁頼の解説

2番は報告資料で誤解を招きやすい箇所です。「今年からAI経由の流入が増えた」と見えても、分類が始まっただけということがあります。前年同月と比べる場合は、参照元/メディアの生の数値で比べてください。

1番への対処としては、カスタムチャネルグループを作る方法があります。作り方は次のセクションで説明します。

計測を始める前に、どんな設定が必要ですか？

Googleアナリティクス4のデータ保持期間を、既定の2か月から14か月へ変更します。この設定を先に済ませてください。

保持期間を過ぎたデータは探索レポートから削除されます。後から延ばしても、消えた分は戻りません。

データ保持期間の設定

既定値は2か月です。無料版では14か月まで延長できます。

出典: アドエビス「GA4のデータ保持期間を徹底解説！」

有料のGoogleアナリティクス360では、26か月、38か月、50か月も選べます。中小企業の御社であれば、無料版の14か月で足ります。

設定の手順は次のとおりです。所要時間は3分ほどです。

  1. 管理から、データ設定のデータ保持を開く。
  2. イベントデータの保持を14か月に変更する。
  3. 保存する。

つまずきやすい点は、この設定が管理者権限でないと変更できないことです。権限が無い場合は、アカウントの管理者に依頼してください。制作会社にアカウントを作ってもらった場合、管理者が外部のままになっていることがあります。

カスタムチャネルグループの作り方

前のセクションで触れたとおり、AI Assistantチャネルの定義に含まれない参照元は他のチャネルに散らばります。まとめて見たい場合は、カスタムチャネルグループを作ります。

手順は次のとおりです。所要時間は15分ほどです。

  1. 管理から、データの表示のチャネルグループを開く。
  2. 新しいチャネルグループを作成する。
  3. 条件として、参照元に含まれる文字列でAIサービスのドメインを列挙する。
  4. 名前を付けて保存する。

3番で列挙するドメインは、自社に流入がある分だけで足ります。前のセクションの手順で参照元/メディアを確認し、実際に出ているものを入れてください。

もう1つの方法として、URLにパラメータを付けて配布する形もあります。ただしAI検索からの流入は、御社が配布したURLではなくAIが提示したリンクから来ます。パラメータを付けられないため、この方法は補助にとどまります。

設定が終わったら、1か月ほど数字が溜まるのを待ちます。その間に、Search Console側の生成AIパフォーマンスレポートも月次で控えておいてください。

数字を読むとき、何に注意しますか？

表示はあるのに遷移が無い場合と、そもそも表示が無い場合を切り分けて読みます。打つ手が変わるためです。

数字が小さいうちは、増減に一喜一憂しないことも大切です。母数が小さいと、数件の差が大きな比率に見えます。

2つの数字の組み合わせで読む

Search Consoleの表示回数と、Googleアナリティクス4の遷移数を組み合わせます。状態は4つに分かれます。

表示回数 遷移数 読み方 次に見ること
0 0 生成AI機能に出ていません 該当テーマのページがあるか、内容が問いに答えているか
あり 0 出ているが遷移していません 引用されているページの内容と、先を読む理由があるか
あり あり 出て遷移もしています どのページが効いているかを控えます
0 あり Google以外のAIサービス経由です 参照元でどのサービスか確認します

4番目の組み合わせは見落とされがちです。Search Consoleが見ているのはGoogle検索の生成AI機能だけです。ChatGPTやPerplexityからの流入は、Search Consoleには現れません。

計測できない流入が残る

すべてが数字になるわけではありません。残る範囲を把握しておきます。

  1. AIの回答内に自社名や内容が出ても、リンクがクリックされなければGoogleアナリティクス4には残りません。認知はされているのに、数字は0のままという状態が起こります。
  2. 検索クエリが分からないため、どんな質問で引用されたかは追えません。前のセクションで触れたとおり、生成AIパフォーマンスレポートは検索クエリに未対応です。
  3. アプリ内のブラウザや、参照元情報が送られない環境からの遷移は、Direct（直接）として記録されることがあります。

3番があるため、Directの数値が不自然に増えていないかもあわせて見てください。ただしDirectはブックマークや入力による訪問も含むため、AI経由と断定はできません。増減の傾向を見る程度にとどめます。

ここまでの注意点を踏まえると、月次で見る指標は多くありません。生成AI機能での表示回数、AIサービスからの遷移数、Directの推移の3つで足ります。最初の数か月は、この3つを並べて記録することをおすすめします。

計測した結果を、次の施策にどう使いますか？

表示が取れているページと取れていないページを分け、取れているページの構成を横展開します。推測ではなく、実際に引用されたページを基準にします。

数か月ぶんの記録が溜まってから着手してください。1か月の数値では判断できません。

まず見る3つの切り口

見る順番は次のとおりです。

  1. ページ別の表示回数を降順に並べる。上位のページに共通する形式を探します。所要時間は30分ほどです。
  2. 上位ページの構成を確認する。見出しが問いの形か、答えが見出しの直下にあるか、表や箇条書きで整理されているかを見ます。
  3. 表示はあるが遷移が無いページを抜き出す。前のセクションの表の2番目の状態です。本文に、続きを読む理由が書かれているかを確認します。

2番で見つかった形式を、他のページにも適用していきます。つまずきやすい点は、上位ページの本数が少ないうちに一般化してしまうことです。3本程度では傾向とは言えません。10本以上溜まってから判断してください。

3番の対処は、記事を増やすことではありません。既存のページに、具体的な数値や手順を足す作業になります。AIの回答で要約されても、原文を見る理由が残る内容かどうかという観点です。

中小企業がどこまでやるかの目安

どこまで手をかけるかは、利用の広がりを見て判断します。総務省の情報通信白書では、生成AIを使ったことがある個人の割合は日本で26.7%です。米国は68.8%、ドイツは59.2%、中国は81.2%でした。

出典: 総務省「令和7年版 情報通信白書 個人におけるAI利用の現状」

個人の利用では、日本はまだ差があります。一方で企業側は広がっています。令和8年版の情報通信白書では、何らかの業務で生成AIを使っていると回答した企業の割合は日本で86.4%でした。米国は90.9%、ドイツは91.6%、中国は98.1%です。

出典: 総務省「令和8年版情報通信白書（概要）」（2026年7月）

この差は、御社の読者がどちらかによって判断が変わることを意味します。法人向けの情報を出しているなら、AI検索経由の流入は今後増える見込みで見ておくほうが自然です。個人向けであれば、従来の検索の比重がまだ高い状態です。

いずれにしても、まずは計測を始めておくことをおすすめします。設定にかかる時間は合計で20分ほどで、費用はかかりません。数か月後に判断する材料が手元に残ります。

当社では、計測の設定から、引用されやすい記事の構成づくりまで一貫して支援しています。自社の数字をどう読めばよいか分からない場合は、無料診断でご相談ください。現状の設定を確認し、何から着手すべきかを整理します。

AI検索そのものへの対策については、当社の別記事で基本から整理しています。計測と対策をあわせてご覧ください。

よくあるご質問

この記事に関して多い質問と回答をまとめます。

生成AIパフォーマンスレポートはどこから開きますか

Search Consoleの左側のメニューから、検索パフォーマンスの配下にあるビューを選びます。プロパティによっては表示までに時間がかかる場合があります。

このレポートは2026年6月3日に追加されました。メニューに見当たらない場合は、Search Consoleのプロパティが正しく所有権確認されているかをご確認ください。

AI検索経由のクリック数は分かりますか

現時点では分かりません。生成AIパフォーマンスレポートで確認できるのは、インプレッション、ページ、国、デバイス、日付の5項目です。クリック、CTR、検索クエリには対応していません。

出典: 海外SEO情報ブログの解説

遷移があったかどうかは、Googleアナリティクス4の参照元で確認します。

ChatGPT経由の流入はGA4のどこに表示されますか

トラフィック獲得レポートで確認します。行の項目を「セッションの参照元/メディア」に切り替えてください。chatgpt.com / referral として表示されます。

出典: LLMOナビの解説

Geminiはgemini.google.com / referralです。Perplexityはperplexity.ai / referralと記録されます。既定のチャネルグループ表示のままだと見えないため、切り替えが必要です。

データ保持期間を14か月に変えると過去のデータも戻りますか

戻りません。既定の2か月を過ぎて削除されたデータは復元されません。

出典: アドエビス「GA4のデータ保持期間を徹底解説！」

そのため、計測を始めると決めた時点ですぐに設定を変更してください。所要時間は3分ほどです。なお、標準レポートの集計値は保持期間の影響を受けにくい一方、探索レポートは影響を受けます。

AI検索からの流入が0件の場合、何を確認すればよいですか

まずSearch Console側の表示回数を確認します。表示回数も0であれば、生成AI機能に出ていない状態です。表示回数があるのに遷移が0であれば、出てはいるが遷移が起きていない状態になります。

前者は該当するテーマのページがあるか、後者は本文に原文を読む理由があるかという観点で見直します。

外部のLLMO計測ツールは必要ですか

まずは不要です。Search ConsoleとGoogleアナリティクス4で、表示回数と遷移数は確認できます。費用もかかりません。

外部ツールは、AIの回答内での言及そのものを追う用途で使われます。ただし御社の流入がまだ少ない段階では、判断材料になるほどのデータが集まりません。数か月ぶんの記録が溜まり、判断に足りないと分かった時点で検討することをおすすめします。
