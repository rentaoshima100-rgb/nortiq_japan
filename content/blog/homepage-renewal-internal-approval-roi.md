# ホームページリニューアルの稟議｜使える数字

## ホームページリニューアルの稟議は、何から書き始めますか？

現状の数字を1枚にまとめることから始めます。目的や熱意ではなく、今の状態を示す数字が出発点です。

決裁者が判断できないのは、金額が高いからではありません。今のままだと何が起きるのかが分からないからです。数字は、その空白を埋めるために使います。

### 稟議書に必要な5つの構成

稟議書は、次の5つの要素で組み立てます。

1. 現状 (今のサイトの数字と、そこから起きている不都合)
2. 目的 (リニューアルで何を変えるか。1つか2つに絞る)
3. 費用 (見積もりの内訳と、補助金を使う場合の自己負担額)
4. 効果 (何がどれだけ変わるか。測り方も併記する)
5. 期間と体制 (いつ着手し、誰が社内の窓口になるか)

つまずきやすいのは2番目です。目的を「集客の強化とブランディングと採用」のように並べると、効果の測り方が定まりません。1つか2つに絞ると、あとの項目が自然に決まります。

書き上げる所要時間の目安は、数字が手元にある状態で2時間ほどです。数字の収集を含めると、1週間は見ておいてください。

### 書き始める前に集める3つの数字

集めるのは、次の3つです。

1. 問い合わせの件数 (直近12か月分を月別に)
2. サイトの訪問数と、問い合わせページまで進んだ人の数
3. サイトに関わる社内の作業時間 (更新の依頼、修正の待ち時間)

1番目は、営業部門やメールの受信箱から数えられます。2番目は、Googleアナリティクスの管理画面で確認します。3番目は、担当者への聞き取りで構いません。

実務でつまずきやすいのは2番目です。計測ツールのデータには保持期間があり、古い分は後から取り出せません。稟議を出す前に、必要な期間の数字を書き出して保存しておいてください。保持期間の扱いは後述します。

この3つが揃えば、稟議書の現状の欄は埋まります。数字が揃っていない場合は、その事実自体を現状として書いてください。測れていないことも、投資の理由になります。

## 費用対効果は、売上以外の何で説明できますか？

問い合わせ数、採用の応募数、社内の作業時間の3つで説明できます。売上への寄与だけに絞ると、リニューアル以外の要因が混ざり、根拠が弱くなります。

サイトの改修から売上までの間には、営業の活動や景気の変動が挟まります。だからこそ、サイトが直接動かせる数字まで戻して説明します。

### 効果を分解する3つの軸

次の表のように、軸ごとに測る数字と、その数字が動く理由を並べます。

| 効果の軸 | 稟議に載せる数字 | 変わる理由 |
|---|---|---|
| 問い合わせ | 月あたりの問い合わせ件数、フォームの到達率 | 導線と入力項目の見直しで、途中の離脱が減る |
| 採用 | 応募数、求人ページの閲覧数 | 募集要項と働く環境の情報を自社サイトに置ける |
| 社内の作業 | 更新の依頼から公開までの時間、月あたりの依頼件数 | 担当者が管理画面から直接更新できる |

3つすべてを書く必要はありません。自社で数えられる軸だけを選んでください。数えられない軸を書くと、報告の段階で困ります。

つまずきやすいのは、目標値の置き方です。「問い合わせを2倍にする」と書くと、達成できなかったときに次の投資が通りません。現状の数字に対して、何がどれだけ減るか、増えるかを控えめに書くほうが、後の報告が楽になります。

### 社内の作業時間を金額に換算する

作業時間は、金額に直すと決裁者に伝わりやすくなります。手順は次のとおりです。

1. サイトに関わる作業を書き出す。更新の依頼、原稿の受け渡し、確認、公開後の修正まで含めます。所要時間の目安は、担当者への聞き取りで1時間です。
2. 作業ごとに、月あたりの発生回数と1回の所要時間を記入します。つまずきやすいのは、待ち時間を入れ忘れる点です。制作会社へ依頼してから反映されるまでの待ちも、業務の停滞として記録してください。
3. 合計時間に、社内の時間単価をかけます。人事部門が持つ単価があればそれを使い、無ければ人件費の総額から概算で構いません。
4. リニューアル後に減る見込みの時間を、同じ計算式で出します。

この計算は、前提を書き添えることが重要です。単価をいくらで置いたか、どの作業を対象にしたかを注記しておくと、金額の妥当性を問われたときに議論が早く終わります。

なお、費用の側の相場と自己負担額は後述します。ここでは効果の側だけを整理してください。

## 同業と比べる根拠には、どの統計を使いますか？

総務省の通信利用動向調査を使います。企業のホームページ開設率が産業分類別に公表されており、自社の業種の水準を示せます。

この統計を使う利点は、出所が政府統計である点です。制作会社の調査だけを根拠にすると、発注先に都合のよい数字だと受け取られることがあります。

### 開設率の全体と業種別の水準

令和6年通信利用動向調査によると、自社のホームページを開設している企業の割合は93.2%です。前年から0.2ポイント増えています。

産業分類別の水準は次のとおりです。

| 産業分類 | ホームページ開設率 (令和6年) |
|---|---|
| 情報通信業 | 98.6% |
| 金融・保険業 | 97.0% |
| 不動産業 | 96.7% |
| 建設業 | 95.4% |
| 卸売・小売業 | 95.3% |

出典: 総務省『令和6年通信利用動向調査の結果』 (https://www.soumu.go.jp/menu_news/s-news/01tsushin02_02000178.html、2026年9月時点)

稟議書では、この数字を「持っているかどうか」の話で終わらせないでください。開設率が9割を超える業種では、サイトの有無ではなく中身で比較されます。自社のサイトが何年前の状態かを併記すると、比較の意味が伝わります。

### 統計を使うときの注意点

注意点は3つあります。

1. 調査の対象範囲を確認する。調査年や集計の区分によって、対象となる企業の規模が異なります。つまずきやすいのは、規模を限定した数値を全企業の数値として引用してしまう点です。
2. 開設率と活用度を混同しない。開設率は、サイトを持っている企業の割合です。更新の頻度や成果までは示しません。
3. 出典と調査年を必ず添える。稟議書の数字に出典が無いと、決裁の場で確認の作業が発生し、判断が翌月に持ち越されます。

引用の作業そのものは短時間で終わります。所要時間の目安は、報道資料から必要な数値を抜き出して表にするまで30分ほどです。

なお、自社サイトの現在の状態を数字で示す方法は次のセクションで扱います。統計は外部との比較、次の指標は自社の現状という役割の分担です。

## 改善の目標値は、どの基準で置きますか？

GoogleのCore Web Vitalsの基準を使います。公式に数値が定められているため、改善前と改善後を同じ物差しで比較できます。

自社で目標値を作ると、その水準が妥当かどうかの議論が発生します。公式の基準を引けば、議論は現状値との差の話だけで済みます。

### LCP、INP、CLSの基準

Googleが良好としている基準は次の3つです。

| 指標 | 何を測るか | 良好の基準 |
|---|---|---|
| LCP (最大コンテンツの描画) | 主要な内容が表示されるまでの速さ | 2.5秒以内 |
| INP (次のペイントまでのインタラクション) | 操作に対する反応の速さ | 200ミリ秒以下 |
| CLS (累積レイアウトシフト) | 表示中のずれの少なさ | 0.1以下 |

出典: web.dev『Web Vitals』 (https://web.dev/articles/vitals、2026年9月時点)

判定は、実際の利用者のデータの75パーセンタイルで行われます。平均値ではありません。

出典: web.dev『How the Core Web Vitals metrics thresholds were defined』 (https://web.dev/articles/defining-core-web-vitals-thresholds、2026年9月時点)

実務でつまずきやすいのは、この見方の違いです。平均値で「2.4秒なので基準内」と稟議に書くと、公開後の報告で数字が合わなくなります。記録する段階から75パーセンタイルの値で揃えてください。

### 現状値をどこで測るか

現状値は、リニューアルに着手する前に記録します。後から遡れないためです。

1. Search Consoleで、表示回数とクリック数を書き出します。検索パフォーマンスで遡れる期間は最長16か月です。画面上の操作にもAPIにも同じ制限がかかります。
2. Googleアナリティクス4のデータ保持期間の設定を確認します。既定値は2か月で、無料版の上限は14か月です。既定のままだと、2か月より前の状態を後から確認できません。
3. Core Web Vitalsの現状値を、3指標とも記録します。所要時間の目安は、画面の数値を控えるだけなら30分ほどです。

出典: Google『検索パフォーマンス レポート (検索結果): 概要と基本設定』(https://support.google.com/webmasters/answer/7576553?hl=ja)、Google『データ保持期間』(https://support.google.com/analytics/answer/7667196?hl=ja) (いずれも2026年9月時点)

2番目のつまずきは、設定を変えても過去には遡れない点です。保持期間を延ばした時点より前のデータは戻りません。稟議を書く前の段階で設定を確認しておくと、公開後の報告で困りません。

記録した数字は、稟議書の現状の欄と、承認後の報告の両方で使います。報告の準備は後述します。

## 自己負担額は、どこまで下げられますか？

補助金を使える場合は、補助率と上限額から自己負担額を計算して稟議に載せます。総額ではなく、実際に社外へ出る金額が判断の材料になります。

中小企業庁は、令和7年度補正予算事業から「IT導入補助金」を「デジタル化・AI導入補助金」へ名称変更しました。稟議書に古い名称を書くと、制度を調べ直す手間が決裁者側に発生します。

### 補助率と上限額の考え方

デジタル化・AI導入補助金2026の主な枠は次のとおりです。

| 枠 | 補助率 | 補助額の上限 |
|---|---|---|
| 通常枠 | 原則2分の1以内 (要件により3分の2以内、小規模事業者は最大5分の4) | 業務プロセス4つ以上で450万円 |
| インボイス枠 (電子取引類型) | 中小企業は3分の2まで | 350万円 |

出典: デジタル化・AI導入補助金2026『通常枠』 (https://it-shien.smrj.go.jp/applicant/subsidy/normal/、2026年9月時点)、中小企業庁

自己負担額は、対象経費に補助率をかけて差し引きます。上限額を超える部分は、全額が自己負担です。稟議書には、総額、補助額、自己負担額の3つを並べて書いてください。

制度の目的は、中小企業・小規模事業者等の労働生産性の向上に置かれています。そのため、稟議でも売上の増加だけでなく、社内の工数がどれだけ減るかを併記すると、制度の趣旨と説明の筋が揃います。工数の換算方法は前述のとおりです。

### 補助金を織り込むときの但し書き

補助金は、申請しても採択されるとは限りません。稟議書には、次の但し書きを必ず添えてください。

1. 採択されなかった場合の扱い (全額自己負担で進めるか、規模を縮小するか)
2. 申請の締切と、採択の通知が出る時期
3. 対象になる経費と、ならない経費の区分

つまずきやすいのは3番目です。補助の対象になるかどうかは公募要領で定められています。サイトの制作費のうち、どこまでが対象かを外注先と確認してから金額を書いてください。所要時間の目安は、公募要領の該当箇所を読むのに1時間ほどです。

もう1つの注意点は、発注の時期です。交付の決定より前に契約や発注をすると、対象外になる制度があります。着手の予定日を稟議書に書く際は、申請の手順と並べて確認してください。

補助金の可否を前提にせず、自己負担が最大になる金額でも通る組み立てにしておくと、採択の結果に左右されずに進められます。

## 決裁者からの質問に、どう備えますか？

費用、期間、効果の測り方、失敗したときの対応の4点に、あらかじめ答えを用意します。稟議書の本文ではなく、別紙や口頭の補足で持っておく形で構いません。

質問に即答できないと、判断は次の会議に持ち越されます。持ち越しの回数が増えるほど、着手は遅れます。

### よく出る質問と回答の組み立て

多いのは次の4つです。

| 質問 | 用意しておく答え |
|---|---|
| この金額は妥当か | 相場の幅と、自社の見積もりがどこに位置するか |
| なぜ今なのか | 現状の数字と、公式基準との差 |
| 効果はどう測るのか | 記録済みの現状値と、報告の時期 |
| 成果が出なかったらどうするか | 測定の結果に応じて次に何を直すか |

1番目の相場については、制作会社や比較メディアの公開情報が参考になります。小規模なコーポレートサイト (10ページ前後) のリニューアルは30万円から100万円程度、中規模サイト (30ページから50ページ) では100万円から300万円程度という目安が示されています。

出典: 株式会社GIG『ホームページのリニューアル費用の相場と内訳』 (https://giginc.co.jp/blog/giglab/hp-renewal-cost)、lany『サイトリニューアル費用相場とは？』 (https://www.lany.co.jp/blog/site-renewal-cost) ほか複数の制作会社メディアの掲載情報 (2026年9月時点)

注意したいのは、これらが公的統計ではなく制作会社による参考値である点です。稟議書に載せるときは、参考値であることを明記し、自社で取得した相見積もりの金額を主にしてください。

補助金の欄も質問の的になります。デジタル化・AI導入補助金2026の通常枠は、補助率が2分の1以内で、補助上限を150万円未満とする区分があります。枠や要件によって上限額は変わるため、稟議書には申請予定の枠の名称と、参照した公募要領の版を書き添えてください。

出典: 中小企業庁『デジタル化・AI導入補助金2026 通常枠』 (https://it-shien.smrj.go.jp/applicant/subsidy/normal/、2026年9月時点)

つまずきやすいのは、補助金の枠ごとの数字を混ぜて書くことです。枠が違えば上限も要件も違います。1つの枠に絞って書くほうが、確認が早く終わります。

### 承認後に効果を報告する準備

承認の時点で、報告の時期と様式を決めておきます。次の3つを稟議書の末尾に書いてください。

1. 報告の時期 (公開から3か月後と6か月後など)
2. 報告する数字 (稟議書に書いた現状値と同じ項目)
3. 報告する人 (担当者が異動した場合の引き継ぎ先も含む)

所要時間の目安は、決めて書くだけなら15分です。ここを書いておくと、次の投資の稟議が通りやすくなります。報告の実績が、そのまま次の根拠になるためです。

当社もWeb制作を手がけており、見積もりの段階で費用の内訳と、リニューアル前に記録しておくべき数値の一覧をお渡ししています。社内の説明に使える資料の形で相談したい場合は、[無料診断](/diagnostic)をご利用ください。

## よくあるご質問

稟議の準備でよく聞かれる点をまとめます。社内で説明する前の確認にお使いください。

### ホームページリニューアルの稟議書に、最低限どの項目を書けばよいですか？

現状、目的、費用、効果、期間と体制の5項目です。この5つが揃っていれば、決裁の場で議論の対象が明確になります。

とくに現状の欄は、感想ではなく数字で書いてください。数字が無い場合は、測れていないこと自体を現状として書きます。

### 費用対効果を数字で示せない場合、どう説明すればよいですか？

社内の作業時間から説明します。問い合わせや売上が測れない場合でも、更新の依頼にかかる時間や待ち時間は記録できます。

時間を金額に換算する手順は本文のとおりです。単価と対象の作業を注記しておけば、概算でも議論の土台になります。

### 同業他社の状況は、どこで調べられますか？

総務省の通信利用動向調査で、産業分類別のホームページ開設率を確認できます。政府統計のため、出所を問われても説明が簡単です。

個別の競合サイトの状況は、公開されているページを自分で確認する形になります。表示速度は計測ツールで測れます。

### 補助金を前提に稟議を出しても問題ありませんか？

問題ありませんが、採択されなかった場合の扱いを必ず併記してください。全額自己負担で進めるのか、規模を縮小するのかを決めておきます。

交付の決定より前の発注が対象外になる制度もあります。着手の予定日と申請の手順を並べて確認してください。

### 稟議が通った後、効果はいつ報告すればよいですか？

公開から3か月後と6か月後を目安に、稟議書へ書いた項目と同じ数字で報告します。検索順位や流入は、公開直後に一時的に下がることがあるためです。

報告の時期を承認の時点で決めておくと、担当者が変わっても引き継げます。次の投資を通すときの根拠にもなります。

リニューアルの要件整理や、社内の説明に使う資料づくりでお困りの場合は、お問い合わせからご相談ください。
