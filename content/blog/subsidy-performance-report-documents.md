# ホームページ補助金の実績報告｜書類と保存5年

## 実績報告はいつまでに何を出す？

提出するのは実績報告書と支出内容の分かる関係書類等です。期限は補助事業が終了した日から30日を経過した日と、定められた実績報告書提出期限のいずれか早い日です。

以下は小規模事業者持続化補助金 一般型 通常枠 第19回公募の公募要領 第6版の記載です（出典: https://www.jizokukanb.com/jizokuka_r6h/doc/kobo/r6_19/19_%E9%80%9A%E5%B8%B8%E6%9E%A0_%E5%85%AC%E5%8B%9F%E8%A6%81%E9%A0%98_%E7%AC%AC6%E7%89%88.pdf）。第6版は2026年3月6日の公表です。回次と版で内容が変わるため、2026年3月6日時点の記載として読んでください。最新は公式サイトでご確認ください。

### 提出物は2種類

公募要領は、補助事業者の義務として次のように定めています。

「補助事業の終了後、実績報告書（交付規程様式第 8）および支出内容の分かる関係書類等を、定められた期日までに補助金事務局に提出しなければなりません。」（出典: 同要領、2026年3月6日時点）

提出物は2種類です。様式が決まっている実績報告書と、支出内容を裏づける関係書類等です。

関係書類等の個別の一覧は、公募要領ではなく事務局が公開する補助事業の手引き側に置かれています。手引きは交付決定の後に案内されます。最新は公式サイトでご確認ください。

### 期限の数え方は30日と提出期限の早い方

期限は2つを比べて早い方です。

| 比べる日 | 内容 |
| --- | --- |
| 終了した日から30日を経過した日 | 補助事業が実施期間の途中で終了した場合の起算 |
| 補助事業実績報告書提出期限 | 公募要領の表に受付締切分ごとに示される日 |

公募要領の記載は次のとおりです。「上記実施期間の途中で、補助事業が終了（補助対象経費の支払いまで含みます）したときは、その日から起算して 30 日を経過した日、または上記『補助事業実績報告書提出期限』のいずれか早い日までに実施事業内容および経費内容を取りまとめ、提出しなければなりません。」（出典: 同要領、2026年3月6日時点）

同要領の表では、第19回受付締切分の提出期限が2027年7月10日と示されています（出典: 同要領、2026年3月6日時点）。御社の受付締切分の日付は、該当回の公募要領で確認してください。最新は公式サイトでご確認ください。

### 終了の判定には支払いまで含まれる

見落としやすいのが、終了の定義です。

条文の括弧の中に「補助対象経費の支払いまで含みます」と書かれています。公開した日ではなく、制作会社への支払が済んだ日が起点です。

つまり、公開から支払までに時間がかかると、30日の計算もそのぶん後ろへ動きます。逆に、支払を早く済ませた場合は期限も早く来ます。

当社が発注側のお客様に申し上げているのは、支払日を先に確定させてから報告の作業日を押さえることです。公開日を基準に段取りを組むと、支払が前後したときに期限の認識がずれます。

## 期限に間に合わないとどうなる？

交付決定が取り消されます。公募要領は、定められた期日までに提出が確認できなかった場合は交付決定を取り消すと定めています。

以下はいずれも第19回公募の公募要領 第6版の記載です（出典: https://www.jizokukanb.com/jizokuka_r6h/doc/kobo/r6_19/19_%E9%80%9A%E5%B8%B8%E6%9E%A0_%E5%85%AC%E5%8B%9F%E8%A6%81%E9%A0%98_%E7%AC%AC6%E7%89%88.pdf）。2026年3月6日時点の内容です。最新は公式サイトでご確認ください。

### 提出できなかった場合

条文はこうなっています。

「定められた期日までに実績報告書等の提出が補助金事務局で確認できなかった場合、交付決定を取り消します。」（出典: 同要領、2026年3月6日時点）

書き方に注意してください。提出したかどうかではなく、事務局で確認できたかどうかが基準です。郵送や電子申請の到達の遅れも、御社の側の事情になります。

期限の直前に出す段取りは避けてください。差し戻しがあった場合に、訂正の時間が残りません。

### 書類に不備があった場合

不備は訂正して出し直します。公募要領は次のように定めています。

「実績報告書等に不備が発見された場合には、補助金事務局の指示に従って実績報告書等を訂正し、速やかに再提出しなければなりません。」（出典: 同要領、2026年3月6日時点）

ここで効いてくるのが、前の見出しで触れた期限の数え方です。訂正のやり取りに日数がかかると、期限に間に合わなくなります。

### 要件を満たしていないと判断された場合

金額が減る、あるいは取り消される場合があります。

「実績報告時に要件を満たしていると認められない場合には、『補助金交付決定通知書』に記載した交付金額より少なくなる場合（交付決定を取り消す場合も含む）があります。」（出典: 同要領、2026年3月6日時点）

対象と対象外を正直に押さえておく必要があります。補助金は、交付決定を受けた額が確定額ではありません。報告の内容で確定します。

起こりやすい減額の原因を挙げます。

| 原因 | 報告時に何が起きるか |
| --- | --- |
| 交付決定の前に発注や契約をしていた | 当該経費が対象外として扱われることがある |
| 計画に無い費目の支出を追加していた | 原則として認められず対象外になる |
| 支払の証拠が揃っていない | 支出内容を確認できず計上できない |
| 補助事業期間を越える契約を結んでいた | 期間分のみが対象になる場合がある |

いずれも、報告の段階では直せません。発注の前に決まってしまう項目です。発注の時期と証拠の関係は、後述します。

当社がリニューアルのご相談を受けるときは、交付決定の通知を見せていただいてから発注の日付を決めています。順番を逆にすると、作ったものは残っても補助の対象から外れます。

## 証拠書類はどこまで、いつまで残す？

補助事業に関係する帳簿と証拠書類を、補助事業の終了日の属する年度の終了後5年間保存します。起算点が終了日そのものではない点に注意が必要です。

以下は第19回公募の公募要領 第6版の記載です（出典: https://www.jizokukanb.com/jizokuka_r6h/doc/kobo/r6_19/19_%E9%80%9A%E5%B8%B8%E6%9E%A0_%E5%85%AC%E5%8B%9F%E8%A6%81%E9%A0%98_%E7%AC%AC6%E7%89%88.pdf）。2026年3月6日時点の内容です。最新は公式サイトでご確認ください。

### 5年の起算点は年度の終了後

公募要領は見出しで「補助事業関係書類は事業終了後 5 年間保存しなければなりません。」と示しています。本文の規定は次のとおりです。

「補助事業者は、補助事業に関係する帳簿および証拠書類を補助事業の終了日の属する年度の終了後 5 年間、補助金事務局等や独立行政法人中小企業基盤整備機構（中略）、国の補助金等の執行を監督する会計検査院からの求めがあった際に、いつでも閲覧に供せるよう保存しておかなければなりません。」（出典: 同要領、2026年3月6日時点）

起算点は「終了日の属する年度の終了後」です。終了日から5年ではありません。

例えば終了日が年度の前半であれば、実際に保存する期間は5年より長くなります。御社の決算月で年度の終わりが変わるため、社内では年度末を基準に管理するのが実務的です。

### 閲覧を求める相手は3者

条文に挙がっている相手は3者です。

| 相手 | 立場 |
| --- | --- |
| 補助金事務局等 | 補助金を執行する側 |
| 独立行政法人中小企業基盤整備機構 | 条文に明記された機関 |
| 会計検査院 | 国の補助金等の執行を監督する機関 |

公募要領は「この期間に、会計検査院等による実地検査等が実施される可能性もあり、補助金の交付を受けた者の義務として応じなければなりません。」としています（出典: 同要領、2026年3月6日時点）。

さらに「検査等の結果、仮に、補助金の返還命令等の指示がなされた場合には従わなければなりません。」と記載されています（出典: 同要領、2026年3月6日時点）。

### 保存の実務の組み方

実地検査は、いつ来るか分かりません。したがって、探さずに出せる状態にしておくのが前提です。

1. 補助事業ごとに1つのフォルダを作る（目安: 30分）。年度と回次を名前に入れます。
2. 書類を工程の順に並べる（目安: 1時間）。見積、交付決定通知、発注、納品、請求、支払、実績報告の順です。
3. 支払の証跡を同じ場所に揃える（目安: 1時間）。通帳の記録や振込の控えを、請求書と対応づけて置きます。つまずきやすい点は、支払だけ経理のファイルに分かれていて、報告のときに突き合わせが必要になることです。
4. 紙と電子の保管場所を1つに決める（目安: 30分）。両方に分かれると、担当者が変わったときに揃いません。
5. 年度末に残す期間を見直す（目安: 30分）。前述の起算点で終期を計算し、フォルダ名に記載します。

当社がリニューアルの納品でお渡ししているのは、見積と納品物の一覧、作業の記録、公開日の記録です。制作会社から出せる書類は限られているため、支払の証跡は御社の側で揃えていただく形になります。どちらが何を持つかは、発注の段階で決めておくと後が楽です。

## ホームページの費用はどこまで対象になる？

ウェブサイト関連費として計上します。上限は回次と版で変わっており、第20回公募の公募要領 第7版では30万円 (税込) です。いずれの回次でも、この費目だけでの申請はできません。

ここは誤りが残りやすい箇所です。先に上限の変化を整理します。

### 上限は回次で変わっている

| 公募要領 | ウェブサイト関連費の上限 |
| --- | --- |
| 第19回公募 第6版 (2026年3月6日) | 補助金交付申請額の1／4 (最大50万円) |
| 第20回公募 第7版 (2026年5月27日) | 30万円 (税込) |

第19回の記載は次のとおりです。「ウェブサイト関連費は、補助金交付申請額の 1／4 (最大 50 万円) が、当経費の申請額の上限です。」（出典: 第19回公募 公募要領 第6版 https://www.jizokukanb.com/jizokuka_r6h/doc/kobo/r6_19/19_%E9%80%9A%E5%B8%B8%E6%9E%A0_%E5%85%AC%E5%8B%9F%E8%A6%81%E9%A0%98_%E7%AC%AC6%E7%89%88.pdf、2026年3月6日時点）

第20回の公募要領 第7版では、この経費の補助金交付申請額の上限を30万円 (税込) と明記しています（出典: 小規模事業者持続化補助金 一般型 通常枠 第20回公募 公募要領 第7版、2026年5月27日、小規模事業者持続化補助金事務局 https://www.jizokukanb.com/ 。2026年5月27日時点）。

「4分の1かつ最大50万円」と説明している解説は今も見られます。御社が申請する回次の公募要領で必ず確認してください。最新は公式サイトでご確認ください。

### ウェブサイト関連費の範囲

第20回公募の公募要領は、ホームページやECサイト、システムの開発、構築、更新、改修、運用に要する経費をウェブサイト関連費と定めています。

計上先の指定もあります。ウェブサイトやシステム開発等に関連するソフトウェアは機械装置等費ではなくウェブサイト関連費へ、自社ホームページやECサイトで使用する動画や写真の制作費用等は広報費ではなくウェブサイト関連費へ計上するよう指示されています（出典: 同第7版、2026年5月27日時点）。

対象となる経費例として挙げられているのは次のものです。

- 商品販売のための自社ウェブサイトの作成や更新
- 効果や作業内容が明確なウェブサイトのSEO対策
- 顧客管理システムの構築
- アプリケーション開発

### 対象外になりやすい経費

対象外も公募要領に明記されています。報告の段階で落ちやすいのはこちらです。

| 対象外の経費 | 注意点 |
| --- | --- |
| ウェブサイトおよびシステムに関連するコンサルティングやアドバイス費用 | 制作の見積に助言の工数が含まれていると分離が必要になる |
| 補助事業期間内に運用に至らなかったホームページやランディングページ | 公開まで到達していないと計上できない |
| 既に導入しているソフトウェアの更新料 | 継続費用は対象にならない |
| 家庭および一般事務用ソフトウェア | 汎用のソフトは対象にならない |

これらは第20回公募の公募要領の記載です（出典: 同第7版、2026年5月27日時点）。

あわせて、この費目は単独では申請できません。「ウェブサイト関連費のみによる申請はできません。必ず、ほかの経費と一緒に申請してください」と記載されています（出典: 同第7版、2026年5月27日時点）。

なお補助金全体の枠は、補助率が3分の2 (賃金引上げ特例のうち赤字事業者は4分の3)、補助上限が50万円です。インボイス特例の要件を満たす場合は50万円、賃金引上げ特例の要件を満たす場合は150万円が上限に上乗せされます（出典: 同第7版「6．補助率、補助上限額等」、2026年5月27日時点）。

見積についても定めがあります。採択発表後から交付決定までに、経費の価格の妥当性を証明できる見積書等 (相見積を含む) の提出が必要で、支出内容が不明確なものは認められないとされています（出典: 同第7版、2026年5月27日時点）。

当社がお客様の見積を作るときは、助言の工数と制作の工数を最初から別の行に分けています。1行にまとめた見積は、対象外の経費が混ざっていないことを後から示せません。ウェブサイト関連費の上限そのものは、当サイトの「小規模事業者持続化補助金 ウェブサイト関連費の上限」で扱っています。

## 作ったホームページは自由に作り直せる？

50万円 (税抜) 以上で作成または更新した場合は処分制限財産に該当し、通常は取得日から5年間、処分が制限されます。ただし目的の遂行に必要な改良や機能強化は処分に該当しません。

更新ができなくなるわけではありません。線引きがどこにあるかを押さえておけば足ります。

### 処分制限財産に該当する条件

公募要領の記載は次のとおりです。

「ウェブサイトを 50 万円 (税抜き) 以上の費用で作成・更新する場合、当該ウェブサイトは『処分制限財産』に該当し、補助事業が終了し、補助金の支払を受けた後であっても、一定の期間 (通常は取得日から 5 年間) において処分 (補助事業目的外での使用、譲渡、担保提供、廃棄等) が制限されることがあります。」（出典: 小規模事業者持続化補助金 一般型 通常枠 第19回公募 公募要領 第6版 https://www.jizokukanb.com/jizokuka_r6h/doc/kobo/r6_19/19_%E9%80%9A%E5%B8%B8%E6%9E%A0_%E5%85%AC%E5%8B%9F%E8%A6%81%E9%A0%98_%E7%AC%AC6%E7%89%88.pdf、2026年3月6日時点）

判定の基準は税抜の費用です。補助金の額ではなく、作成または更新にかかった費用で見ます。最新は公式サイトでご確認ください。

### 承認が必要な行為と不要な行為

区別を表にします。

| 行為 | 扱い |
| --- | --- |
| 補助事業目的外での使用、譲渡、担保提供、廃棄等 | 処分に該当する。事前に補助金事務局の承認が必要 |
| 補助事業の目的を遂行するために必要なホームページの改良や機能強化 | 処分に該当しない。事前承認申請等は不要 |

後者は公募要領に明記されています。「補助金の交付を受けた補助事業の目的を遂行するために必要なホームページの改良や機能強化は、補助金事務局への事前承認申請等が必要となる『処分』には該当しません。」（出典: 同要領、2026年3月6日時点）

つまり、販路開拓のために作ったサイトを、同じ目的のために直す行為は制限されていません。ページの追加、文章の更新、表示速度の改善は、通常はこちらに入ります。

迷いやすいのは、サイトを閉じる場合と、別の用途へ使う場合です。廃棄や目的外での使用は処分に当たるため、判断を自社で決めずに事務局へ確認してください。

### 承認を得ずに処分した場合

公募要領は、処分制限期間内に処分する場合は必ず補助金事務局へ承認を申請し、承認を受けた後でなければ処分できないとしています（出典: 同要領、2026年3月6日時点）。

さらに次の記載があります。

- 財産処分を承認した補助事業者に対し、残存簿価等から算出される金額の返還のため、交付した補助金の全部または一部に相当する金額を納付させることがある
- 承認を得ずに処分を行うと、交付規程違反により補助金交付取消および返還命令 (加算金付き) の対象となる

いずれも同要領の記載です（出典: 同要領、2026年3月6日時点）。

当社がお客様にお伝えしているのは、取得日と費用を社内の記録に残しておくことです。5年の起算点は取得日なので、この2つが分からないと、後から判断できません。前の見出しで触れた書類の保存と同じフォルダに入れておくのが確実です。

## 実績報告の後にも報告がある？

あります。補助事業終了から1年後の状況について、事業効果等状況報告の提出が必要です。提出していない事業者には、次の補助金申請で制限が課されます。

実績報告で終わりだと思っていると、1年後の案内を見落とします。

### 事業効果等状況報告の時期

公募要領の記載は次のとおりです。

「補助事業者は、補助事業終了から 1 年後の状況について、交付規程第 29 条に定める『事業効果等状況報告』を、補助事業実施後、補助金事務局が指定する期限までに必ず行うことが必要です。」（出典: 小規模事業者持続化補助金 一般型 通常枠 第19回公募 公募要領 第6版 https://www.jizokukanb.com/jizokuka_r6h/doc/kobo/r6_19/19_%E9%80%9A%E5%B8%B8%E6%9E%A0_%E5%85%AC%E5%8B%9F%E8%A6%81%E9%A0%98_%E7%AC%AC6%E7%89%88.pdf、2026年3月6日時点）

報告の対象は、補助事業終了から1年後の状況です。提出の期限は補助金事務局が指定します。最新は公式サイトでご確認ください。

同要領では、補助金を活用して取り組む事業やその効果等を把握するためのアンケート調査等を実施する場合があり、協力を依頼する旨も記載されています（出典: 同要領、2026年3月6日時点）。

### 出し忘れたときの影響

次の申請に影響します。公募要領は「提出していない事業者には補助金申請に際し、制限が課されます。」としています（出典: 同要領、2026年3月6日時点）。

同要領は、詳細を「3．補助対象外となる事業者」で確認するよう案内しています（出典: 同要領、2026年3月6日時点）。

つまり、1年後の報告を落とすと、次に使いたい補助金の入口で止まる可能性があります。制作そのものは終わっていても、手続は続いていると考えてください。

管理の方法は単純です。

1. 補助事業の終了日を社内の記録に書く（目安: 10分）。前の見出しで作ったフォルダに入れます。
2. 終了日の11か月後にリマインダを設定する（目安: 10分）。事務局の案内を待たずに準備を始める時期です。
3. 報告に使う数値の取り方を決める（目安: 30分）。売上や問い合わせ件数など、1年後に答える項目を想定して記録を残します。つまずきやすい点は、公開前の数値を測っていないため、1年後に比較ができないことです。

3番目は、当社がリニューアルのご相談で最初に確認している点でもあります。公開前の問い合わせ件数とアクセス数を記録しておかないと、1年後に効果を説明できません。測定の準備は、発注の段階で済ませておくのが確実です。

## 発注前と報告でつながる準備は？

交付決定の前に発注してよいかという判断と、報告で求められる証拠書類は同じ流れの上にあります。発注の時期を間違えると、報告の段階で経費が対象外になります。

ここだけは、報告の直前に気付いても戻せません。

### 発注の時期と証拠の関係

対象外になるのは支払だけではありません。契約と発注も含まれます。

IT導入補助金の事業完了報告の手引き (令和元年度) には、「交付決定」を受ける前に契約・発注、支払い等を行った申請は補助金の交付を受けることができません、と記載されています（出典: IT導入補助金 事業完了報告の手引き 令和元年度 https://www.it-hojo.jp/r01/doc/pdf/r1_completion_manual.pdf）。同じ趣旨は令和2年度の手引きにも引き継がれています（出典: IT導入補助金 事業完了報告の手引き 令和2年度 https://it-hojo.jp/r02/doc/pdf/r2_completion_manual.pdf）。

小規模事業者持続化補助金でも同様です。補助事業を開始できるのは交付決定通知書に記載の交付決定日からであり、交付決定日より前に発注、購入、契約等を実施したものは補助対象外になると案内されています（出典: 小規模事業者持続化補助金 災害支援枠 採択後の見積書等に関する案内 https://r6.jizokukahojokin.info/noto/doc/r6_saitakumitsumori_noto6.pdf）。

例外は制度と枠ごとに個別に定められます。例えば災害支援枠では、被災日以降の申込み、契約、発注、精算を遡って認める特例が示されていますが、写真や書類等による確認が可能であって適正と認められるものに限るという条件が付いています（出典: 同案内）。令和2年度のIT導入補助金では、特別枠に限り2021年1月8日以降の導入契約も対象となる記載がありました（出典: 前掲 令和2年度の手引き）。

こうした例外は、その枠と回に限って定められたものです。別の制度や別の回へそのまま当てはめることはできません。最新は公式サイトでご確認ください。

### 制作会社へ依頼しておく書類

報告で使う書類のうち、制作会社から受け取るものは発注時に伝えておきます。

| 受け取る書類 | 依頼する時期 |
| --- | --- |
| 内訳の分かる見積書 | 交付決定の前 (妥当性の証明に使う) |
| 発注書または契約書の控え | 交付決定日以降の日付で取り交わす |
| 納品書 | 納品時 |
| 請求書 | 納品後 |
| 公開した画面の記録 | 公開時 |

日付の整合が肝心です。見積は交付決定の前でよい一方、発注と契約の日付は交付決定日以降になります。

### 申請から報告までの流れと当社の支援範囲

全体の流れを番号で示します。

1. 申請する (目安: 準備に2週間から1か月)。計画と経費の区分を決めます。
2. 採択発表を受け、妥当性を証明できる見積書等を提出する (目安: 1週間)。つまずきやすい点は、助言の工数と制作の工数が1行にまとまった見積を出してしまうことです。
3. 交付決定通知書を受け取る (目安: 採択発表から1か月から2か月)。この日付が発注の起点です。
4. 発注し、制作し、公開する (目安: 案件により変動します)。つまずきやすい点は、公開が補助事業期間の末日に寄り、運用に至らないまま期間が終わることです。
5. 支払を済ませる (目安: 請求後)。ここで補助事業が終了します。
6. 実績報告書と関係書類等を提出する (目安: 終了日から30日以内と提出期限の早い方)。
7. 1年後に事業効果等状況報告を提出する (目安: 事務局の指定期限まで)。

当社がお手伝いできるのは、2番の見積の作り方、4番の制作と公開、そして6番と7番で御社が答えるための記録の残し方です。申請書の代行や採択の保証は行っていません。補助金の制度そのものの判断は、事務局と商工会および商工会議所にご確認ください。

対象になる補助金の整理は[補助金のご案内](/subsidy)にまとめています。発注の段取りから相談したい場合は[無料診断](/diagnostic)をご利用ください。

## よくあるご質問

この記事に関して多い質問と回答をまとめます。以下はいずれも小規模事業者持続化補助金 一般型 通常枠 第19回公募の公募要領 第6版の記載に基づきます（出典: https://www.jizokukanb.com/jizokuka_r6h/doc/kobo/r6_19/19_%E9%80%9A%E5%B8%B8%E6%9E%A0_%E5%85%AC%E5%8B%9F%E8%A6%81%E9%A0%98_%E7%AC%AC6%E7%89%88.pdf、2026年3月6日時点）。最新は公式サイトでご確認ください。

### ホームページ制作の補助金の実績報告には何を提出しますか

実績報告書 (交付規程様式第8) と、支出内容の分かる関係書類等です。公募要領はこの2種類を補助金事務局へ提出すると定めています（出典: 同要領、2026年3月6日時点）。

関係書類等の個別の一覧は、公募要領ではなく事務局が公開する補助事業の手引き側に置かれています。交付決定の後に案内されるため、そちらで確認してください。

### 実績報告の期限はいつですか

補助事業が終了した日から30日を経過した日と、公募要領の表に示された補助事業実績報告書提出期限の、いずれか早い日です。

終了の判定には補助対象経費の支払いまで含まれます。公開した日ではなく、支払が済んだ日が起点です。

### 補助金の証拠書類は何年保存すればよいですか

補助事業の終了日の属する年度の終了後5年間です。起算点が終了日そのものではないため、実際の保存期間は5年より長くなります。

閲覧を求める相手として、補助金事務局等、独立行政法人中小企業基盤整備機構、会計検査院が条文に挙がっています。

### 補助金で作ったホームページはリニューアルできますか

目的の遂行に必要な改良や機能強化であれば、事前承認申請等が必要な処分には該当しません。

ただし50万円 (税抜) 以上で作成または更新した場合は処分制限財産に当たり、通常は取得日から5年間、目的外での使用や譲渡、廃棄等が制限されることがあります。サイトを閉じる場合や別の用途へ使う場合は、自社で判断せず事務局へご確認ください。

### 実績報告を出し忘れた場合はどうなりますか

交付決定が取り消されます。公募要領は、定められた期日までに提出が補助金事務局で確認できなかった場合は交付決定を取り消すとしています（出典: 同要領、2026年3月6日時点）。

提出したかどうかではなく、事務局で確認できたかどうかが基準です。期限の直前の提出は避けてください。

なお、実績報告とは別に、補助事業終了から1年後の事業効果等状況報告もあります。こちらを提出していない事業者には、補助金申請に際して制限が課されます。
