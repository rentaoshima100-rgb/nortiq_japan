# お客様の声の掲載、同意の取り方と出す範囲

## まず決めるのは、同意を取る方法と残し方の2点です

最初にやることは、誰に何を許可してもらうかを1枚の依頼文にまとめ、同意を後から確認できる形 (書面かメール) で受け取ることです。お客様の声は原稿を書くことが本番ではなく、この2点が決まっていないまま進めると、公開の直前に掲載を見送る判断が必要になります。

顧客の氏名や社名を出す場合は、個人情報の第三者提供にあたるかどうかの確認が必要です。個人情報保護委員会「個人情報の保護に関する法律についてのガイドライン (通則編)」は、個人情報保護法第27条第1項を「個人情報取扱事業者は、次に掲げる場合を除くほか、あらかじめ本人の同意を得ないで、個人データを第三者に提供してはならない」と示しています。自社サイトへの掲載は誰からでも見える状態にすることなので、同意が要るかどうかは最初に確認する前提になります。

### 依頼文に入れる4項目 (掲載先、掲載する内容、出す範囲、取り下げの連絡先)

依頼文は次の順でまとめます。

1. **掲載先**を書きます。自社サイトのどのページに載せるか、URLまで示します。所要時間の目安は10分です。
2. **掲載する内容**を添付します。アンケートの回答やインタビューの原稿を、実際に載せる文面のまま見せます。つまずきやすい点は、要約や語尾の整えまで含めて最終の文面を見せることです。後から整えると再確認が必要になります。
3. **出す範囲**を選んでもらいます。業種と地域だけ、社名まで、担当者名まで、顔写真まで、のどこまでを許可するかを選択式にします。段階の決め方は後述します。
4. **取り下げの連絡先**を書きます。掲載をやめたいときの窓口と、申し出から取り下げまでの目安の日数を示します。

### 同意の受け取り方を書面かメールに寄せる理由

受け取り方は、電話や訪問での口頭ではなく、書面かメールに寄せることをおすすめします。理由は、掲載が数年続くためです。担当者が交代したあとに「許可した覚えがない」と言われた場合、口頭では何をどこまで許可してもらったのかを示せません。ガイドラインが同意を得ている事例として挙げている方法は複数あり、その中からどれを選ぶかは次のセクションで扱います。

## 同意の取り方は、ガイドラインが示す方法から選びます

個人情報保護委員会のガイドラインは同意を得ている事例を複数挙げており、そのうち後から確認できる方法を選ぶのが実務的です。どれか1つが正解というわけではないため、自社の顧客との連絡手段に合うものを選びます。

### ガイドラインが挙げる同意の方法

個人情報保護委員会「個人情報の保護に関する法律についてのガイドライン (通則編)」2-16は、同意を得ていると認められる事例として次の6通りを挙げています。あわせて、本人の同意とは、本人の個人情報が示された取扱方法で取り扱われることを承諾する旨の本人の意思表示であり、本人であることを確認できていることが前提になると説明しています。

| 方法 | 記録が残るか | 向いている場面 |
|---|---|---|
| 口頭による意思表示 | 残りません | 急ぎで確認を取る場面 |
| 書面 (電磁的記録を含む) の受領 | 残ります | 社名や顔写真まで出す場合 |
| メールの受信 | 残ります | 担当者とメールでやり取りしている場合 |
| 確認欄へのチェック | 残ります | アンケートと同時に取る場合 |
| ホームページ上のボタンのクリック | 残ります | 投稿フォームを設ける場合 |
| 音声入力やタッチパネルへのタッチ等による入力 | 仕組みによります | 店頭の端末で受け付ける場合 |

### 口頭だけで済ませた場合に起きること

口頭も事例に挙げられている方法ですが、後から内容を示せません。つまずきやすい点は、許可の有無ではなく範囲の記憶が食い違うことです。社名までの許可だったのか担当者名まで含めたのか、言った側と聞いた側で違う記憶になると、掲載を取り下げる以外の選択肢が残りません。

### 取り下げの申し出に応じる手順を先に決める

同意を取る時点で、取り下げの手順も決めておきます。

1. 窓口を1つに決めます。所要時間の目安は5分です。
2. 申し出から公開停止までの目安の日数を社内で決めます。つまずきやすい点は、サイトの更新を外注している場合に自社だけでは止められないことです。更新の依頼から反映までの日数を含めて決めます。
3. 取り下げた内容の控えを、同意の記録とあわせて保管します。

## 社名・担当者名・顔写真は、出す範囲を段階で決めます

出す範囲は、業種と地域だけ、社名まで、担当者名まで、顔写真まで、の4段階で考え、同意が取れた段階までを載せます。最初から顔写真まで求めると断られて1件も載らないため、段階を下げた案を同時に示すのが実務的です。

### 段階ごとの依頼のしやすさとつまずきやすい点

| 段階 | 掲載の例 | つまずきやすい点 |
|---|---|---|
| 業種と地域だけ | 「県内の製造業A社様」 | 読者から実在性を疑われやすく、他社の事例と区別もつきません |
| 社名まで | 「株式会社○○様」 | 先方の広報や法務の確認が必要になる場合があります |
| 担当者名まで | 「株式会社○○ 総務部 ○○様」 | 担当者の交代後に本人から取り下げを求められることがあります |
| 顔写真まで | 担当者の写真を添える | 撮影の日程調整が必要で、提供までに日数がかかります |

### B2Bで社名を出す場合に先方の広報確認が必要になること

相手が法人の場合、やり取りしている担当者の同意だけでは足りないことがあります。社名の露出は先方の広報の管轄で、取引先の事例として名前が出ることを社内規程で制限している会社もあります。依頼文は担当者が社内で回せる形にしておき、確認の時間を2週間ほど見ておくと進行が止まりません。

### 写真を使う場合に合わせて確認すること

顔写真を載せる場合は、次の3点を同じ依頼文で確認します。

1. 写真そのものの提供元を確認します。先方から受け取るのか自社で撮影するのかを決めます。所要時間の目安は10分です。
2. 使う範囲を確認します。自社サイトだけか、会社案内やSNSにも使うかを分けて許可をもらいます。つまずきやすい点は、サイト用の許可だけで印刷物にも使ってしまうことです。
3. 保管と削除の扱いを決めます。取り下げの申し出があったときに元データも消すのかを、先に決めておきます。

なお、肖像権については日本の法律に明文の規定を確認できていません。顔写真の掲載は、本人の同意を書面やメールで残すという実務上の手当てで備えることになります。

## 謝礼や割引を渡す場合は、広告だと分かる表示が必要です

謝礼や割引と引き換えに声を書いてもらう場合は、それが分かる表示を入れないと景品表示法のステルスマーケティング規制に触れる可能性があります。何も渡していない場合と、渡した場合で扱いが変わるため、依頼の時点で分けて考えます。

### 規制の対象になるのは掲載する自社の側であること

消費者庁「ステルスマーケティングは景品表示法違反です」によると、この規制は令和5年10月1日に施行されました。同庁は規制の対象となる表示を、広告であるにもかかわらず消費者から見て広告だと判別しにくい表示と説明しており、事業者が第三者に依頼・指示した広告も対象に含まれます。SNSやレビューの投稿も対象です。

重要なのは、規制の対象になるのが商品やサービスを供給する事業者 (広告主) のみで、依頼を受けた第三者は対象にならない点です。お客様に書いてもらった文章であっても、掲載について責任を問われるのは掲載する自社の側になります。

### 対象外とされているものとの線引き

同庁は、個人の感想にあたるものや、広告であることが明らかなものは対象外としています。実務上の線引きは、自社が表示の内容に関与したかどうかに寄ります。

| 依頼の仕方 | 表示の要否 |
|---|---|
| 何も渡さず、文面にも手を入れずに掲載する | 表示は不要と考えられます |
| 割引やクーポン、無料提供品と引き換えに書いてもらう | 渡したことが分かる表示を入れます |
| 自社で文案を用意し、それに沿って書いてもらう | 自社の表示として扱われる前提で考えます |

### 表示の入れ方と、文面の修正をどこまでしてよいか

表示は、声の近くに読み飛ばせない形で置きます。ページの最下部にまとめて書くと、どの声に対する表示なのか分かりません。

文面の修正は、誤字の訂正と、個人や取引先が特定される記述の削除までに留めます。つまずきやすい点は、読みやすさのために言い回しを強めてしまうことです。書いていないことを足した時点で自社の表示になります。修正した場合は、修正後の文面で改めて本人に確認を取ります。所要時間の目安は1件あたり15分です。

## 星の評価を検索結果に出したい場合は、先に制約を確認します

自社に関するレビューを自社サイトに載せる場合、Googleのレビュースニペットの対象にならないため、星の評価を狙う前提で設計しないことが先決です。制作会社から星を出す提案を受けた場合も、この点を先に確認します。

### 自社ページでのLocalBusiness・Organizationの扱い

Google検索セントラル「レビュースニペット (Review, AggregateRating) の構造化データ」には、評価対象の事業者がレビューを管理している場合、その事業者のページで LocalBusiness や Organization の構造化データを使ってもレビューの星評価の表示対象にならないと記載されています。Googleビジネスプロフィールや外部のレビューウィジェットを埋め込む場合も同様とされています。

同ドキュメントは、これらのレビューマークアップは他の地域のビジネスや組織へのレビューを集めるサイトに限られると明記しています。自社サイトに自社の評価を載せる形は、はじめから対象外という整理です。

### 他サイトのレビューを集めて載せてはいけないこと

同ドキュメントでは、他のウェブサイトのレビューや評価を集約して掲載することも禁止されています。評価は利用者から直接得たものである必要があり、編集者が作成、選別、編集してはならないとされています。あわせて、実際の体験に基づかないレビューや、金銭、割引、クーポン、無料提供品などの見返りを受けて書かれたレビューで、その旨を明確かつ目立つ形で開示していないものは、ページにもマークアップにも含めてはならないとしています。違反した場合は手動による対策の対象となり、構造化データが無視される可能性があると記載されています。

実装者視点でつまずきやすいのは、レビュー収集サービスのタグを貼るだけで星が出ると説明される場面です。構造化データが通るかどうかではなく、自社のページで自社の評価を扱っているという関係のほうが先に効きます。

### 構造化データを使わずに読者へ伝える作り

星が出ない前提で、読者が判断できる形にします。

1. 声の冒頭に、業種、規模、依頼した内容を1行で添えます。所要時間の目安は1件あたり5分です。
2. 導入の前に困っていたことと、導入後に変わったことを分けて書きます。つまずきやすい点は、変わったことだけを並べると他社の事例と区別がつかなくなることです。
3. 掲載した日付を入れます。いつの時点の声かが分かると、読者が自分で判断できます。

## 外注している場合は、分担と渡すデータを見積もり前に決めます

原稿の作成、写真の手配、同意の取得のうち誰が何をやるかを見積もり前に決めておくと、公開直前の差し戻しを防げます。お客様の声は、制作会社が自力で用意できない唯一のコンテンツなので、分担が曖昧なまま進むと最後に残ります。

### 制作会社に渡すもの、自社で持つもの

分担は、文章を書く作業の分担ではなく、情報を出す責任の分担として決めるほうが実務に合います。Googleの「有用で信頼性が高い、ユーザファーストのコンテンツの作成」は、自己評価の質問として「コンテンツは、独自の情報、レポート、研究、分析を提供していますか。」「コンテンツの著者が誰であるかを明確にしていますか。」を挙げています。自社の顧客とのやり取りは、制作会社が調べて書けるものではありません。

| 項目 | 持ち手 |
|---|---|
| 顧客への依頼と同意の取得 | 自社 |
| 同意の記録の保管 | 自社 |
| 原稿の体裁の整えと誤字の訂正 | 制作会社 |
| 掲載ページの作成と更新 | 制作会社 |
| 取り下げの依頼の受付 | 自社 |

補助金を使う場合は費目も関わります。小規模事業者持続化補助金の公募要領 (一般型通常枠 第19回公募) は、ウェブサイト関連費を補助金総額の4分の1 (最大50万円) を上限とし、ウェブサイト関連費のみでの申請はできないと明記しています。写真撮影や原稿の作成をどの費目で扱うかを含めて、申請の構成を先に決める必要があります。

### 写真の撮影を外注する場合に決める項目

1. 撮影の場所と立ち会いを決めます。顧客の事務所で撮る場合は、先方の入館手続きが必要かを確認します。所要時間の目安は30分です。
2. 撮影した写真の確認の手順を決めます。つまずきやすい点は、顧客が写真を見て掲載を取りやめる場合があることです。先方が1枚を選ぶ形にしておくと止まりません。
3. 元データの保管場所と削除の扱いを決めます。制作会社側に残るのか自社に引き渡すのかを契約で決めます。

### 公開後に取り下げの依頼が来たときの運用

受付は自社で、停止の作業は制作会社という分担になるため、連絡の経路を1本に決めておきます。保守契約に、急ぎの更新を何営業日で行うかが書かれているかを確認します。書かれていない場合は、取り下げの依頼に限って別の目安を取り決めておくほうが安全です。

## 掲載前の確認リスト

公開前に、同意の記録、出す範囲、謝礼の有無の表示、原文の改変の有無の4点を照合します。1件でも欠けていれば、その声だけを外して公開します。全件が揃うまで公開を止めると、いつまでも載りません。

### 確認の順番

次の順で確認します。前の項目が未了のまま先に進むと、やり直しになります。

1. **同意の記録があるか**を確認します。書面かメールの控えを、声の1件ごとに紐づけます。所要時間の目安は1件あたり5分です。
2. **出す範囲が記録と一致しているか**を確認します。つまずきやすい点は、社名までの許可なのに担当者名が原稿に残っている場合です。原稿側ではなく記録側を基準に合わせます。
3. **謝礼や割引を渡したかどうか**を確認します。渡した場合は、その旨の表示が声の近くに入っているかを見ます。
4. **原文に手を入れていないか**を確認します。誤字の訂正と特定される記述の削除を超えた修正がある場合は、修正後の文面で本人の確認が取れているかを見ます。
5. **掲載日を入れているか**を確認します。あわせて、取り下げの窓口が社内で共有されているかも見ます。

### 1件ずつ記録を残す形にしておく

記録は、声の件数と同じ数だけ作ります。表計算ファイル1枚で足ります。列は、顧客名、同意を受け取った日、受け取った方法、許可した範囲、謝礼の有無、掲載日、取り下げの有無の7つです。

この形にしておく利点は2つあります。1つは、担当者が交代しても範囲が引き継げることです。もう1つは、サイトのリニューアルで声を移す際に、改めて同意を取り直す必要があるかどうかを件ごとに判断できることです。掲載先が変わる場合は、依頼文に書いた掲載先と一致しなくなるため、移す前に確認します。

## よくあるご質問

この記事に関して多い質問と回答をまとめます。

### お客様の声を載せるとき、本人の同意は口頭でもよいのですか

個人情報保護委員会「個人情報の保護に関する法律についてのガイドライン (通則編)」2-16は、同意を得ている事例として口頭による意思表示も挙げています。したがって口頭が認められないわけではありません。ただし、掲載は数年続くため、許可した範囲が後から確認できないという問題が残ります。書面かメールで受け取ることをおすすめします。

### 社名を出さずに「製造業A社様」とだけ書く場合も同意は必要ですか

特定の個人や会社が分からない書き方であれば、個人データの第三者提供には当たらないと考えられます。ただし、同意とは別に、掲載すること自体を伝えておくほうが安全です。業種と地域の組み合わせや、取引の内容から相手が分かってしまう場合もあるため、「どう書くか」を先方に見せて確認する手順は変わりません。

### アンケートの回答をそのまま掲載する場合、改めて同意を取る必要はありますか

アンケートを取った時点で掲載についての同意を得ていない場合は、改めて確認します。回答の用紙やフォームに、自社サイトへの掲載に使うことと、どこまでを出すかが書かれていれば、その範囲で掲載できます。書かれていない場合は、回答を集める目的と掲載は別のものとして扱います。次回からは、アンケートの中に掲載の可否と出す範囲の選択欄を入れておくと、やり取りが1往復で済みます。

### 謝礼として割引券を渡した場合、何と書けばよいのですか

渡したことが分かる表示を、その声の近くに置きます。消費者庁が示す規制は、広告であるにもかかわらず消費者から見て広告だと判別しにくい表示を対象としているため、読み飛ばせない位置に置くことが要点になります。文言は難しく考える必要はなく、謝礼を受け取って書かれたものである旨が伝わればよく、ページの最下部にまとめて書く形は避けます。

### 掲載後に取り下げてほしいと言われたら、応じる義務はありますか

同意に基づいて掲載している以上、その同意が撤回された場合は掲載を続ける根拠が弱くなります。実務としては、申し出があれば速やかに外す運用にしておくのが確実です。サイトの更新を外注している場合は自社だけでは止められないため、保守契約で急ぎの更新にかかる日数を確認しておきます。
