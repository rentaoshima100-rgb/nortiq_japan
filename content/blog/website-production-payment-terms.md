# ホームページ制作費の支払条件｜着手金と支払期日の決め方

## ホームページ制作費の支払条件は何から決める？

最初に決めるのは着手金の割合ではありません。代金の支払期日です。期日には法令上の上限があり、そこから逆算すると分割の回数と時期が自然に決まります。

支払条件とは、代金をいつ、いくつに分けて、どの手段で払うかの取り決めです。見積書には総額と項目しか書かれていないことが多く、支払条件は契約書か発注書で初めて姿を現します。

### 決める順番は、支払期日、分割の回数、支払手段

次の順で決めると、後から戻る手戻りが起きません。

1. 支払期日を決める（所要時間の目安: 30分）。自社が中小受託取引適正化法（取適法）の対象かを確認し、対象なら上限の範囲で期日を置きます。取適法は、下請代金支払遅延等防止法が改正されたもので、2026年1月1日に施行されました（出典: 中小企業庁 ミラサポplus「【2026年1月1日施行】受注者を守る法！手形払い禁止など『取適法』がもたらす変化」）。
2. 分割の回数と区切りを決める（所要時間の目安: 制作会社との打ち合わせ1回）。つまずきやすい点は、区切りを工程名ではなく成果物で書くことです。「デザイン完了時」ではなく「トップページのデザイン確定時」と書きます。
3. 支払手段を決める（所要時間の目安: 15分）。振込か現金か、振込手数料をどちらが負担するかまで決めます。

期日が先に決まっていれば、最終回の支払をいつ置けるかが定まります。そこから逆算して、着手金と中間金の位置が決まります。

### 見積書に書かれていない項目こそ先に確認する

見積書で確認が漏れやすいのは、金額ではなく条件の側です。発注前に次の4点を制作会社へ確認してください。

| 確認する項目 | 見積書に書かれていないときの確認の仕方 |
| --- | --- |
| 支払期日の起点 | 納品日か、検収完了日か、請求書発行日かを聞く |
| 分割の回数と各回の金額 | 着手金の有無と、残金の請求タイミングを聞く |
| 支払手段 | 銀行振込以外を求められるかを聞く |
| 振込手数料の負担 | どちらが負担する前提の金額かを聞く |

つまずきやすいのは支払期日の起点です。取適法の対象となる取引では、給付を受領した日などから60日以内のできる限り短い期間に支払期日を定める必要があります（出典: 中小受託取引適正化法の概要 説明資料）。社内の検収が終わってから数え始める運用にすると、この上限を超えることがあります。起点の数え方は後述します。

補助金を使う予定がある場合は、支払手段の自由度がさらに下がります。小規模事業者持続化補助金では現金払いが認められるのは税抜10万円以下の支払いに限られます（出典: 小規模事業者持続化補助金 実績報告の手引き）。着手金の払い方を決める前に、この制約を先に確認しておくと安全です。

## 支払期日はいつまで？取適法の60日ルール

取適法の対象となる取引では、給付を受領した日などから60日以内のできる限り短い期間に支払期日を定める必要があります。委託した側は、その期日までに代金を支払う義務を負います（出典: 中小受託取引適正化法の概要 説明資料）。

取適法とは、下請代金支払遅延等防止法が改正されたもので、正式には中小受託取引適正化法といいます。2026年1月1日に施行されました（出典: 中小企業庁 ミラサポplus「【2026年1月1日施行】受注者を守る法！手形払い禁止など『取適法』がもたらす変化」）。

この60日は上限です。上限いっぱいに置いてよいという意味ではありません。条文は「できる限り短い期間」と定めています。

### 起点は受領した日で、社内の検収完了日ではない

期日の起点は、給付を受領した日などです。社内の検収が終わった日ではありません。ここを取り違えると、上限を超えた支払条件になります。

ホームページ制作で起きやすいのは、次のような流れです。

1. 制作会社がサイトを納品する（この日が受領日になります）。
2. 社内で各部署に見てもらい、修正の要望を集める（つまずきやすい点: ここで1か月以上かかることがあります）。
3. 検収書に押印し、そこから「月末締め翌月末払い」を適用する。

3の運用だと、受領日から数えて60日を超える場合があります。検収に時間がかかる社内事情は、起点を後ろにずらす理由になりません。

対策は単純です。検収にかける日数を契約書で定め、その日数を織り込んで支払期日を書きます。たとえば「納品後14日以内に検収、検収完了月の翌月末払い」と書けば、受領日からの日数が読めるようになります。

### 自社が対象になるかは資本金と取引内容で決まる

取適法が適用されるかどうかは、取引の内容と、発注側と受注側の資本金の区分の両方で決まります。自社が小規模であれば、対象にならないこともあります。

| 確認する点 | 見るところ |
| --- | --- |
| 取引の内容 | ホームページ制作がどの委託類型にあたるかを確認する |
| 資本金の区分 | 自社と制作会社それぞれの資本金額を確認する |
| 適用の有無 | 両方を満たすときに取適法の義務が発生する |

対象外であっても、60日を一つの目安にしておく実務上の利点があります。期日が遠いほど制作会社の資金繰りに負荷がかかり、小規模な制作会社では進行に影響します。経済産業省も、下請代金の支払についてサイトを60日以内に短縮し、できる限り現金で支払うよう関係事業者団体へ要請しています（出典: 経済産業省 報道発表「下請代金の支払手段についての要請」）。

なお、適用の有無を自社で判断しきれない場合は、契約の前に顧問の士業へ確認してください。支払手段の制限については次のセクションで扱います。

## 手形や相殺で払ってよい？支払手段の制限

2026年1月1日施行の取適法では、支払手段としての手形払いが禁止されました。振込手数料を制作会社に負担させることもできません（出典: 中小企業庁 ミラサポplus「【2026年1月1日施行】受注者を守る法！手形払い禁止など『取適法』がもたらす変化」）。

ホームページ制作の代金で手形を使う例は多くありません。ただ、取引全般の支払条件をそのまま制作会社にも適用している企業では、見直しが必要になります。

### 電子記録債権やファクタリングも条件つきで使えない

手形の代わりに使われてきた手段にも制限がかかりました。禁止の対象は、支払期日までに代金の満額を受け取ることが困難なものです。

| 支払手段 | 取適法の対象取引での扱い |
| --- | --- |
| 銀行振込（全額） | 使えます |
| 手形 | 支払手段として禁止されています |
| 電子記録債権 | 期日までに手数料等を含む満額を受け取ることが困難なものは使えません |
| ファクタリング | 同上の条件で使えません |

判断の分かれ目は、割引料や手数料を引かれた結果、制作会社の手元に満額が残らないかどうかです。手形については、経済産業省が改正前から、サイトを60日以内に短縮し、できる限り現金で支払うよう関係事業者団体へ要請してきた経緯もあります（出典: 経済産業省 報道発表「下請代金の支払手段についての要請」）。

### 見積書の「振込手数料は貴社負担」は見直す

取適法では、振込手数料を受託側に負担させることが禁止されています。見積書や契約書に「振込手数料は貴社負担」と書く前提は、対象となる取引では置けません。

発注前に次の3点を確認してください。

1. 見積書の備考欄を読む（所要時間の目安: 5分）。振込手数料の負担者が書かれているかを見ます。
2. 自社の支払テンプレートを確認する（所要時間の目安: 15分）。つまずきやすい点は、経理の運用で手数料を差し引く設定が標準になっている場合です。制作会社との契約だけ例外にすると、振込の都度ミスが起きます。
3. 相殺の扱いを決める（所要時間の目安: 15分）。保守費の前受金や他案件の債権と相殺する運用は、満額が渡らない形になりえます。契約書に相殺の条項があるかを読みます。

実装者の視点で付け加えると、公開作業の直前に支払手段で揉めると、公開日そのものが動きます。サーバやドメインの費用を制作会社が立て替えている場合、入金の遅れがそのまま契約更新の遅れになり、公開後にサイトが止まるという形で表面化します。手段の確認は、デザインの確認よりも早い段階で済ませておくのが安全です。

補助金を使う場合は、ここに加えて支払方法そのものが補助の要件になります。次のセクションで扱います。

## 着手金と残金はどう分ける？分割の決め方

割合の公的な相場はありません。公的統計や公式資料で確認できる数字が無いため、本記事では相場を示しません。着手金は制作会社が先に負担する費用に見合う額にとどめ、残金の支払時期を検収と結び付けて決めます。

考え方は単純です。着手金は、制作会社が自社のために先に支出するお金を立て替えてもらわないための金額です。デザインの作業量に対する前払いではありません。

### 分割の区切りは、着手、画面確認、公開の3点が実務的

区切りは工程名ではなく、誰が見ても判定できる成果物で決めます。次の3点が実務的です。

| 区切り | 判定できる事実 | 支払の位置づけ |
| --- | --- | --- |
| 着手 | 契約書の締結と、制作会社が外部に支払う費用の発生 | サーバ、ドメイン、素材の購入費など立て替え分 |
| 画面確認 | トップページと主要な下層ページのデザイン確定 | 中間金 |
| 公開 | 本番サーバでの公開と、検収の完了 | 残金 |

区切りを決める手順は次のとおりです。

1. 制作会社が外部へ支払う費用を見積書から拾う（所要時間の目安: 15分）。サーバ、ドメイン、有料素材、有料プラグインが該当します。
2. その合計額を着手金の下限とする（所要時間の目安: 15分）。つまずきやすい点は、立て替え費用がゼロに近い案件でも慣習で3割を払ってしまうことです。
3. 残金の支払時期を検収の完了と結び付ける（所要時間の目安: 制作会社との打ち合わせ1回）。検収にかける日数も同時に決めます。

### 長期の案件では中間金を置いて双方の持ち出しを抑える

制作期間が3か月を超える案件では、中間金を置きます。置かない場合、制作会社は人件費を数か月分立て替えることになり、進行が鈍ります。

中間金の区切りは、デザインの確定が適しています。この時点で制作会社の作業量の多くが確定し、発注側もでき上がりを目で確認できるためです。

### 実装者の視点: 公開後の修正分を残金に含めると揉めやすい

公開後の修正を残金の条件に含める契約は、支払が止まりやすくなります。修正の範囲が文章で定義されていないためです。

当社の実装経験では、公開後に出てくる要望は次の3つが混在します。

1. 不具合の修正（表示崩れ、リンク切れ、フォームの不達）。
2. 公開前に決めた仕様どおりに直っていない箇所。
3. 公開してから出てきた新しい要望。

1と2は制作会社が直すべきものです。3は追加費用の対象になります。残金の支払条件に「修正完了後」とだけ書くと、3が終わるまで払えないという解釈が成り立ってしまいます。

避け方は、残金の条件を「検収の完了」に限定し、公開後の修正は別枠の保守契約か、追加見積もりとして切り離すことです。書き方は後のセクションで扱います。

## 補助金を使うときの支払方法の注意点は？

補助金を使う場合、支払は銀行振込が原則です。小規模事業者持続化補助金では、10万円（税抜）を超える支払いを現金で行うと、一括か分割かを問わず補助対象外になります（出典: 小規模事業者持続化補助金 一般型 通常枠 ガイドブック 第2版）。着手金を現金で渡す決め方にすると、その分が対象から外れます。

もう一つの落とし穴が、払う時期です。交付決定より前の契約と発注は、支払だけでなく契約の段階で対象外になります。

### 証拠書類として残す振込記録の種類

振込の事実を後から証明できる書類を残します。同ガイドブックでは、ウェブサイト関連費について、補助金総額の1／4（最大50万円）を上限とし、ウェブサイト関連費のみによる申請はできないとされています。上限の範囲内であっても、支払の証拠が揃わなければ精算できません。

| 支払方法 | 補助金での扱い | 残す書類 |
| --- | --- | --- |
| 銀行振込 | 原則の方法です | 振込金受取書、通帳の該当ページ、ネットバンキングの振込記録 |
| 現金（10万円以下、税抜） | 認められる範囲があります | レシート、領収書 |
| 現金（10万円超、税抜） | 補助対象外です | 対象外のため残しても精算できません |

見積もりの要件も制度で分かれます。小規模事業者持続化補助金では、100万円（税込）を超える支払いに2者以上の見積が必要です。中古品の購入（50万円（税抜）未満のもの）は、金額に関わらず2者以上からの見積が必須とされています。

一方、デジタル化・AI導入補助金2026（通常枠）は、ITツールをIT導入支援事業者があらかじめ登録する仕組みで、手続きが異なります。通常枠の補助額は1プロセス以上で5万円から150万円未満、4プロセス以上で150万円から450万円以下、補助率は1／2以内です。条件を満たす場合は2／3以内となり、その条件には対象となる従業員が全従業員の30%以上である月が3か月以上あることが含まれます（出典: デジタル化・AI導入補助金2026 公募要領（通常枠）第7回公募以降）。

### 支払うタイミングは交付決定の前か後か

契約と発注は、交付決定の通知を受けてからが原則です。IT導入補助金の事業完了報告の手引きには、交付決定を受ける前に契約、発注、支払い等を行った申請は補助金の交付を受けることができないと記載されています（出典: IT導入補助金 事業完了報告の手引き 令和元年度）。

小規模事業者持続化補助金でも、補助事業を開始できるのは交付決定通知書に記載の交付決定日からです（出典: 小規模事業者持続化補助金 災害支援枠 採択後の見積書等に関する案内）。

進め方は次のとおりです。

1. 見積もりの取得と制作会社との相談を行う（所要時間の目安: 2週間）。ここまでは申請前に進められます。
2. 申請し、交付決定の通知を待つ（つまずきやすい点: 制作会社に「先に着手してほしい」と伝えてしまうことです。着手の事実が残ると対象外の判断につながります）。
3. 交付決定後に契約を締結し、着手金を振込で支払う（所要時間の目安: 通知から1週間）。

例外は制度と枠ごとに個別です。事業再構築補助金の事前着手制度は、第11回公募まで実施した後に原則廃止され、経過措置の対象者に限る扱いが示されています（出典: 事業再構築補助金 事前着手制度について）。自治体の補助金には事前着手の仕組みを持つものもあります。使う制度と回の公募要領で確認してください。

## 契約書と発注書に支払条件をどう書く？

支払期日、支払手段、分割の区切りと各回の金額、振込手数料の負担者の4点を、発注の前に書面で揃えます。口頭で合意した内容は、担当者が変わった時点で消えます。

書面は契約書と発注書のどちらでも構いません。両方を使う場合は、金額と期日をどちらに書くかを先に決めます。二重に書くと、食い違ったときにどちらが優先するかで揉めます。

### 検収の定義を書かないと支払期日が動く

支払期日は検収に引きずられます。検収の定義が無い契約書では、いつまでも検収が終わらず、残金の支払時期が決まりません。

書き込む項目は次の4つです。

1. 検収の対象（所要時間の目安: 制作会社との確認1回）。どの成果物を見て判定するかを書きます。
2. 検収の期間（所要時間の目安: 社内調整1回）。「納品後14日以内」のように日数で書きます。
3. 検収完了とみなす条件（つまずきやすい点: 発注側が何も回答しないまま日数が過ぎた場合の扱いを書き忘れることです。「期間内に書面での指摘が無い場合は検収完了とみなす」と書いておきます）。
4. 不合格のときの手順（所要時間の目安: 15分）。再納品の期限と、再検収の期間を書きます。

### 追加費用が出たときの支払時期も先に決める

追加費用は、発生してから支払条件を決めると揉めます。契約書に、追加分の扱いを先に書いておきます。

| 書く項目 | 書き方の例 |
| --- | --- |
| 追加の合意方法 | 書面またはメールで、作業内容と金額に双方が合意した時点で発注とする |
| 追加分の支払時期 | 本体の残金と同じ回にまとめる、または追加分のみ別途請求とする |
| 支払期日 | 本体と同じ起点、同じ日数を適用する |

実装者の視点で補足します。追加費用を本体の残金にまとめる書き方は、支払を一度で済ませられる反面、追加分の金額に納得できないときに本体の残金まで止まります。金額が大きい追加が見込まれる案件では、分けて請求する形にしておくほうが安全です。

発注前のチェックは次の4点で足ります。

1. 支払期日とその起点が書かれているか。
2. 支払手段と、振込手数料の負担者が書かれているか。
3. 分割の区切りと、各回の金額が書かれているか。
4. 検収の期間と、完了とみなす条件が書かれているか。

### 支払条件の書き方に迷ったときは

支払条件の設計は、制作会社の規模や制作期間によって妥当な形が変わります。立て替え費用の少ない小規模な案件で3割の着手金を求められた、検収の定義が白紙のまま契約書が送られてきた、といった場面では、見積書の読み方から相談できる相手がいると判断が早くなります。

当社はWeb制作を300,000円から承っており、契約書と支払条件の設計もあわせてご相談いただけます。発注前の段階で、いまの見積書と契約書案に抜けが無いかを確認したい場合は、[無料診断](/diagnostic)をご利用ください。補助金を使う前提で進めたい場合は、[補助金のご案内](/subsidy)もあわせてご確認いただけます。

## よくあるご質問

この記事に関して多い質問と回答をまとめます。

### ホームページ制作の着手金は何割が普通ですか。

公的な統計や公式資料で確認できる相場はありません。割合から決めるのではなく、制作会社がサーバ、ドメイン、有料素材など外部へ先に支払う費用を見積書から拾い、その金額を着手金の下限として交渉する進め方をおすすめします。

### 着手金を払った後に制作が止まった場合、返金してもらえますか。

契約書の定め方によります。中止した時点までの作業に対していくら精算するかを、契約書に書いていなければ争いになります。発注前に、中止したときの精算方法と、そこまでの成果物の扱いを書面で決めておいてください。

### 支払期日の60日は、検収が終わった日から数えるのですか。

いいえ。取適法の対象となる取引では、起点は給付を受領した日などであり、社内の検収が終わった日ではありません（出典: 中小受託取引適正化法の概要 説明資料）。検収に時間がかかると上限を超えるため、検収にかける日数を契約書で先に決めておきます。

### 制作費を手形や分割払いにしてもらうことはできますか。

分割は当事者で決められます。手形は別です。2026年1月1日施行の取適法では、対象となる取引で支払手段としての手形払いが禁止されました（出典: 中小企業庁 ミラサポplus）。電子記録債権やファクタリングも、期日までに手数料等を含む満額を受け取ることが困難なものは使えません。

### 振込手数料はどちらが負担するのが正しいですか。

取適法の対象となる取引では、振込手数料を制作会社に負担させることが禁止されています。見積書や契約書に「振込手数料は貴社負担」と書く前提は置けません。自社の経理で手数料を差し引く運用が標準になっている場合は、設定の見直しが必要です。

### 補助金を使うとき、着手金を現金で払ってもよいですか。

金額によります。小規模事業者持続化補助金では、10万円（税抜）を超える支払いを現金で行うと、一括か分割かを問わず補助対象外です（出典: 小規模事業者持続化補助金 一般型 通常枠 ガイドブック 第2版）。銀行振込に揃え、振込金受取書や通帳の該当ページを残してください。
