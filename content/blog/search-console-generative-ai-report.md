# Search Consoleの生成AIレポートの見方と限界

## 生成AIパフォーマンスレポートとは？ どこで見られますか

生成AIパフォーマンスレポートとは、AIによる概要とAIモードで自社のページが表示された回数を確認できるレポートです。Search Consoleの検索パフォーマンスの画面から開きます。

AI検索に自社が出ているかどうかを、推測ではなくGoogle自身の数字で確認できます。これが従来との一番の違いです。

### 対象は「AIによる概要」と「AIモード」です

Search Consoleヘルプ「生成AIパフォーマンスレポート（検索）」には、対象となる生成AI機能が明記されています。対象は「AIによる概要」と「AIモード」の2つです。

出典: Search Consoleヘルプ「生成AIパフォーマンスレポート（検索）」。

2つの違いを整理します。

| 機能 | どこに出るか |
| --- | --- |
| AIによる概要 | 通常の検索結果の上部に出る要約 |
| AIモード | 対話形式で検索するモードの回答 |

ChatGPTなど他社のAIサービスでの引用は、このレポートの対象外です。あくまでGoogle検索の中の生成AI機能に限られます。

### 自社の画面に出ていない場合

同ヘルプによれば、このレポートは2026年8月31日付けで世界中のすべてのウェブサイトにリリースされました。それ以前は、提供されるサイトが限られていました。

出典: Search Consoleヘルプ「生成AIパフォーマンスレポート（検索）」（2026年8月31日に全サイトへリリース）。

つまり、今は御社の管理画面にも出ているはずです。見当たらない場合は、次の順で確認してください。

1. Search Consoleの「検索パフォーマンス」を開く
2. その中の「生成AI」のメニューを探す
3. プロパティを切り替えて、対象のサイトを見ているか確かめる
4. 表示はされているが数値が0という状態ではないかを確認する

つまずきやすい点は、4つ目です。メニューが出ていないのではなく、表示回数が0で空に見えているだけの場合があります。期間を90日などに広げて確かめてください。

なお、このレポートが遡れるデータの開始日は、ヘルプ上で確認できませんでした。過去にさかのぼって長期の推移を見る用途には、現時点では向きません。

何が見えて何が見えないのかは、次から順に整理します。

## このレポートで何が分かりますか？

分かるのはインプレッション数とその内訳です。時系列の推移に加えて、ページ、国、日付、デバイスの4つの切り口で分解できます。

インプレッションとは、ここでは自社のページがAIの回答の参照元として示された回数を指します。訪問者の数ではありません。

### 確認できる指標と4つのディメンション

Search Consoleヘルプによれば、確認できるのは次の内容です。

- オーガニックインプレッション数の推移を時系列で確認できる
- インプレッション数が最も高い、または最も低いページを確認できる
- デバイスや国などの発生元情報を確認できる

分解できるディメンションは4種類です。

| ディメンション | 見え方 |
| --- | --- |
| ページ | どのURLが表示されたか |
| 国 | どの国からの検索か |
| 日付 | いつ表示されたか |
| デバイス | パソコンか、スマートフォンか |

出典: Search Consoleヘルプ「生成AIパフォーマンスレポート（検索）」。

中小企業のサイトで実際に使うのは、ページと日付の2つがほとんどです。国とデバイスは、海外向けの事業や、スマートフォン中心の業種でなければ出番が少なくなります。

### 表示回数が多いページから読み取れること

ページ別の一覧は、このレポートで最も使える部分です。読み取れるのは次の3点です。

1. AIが参照元として選んでいるページの傾向
2. 通常の検索で上位のページと、AIに選ばれるページのずれ
3. 力を入れたのに一度も表示されていないページ

2つ目が特に有用です。通常の検索で上位なのにAIに選ばれていないページは、内容ではなく書き方に原因がある場合があります。

実装する側から見ると、そうしたページは定義の文が無いことが多いという印象があります。「〇〇とは、〜です」という一文が本文の早い位置に無いページです。ただし、これは相関の観察にとどまります。Googleが選定の基準を公表しているわけではありません。

なお、表示回数の絶対値は業種によって大きく変わります。他社と比べる用途には使えません。読み方は後述します。

## 分からないことは何ですか？

クエリ、クリック数、CTRは含まれていません。どのページが表示されたかは分かっても、そこから読まれたかどうかは、このレポートだけでは追えません。

このレポートは2026年6月3日にSearch Consoleへ追加されました。出典: 海外SEO情報ブログ「Google、Search ConsoleにAI検索パフォーマンスレポートをリリース！」。

### 含まれていない指標

確認できる項目は5つです。インプレッションという指標が1つと、ページ、国、デバイス、日付という4つの切り口です。クリック、CTR、検索クエリには対応していません。

出典: 海外SEO情報ブログ「Google、Search ConsoleにAI検索パフォーマンスレポートをリリース！」。

| 項目 | このレポートで |
| --- | --- |
| インプレッション | 見られます |
| ページ、国、デバイス、日付 | 見られます |
| クリック数 | 見られません |
| CTR | 見られません |
| 検索クエリ | 見られません |

集計にも注意点があります。生成AI機能ぶんの数値は、従来の検索パフォーマンスレポートに含まれたまま合算されています。新設されたのは、そこから生成AI機能ぶんだけを抜き出して見るビューです。

つまり、従来の数値にこのレポートの数値を足してはいけません。二重に数えることになります。出典: 同解説。

ここは実務で誤りやすい点です。月次の報告資料で両方を並べて合算している例を見かけます。合計ではなく、内訳として扱ってください。

### なぜクリックが見えないことが問題になるのか

表示されたのに読まれていないのか、そもそも表示されていないのかを、このレポート単体では切り分けられないからです。

AIによる概要は、回答の中で答えを提示します。読者が満足すれば、参照元のリンクを踏みません。表示回数が伸びてもサイトへの訪問が増えない、という状態が起こりえます。

判断に必要なのは、次の2つの数字の組み合わせです。

1. 生成AI機能での表示回数（このレポート）
2. AIサービスからの実際の訪問数（アクセス解析側）

片方だけでは、打ち手が決まりません。表示が無いなら内容の作り方の問題で、表示はあるのに訪問が無いなら、リンクを踏ませる理由が本文に無いという問題です。

もう1つの限界は、検索クエリが見えないことです。どんな問いに対して選ばれたのかが分かりません。そのため、本文のどの部分が評価されたのかまでは推測に頼ることになります。

アクセス解析側との組み合わせ方は、次で整理します。

## 通常の検索パフォーマンスや解析ツールとどう使い分けますか？

表示はSearch Console、流入後の行動は解析ツールという分担になります。生成AIレポートで表示の有無を押さえ、参照元の記録で実際の訪問を確認します。

### 表示、訪問、成果の3層で分けて見ます

計測を3つの層に分けると、どのツールを見るべきかが決まります。

| 層 | 見るもの | どこで見るか |
| --- | --- | --- |
| 表示 | AIの回答に自社が出たか | Search Console 生成AIレポート |
| 訪問 | そこから実際に来たか | アクセス解析の参照元 |
| 成果 | 問い合わせにつながったか | アクセス解析のコンバージョン |

この3層は上から順に絞り込まれます。表示が0なら、下の2層を見る意味はありません。まず表示から確認してください。

Googleアナリティクス4では、AIサービスからの流入を参照元とメディアで判別します。ChatGPT経由はchatgpt.com / referral、Geminiはgemini.google.com / referral、Perplexityはperplexity.ai / referralとして記録されます。出典: LLMOナビの解説。

2026年6月には、デフォルトチャネルグループに「AI Assistant」が追加され、同月上旬からデータへの反映が確認されています。出典: 株式会社仁頼「GA4でAI検索の流入を計測する3つの設定【2026】」。

ただし限界もあります。定義に含まれない参照元はReferralやOrganic Searchに散らばります。また、追加以前のデータは遡って再分類されません。出典: 同解説。

なお、Googleアナリティクス4側の設定手順は、当サイトの「AI検索の流入を計測する方法｜GA4と参照元の確認」で扱っています。本記事ではSearch Console側の読み方に絞ります。

### 使い分けの一覧

先に確認しておきたい設定が1つあります。データ保持期間です。

Googleアナリティクス4のデータ保持期間は、既定で2か月です。無料版では14か月まで延長できます。出典: アドエビス「GA4のデータ保持期間を徹底解説！」。

既定のままにしておくと、2か月より前のデータが探索レポートから削除されます。AI検索の影響は年単位で見たい種類の変化です。最初に14か月へ変更しておいてください。

まとめると、使い分けは次のようになります。

1. 自社が出ているかを知りたい: Search Consoleの生成AIレポート
2. どのAIサービスから来たかを知りたい: アクセス解析の参照元
3. 通常の検索と比べたい: Search Consoleの検索パフォーマンス（合算値である点に注意）
4. 長期の推移を見たい: データ保持期間を延ばしたうえで、アクセス解析側で見る

つまずきやすい点は、4つ目です。保持期間の延長は、設定した時点より前のデータには効きません。気づいた時点で変更しても、過去は戻りません。

## 数字をどう読めば施策の判断に使えますか？

絶対値ではなく、自社の中での偏りを見ます。どのページが表示され、どのページが表示されていないのかという差が、次に手を入れる場所を示します。

他社の数値と比べる使い方はできません。業種によって母数が違いすぎるためです。

### 最初に見る3つの比較

見る順番を決めておくと、毎回の判断が早くなります。

1. 表示回数の多いページと少ないページの比較。同じテーマの記事の間で差が出ていないかを見ます
2. 通常の検索順位との比較。検索で上位なのに生成AIでの表示が無いページを探します
3. 期間どうしの比較。記事を直した前後で、表示回数が動いたかを見ます

2つ目で差が出たページが、最も手を入れる価値があります。内容は評価されているのに、AIが引用しにくい書き方になっている可能性があるためです。

ここで方向を誤らないための前提があります。Google検索セントラルの公式ドキュメント「AI Features and Your Website」は、検索の生成AI機能に表示されるために、新しい機械可読ファイルやAI向けのテキストファイル、専用のマークアップを作る必要はないと明記しています。特別なschema.orgの構造化データも必要ありません。

llms.txtについても、Googleは検索で利用しておらず、作成しても検索での可視性や順位に良い影響も悪い影響も与えないと説明しています。出典: Google検索セントラル「AI Features and Your Website」、および2026年5月のGoogle検索セントラルブログ。

つまり、表示が伸びない原因をファイルの不足に求めるのは的外れです。ツールがllms.txtの生成を主な機能として挙げている場合は、Google検索向けの効果とは切り分けて評価してください。

### 急いで結論を出さないほうがよい理由

1か月の増減で判断しないでください。理由は3つあります。

- クエリが見えないため、増減の原因を特定できません
- AI機能そのものの提供範囲が変化しています
- 遡れるデータの開始日がヘルプ上で確認できず、長期の比較の土台がまだ弱い状態です

最低でも3か月分をためてから、傾向として読んでください。

### 日本の生成AI利用率という前提

どこまで急ぐべきかは、利用の広がりから考えます。

総務省「令和7年版 情報通信白書」によれば、生成AIを使ったことがある個人の割合は日本で26.7パーセントです。米国は68.8パーセント、ドイツは59.2パーセント、中国は81.2パーセントでした。企業の利用率は55.2パーセントです。

一方、総務省が2026年7月に公表した令和8年版情報通信白書の概要では、自社の何らかの業務で生成AIを使っていると回答した日本企業の割合が86.4パーセントとされています。米国は90.9パーセント、ドイツは91.6パーセント、中国は98.1パーセントです。

この2つは調査年も設問の書き方も異なります。単純な比較はできませんが、企業側の利用が急速に広がったことは読み取れます。

御社にとっての意味は次のとおりです。BtoBで法人の担当者が読者なら、AI検索での見え方は今から測る価値があります。一方、個人の消費者が読者の事業であれば、通常の検索のほうが当面は主戦場です。出典: 総務省「令和7年版 情報通信白書」、総務省「令和8年版 情報通信白書（概要）」（2026年7月公表）。

## 毎月の確認手順

月に1回、15分ほどで終わる確認の型を決めておきます。数字を眺めるのではなく、翌月に手を入れるページを1つ決めるところまでを1回の作業とします。

### 5つの手順

1. Search Consoleの検索パフォーマンスから生成AIのレポートを開く（所要の目安: 1分）。期間は過去3か月に設定します
2. ページ別の一覧を、表示回数の多い順に並べる（所要の目安: 2分）。上位5件を記録しておきます
3. 同じ期間の通常の検索パフォーマンスを開き、順位の高いページと見比べる（所要の目安: 5分）。検索では上位なのに生成AIの一覧に無いページを探します
4. アクセス解析で、AIサービスからの参照元を確認する（所要の目安: 3分）。表示はあるのに訪問が無いのかを切り分けます
5. 翌月に手を入れるページを1つ決めて記録する（所要の目安: 4分）。つまずきやすい点は、候補を複数挙げてしまうことです。1つに絞らないと、変化の原因が分からなくなります

手順5が肝心です。同時に3ページを直すと、翌月に数字が動いても、どの修正が効いたのか判断できません。

### つまずきやすい点

運用を始めた方から多いご相談を、3つ挙げます。

| つまずく場面 | 対応 |
| --- | --- |
| 表示回数が0のまま動かない | 期間を90日に広げて確認します。それでも0なら、まず通常の検索での順位を上げる段階です |
| 先月と数字が合わない | 通常の検索パフォーマンスの数値と足していないかを確認します。合算済みのため二重計上になります |
| 直したのに変わらない | 反映には時間がかかります。3か月ためてから傾向として見てください |

実装する側の実感として、1つ目が最も多いご質問です。生成AIレポートは、通常の検索で見つけてもらえていないページを救う機能ではありません。まず検索で評価されていることが前提になります。

順位が伸びない原因がページの作り方にあるのか、そもそもの構成にあるのかは、サイトを見ないと分かりません。当社は代表自身が実装者として、Search Consoleの数値と本文の両方を突き合わせて原因をお伝えしています。自社サイトの現状を一度整理したい場合は、[無料診断](/diagnostic)をご利用ください。

## よくあるご質問

このレポートについて、実際に多いご質問をまとめます。

### 生成AIパフォーマンスレポートが自社のSearch Consoleに表示されません。なぜですか？

まず、プロパティの選択と期間の設定を確認してください。Search Consoleヘルプによれば、このレポートは2026年8月31日付けで世界中のすべてのウェブサイトにリリースされています。

そのため、提供の対象外という可能性は考えにくい状況です。メニューが見当たらない場合は、検索パフォーマンスの画面の中に「生成AI」の項目がないかを探してください。

表示はされているが数値が0で、空欄のように見えているだけという場合もあります。期間を90日に広げて確かめてください。

### AIによる概要に表示された回数は、通常の検索パフォーマンスの表示回数にも含まれていますか？

含まれています。生成AI機能ぶんの数値は、従来の検索パフォーマンスレポートに合算されたままです。

新設されたのは、そこから生成AI機能ぶんだけを抜き出して見るビューです。出典: 海外SEO情報ブログの解説。

したがって、2つの数値を足すと二重に数えることになります。報告資料では合計ではなく内訳として扱ってください。

### AI検索からの流入を、クリック数として把握する方法はありますか？

このレポートでは把握できません。クリック、CTR、検索クエリには対応していないためです。

訪問の実数は、アクセス解析側で参照元を見て確認します。Googleアナリティクス4では、ChatGPT経由はchatgpt.com / referral、Geminiはgemini.google.com / referralとして記録されます。

ただし、AIによる概要は検索結果の中に表示されるため、そこからの遷移は通常の検索と同じ扱いになります。AIによる概要だけのクリック数を切り出す方法は、現時点ではありません。

### AI機能に自社サイトを使わせない設定はできますか？

Google検索セントラルの公式ドキュメント「AI Features and Your Website」に、AI機能とサイトの関係についての案内があります。設定を検討する場合は、必ず最新の公式ドキュメントで内容を確認してください。

注意点を1つ申し添えます。検索結果での見え方を制御する設定は、AI機能だけでなく通常の検索結果の表示にも影響する場合があります。影響範囲を確認せずに設定すると、通常の検索での見え方まで変わる恐れがあります。

### 表示回数が0のままです。何から手を付ければよいですか？

通常の検索での順位を上げる段階です。生成AIレポートは、検索で見つけてもらえていないページを救う機能ではありません。

手順は次のとおりです。

1. 通常の検索パフォーマンスで、順位が11位から30位のページを探す
2. その中から、事業に近いテーマのページを1つ選ぶ
3. 読者の問いに、見出しの直下で直接答える形に書き直す

Googleは、生成AI機能に表示されるために新しい機械可読ファイルや専用のマークアップを作る必要はないと明記しています。出典: Google検索セントラル「AI Features and Your Website」。先に整えるべきは、ファイルではなく本文の中身です。
