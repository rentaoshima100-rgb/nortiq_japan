# SCS評価制度の準備｜★3の登録料と着手する順番

## SCS評価制度とは何ですか？

SCS評価制度とは、取引先に求めるセキュリティ対策の水準を★の段階で示せるようにする制度です。委託元が委託先に段階を提示し、実施状況を確認することが想定されています。

正式な名称は「サプライチェーン強化に向けたセキュリティ対策評価制度」です。経済産業省は、制度構築方針の案を2025年12月26日に公表し、制度構築方針そのものを2026年3月27日に公表しました。出典: 経済産業省 報道発表（2025年12月26日、2026年3月27日）。

申請受付の開始は先です。★3と★4の制度開始の目標時期は2026年度末頃とされています。出典: 経済産業省「サプライチェーン強化に向けたセキュリティ対策評価制度（SCS評価制度）」。

### 制度が解こうとしている2つの課題

制度は、取引の両側にある困りごとを同時に扱っています。

| 立場 | 抱えている課題 |
| --- | --- |
| 委託元 | 委託先の対策が見えにくく、自社が出すチェックリストが適切かも分からない |
| 委託先 | 委託元ごとに違う要求に個別に答えており、負担が重くなっている |

出典: 経済産業省「サプライチェーン強化に向けたセキュリティ対策評価制度（SCS評価制度）」。

御社が受注側であれば、2つ目が実感に近いはずです。取引先ごとに様式の違うチェックシートが届き、同じ内容を書き直しているという状態です。制度は、この個別対応を共通の★の段階に置き換えようとしています。

### 中小企業にとっての位置づけ

評価は2段階ではなく、★3と★4で求められる方法が違います。

- ★3: 専門家確認付き自己評価
- ★4: 第三者評価と技術検証

出典: 経済産業省「サプライチェーン強化に向けたセキュリティ対策評価制度（SCS評価制度）」。

どちらを求められるかは、御社ではなく取引先が決めます。したがって、御社の準備は「どちらを求められても困らない状態を作る」方向になります。詳しくは後述します。

いま着手できるのは、IPAの「SECURITY ACTION」です。これは中小企業が自ら情報セキュリティ対策に取り組むことを宣言する制度で、取り組み目標に応じて一つ星と二つ星の2段階があります。出典: IPA「SECURITY ACTION セキュリティ対策自己宣言」。

つまずきやすいのは、SCS評価制度の★とSECURITY ACTIONの星を混同することです。別の制度ですので、宣言すれば★が付くわけではありません。

## 申請受付はいつ始まり、登録料はいくらですか？

登録希望組織の受付開始は2027年3月以降の予定で、★3の登録料は10,000円（1年分）、★4は60,000円（3年分）と公表されています。

金額はIPAが公表しています。2026年9月18日付の「料金設定のお知らせ」に、利用者に求める料金が示されました。出典: IPA「サプライチェーン強化に向けたセキュリティ対策評価制度 料金設定のお知らせ」（2026年9月18日）。

### ★3と★4の登録料を表で比較する

登録料は、申請の時期によって変わります。下の表は同じお知らせからの抜粋です。

| 対象 | 2028年3月31日までの申請 | 2028年4月1日以降の申請 |
| --- | --- | --- |
| ★3 登録希望組織 | 10,000円（1年分） | 20,000円（1年分） |
| ★4 登録希望組織 | 60,000円（3年分） | 60,000円（3年分） |

出典: 同「料金設定のお知らせ」。料金には消費税及び地方消費税が含まれ、適用時期は申請日を基準とすると注記されています。

★3は1年分、★4は3年分という単位の違いに注意してください。★3を3年続けると、2028年3月31日までの料金でも30,000円になります。

### 2028年4月1日以降に上がる料金

★3の登録料は、2028年4月1日以降の申請で20,000円（1年分）に変わります。★4は60,000円（3年分）のまま据え置かれます。

- 受付開始は2027年3月以降の予定です。出典: 同「料金設定のお知らせ」。
- つまり、★3の低い料金が適用されるのは、受付開始から2028年3月31日までの申請に限られます。
- つまずきやすいのは、適用の基準が申請日であるという点です。社内の決裁に時間がかかると、料金が変わる側に入ります。

なお、評価する側の料金も同じお知らせに載っています。評価機関の申請料は2028年3月31日までが150,000円、指定料は300,000円（3年分）です。御社が支払う金額ではありませんが、★4で第三者評価を受ける際の費用の背景として押さえておくと、見積もりの読み方が変わります。

もう1つ、専門家の登録についても予定が示されています。SCSセキュリティ専門家の登録受付は2027年1月以降の予定で、登録料は無料です。出典: 同「料金設定のお知らせ」。★3は専門家の確認を伴う自己評価ですので、確認を担う側の登録が先に始まる順番になっています。

## ★3と★4は何が違いますか？

★3は自己評価、★4は第三者評価と技術検証という構成です。IPAが公開しているガイドの種類から、この違いが読み取れます。

費用の差もここから生まれます。★3は御社が自ら評価し、専門家が確認する形です。★4は外部の評価機関が文書を確認し、技術検証も入ります。

### 公開されているガイドの構成

IPAの要求事項・評価基準のページでは、次の文書が公開されています。並びを見ると、どの段階で誰が関わるかが分かります。

| 公開されている文書 | 対象 |
| --- | --- |
| ★3・★4 自己評価等ガイド | ★3と★4の両方 |
| ★4 第三者評価ガイド | ★4のみ |
| ★4 技術検証ガイド | ★4のみ |
| ★3・★4 要求事項・評価基準 解説書 | ★3と★4の両方 |

出典: IPA「要求事項・評価基準」（SCS評価制度）。★3・★4の要求事項・評価基準は2026年4月21日に公開されました。出典: 同ページの更新履歴。

★4だけに第三者評価と技術検証のガイドがある点が、構成上の違いです。経済産業省の説明でも、★3は専門家確認付き自己評価、★4は第三者評価と技術検証とされています。出典: 経済産業省「サプライチェーン強化に向けたセキュリティ対策評価制度（SCS評価制度）」。

### どちらを求められるかは取引先が決める

御社が選ぶのではありません。制度は、委託元が委託先に適切な段階を提示することを想定しています。

- まず、主要な取引先が将来どの段階を求めるのかを聞いておく（目安: 次の商談の機会に1件ずつ）。
- 聞けない場合は★3を前提に準備する。要求事項・評価基準は★3と★4で共通の解説書が出ているため、★3の準備は★4の土台になります。
- つまずきやすいのは、取引先が決める前に★4の準備を始めてしまうことです。第三者評価の費用が先に発生します。

当社がセキュリティ要件の相談を受ける際も、取引先の意向を確認しないまま上の段階を目指す相談が少なくありません。段階が決まらないうちは、どちらにも効く社内の整理から進めるほうが無駄がありません。その具体は次のセクションで扱います。

## 受付開始までに何から着手すればよいですか？

IPAのSECURITY ACTIONの自己宣言から着手してください。登録の受付が始まるまでの期間を、社内の整理にあてるのが順番として無理がありません。

理由は2つあります。SECURITY ACTIONの条件を満たす作業が、★3の準備とそのまま重なるためです。もう1つは、宣言が無料でできるためです。

### 一つ星と二つ星のどちらを選ぶか

取り組み目標に応じて2段階あります。条件が違いますので、御社の現状で選んでください。

| 段階 | 宣言の条件 |
| --- | --- |
| 一つ星 | 「中小企業の情報セキュリティ対策ガイドライン」の情報セキュリティ6か条に取り組む |
| 二つ星 | 付録3の自社診断で状況を把握し、付録2の情報セキュリティ基本方針を定めて外部に公開する |

出典: IPA「SECURITY ACTIONとは?」。情報セキュリティ6か条は、第4.0版で5か条に「バックアップを取ろう!」が追加されたものです。

着手の順番は次のとおりです。

1. 一つ星と二つ星のどちらを宣言するか決める（目安30分）。すでに基本方針がある場合は二つ星から始められます。
2. 付録3の自社診断を実施する（目安1時間）。二つ星を選ぶ場合は事前の条件になります。
3. 付録2をもとに情報セキュリティ基本方針を定め、外部に公開する（目安: 社内決裁を含めて2週間）。
4. 申込フォームから自己宣言を行う。

つまずきやすいのは3番です。基本方針は経営者名で出す文書ですので、決裁に時間がかかります。着手の順番を先に決めておいてください。

### 申込に必要なGビズIDの準備

申込の方法は2026年4月1日に変わりました。SECURITY ACTION管理システムの利用には、GビズIDプライムまたはメンバーのアカウントが必須です。出典: IPA「SECURITY ACTION 自己宣言の申込方法」。

- 法人、個人事業主ともにGビズIDプライムアカウントを取得します。
- GビズIDの取得からロゴマークの使用までは、最短1日で実施が可能とされています。出典: 同ページ。
- ただし、システムメンテナンス等で利用できない期間もあるため、余裕を持って手続きを進めるよう案内されています。

実装者として申し上げると、GビズIDは補助金の申請でも使います。先に取っておけば、この先の手続きで何度も効いてきます。

当社は中小企業のサイト制作と業務システム開発を手がけており、基本方針のページの作成や社内規程の整理もあわせてご相談いただけます。何から着手するかの切り分けだけでも構いませんので、必要な際は[無料診断](/diagnostic)をご利用ください。

## 二つ星の条件になる基本方針は、どこに載せればよいですか？

自社サイトに情報セキュリティ基本方針のページを作り、外部から見える形にしてください。二つ星の宣言は、自社診断の実施と基本方針の外部公開が事前の条件です。

置き場所に決まりはありません。ただし、取引先が探して見つけられる位置である必要があります。会社概要の配下か、フッタからたどれる独立したページが現実的です。

基になる様式は公開されています。IPAは「中小企業の情報セキュリティ対策ガイドライン」第4.0版を2026年3月27日に公開しており、付録に情報セキュリティ基本方針のサンプルが含まれます。出典: IPA プレスリリース「『中小企業の情報セキュリティ対策ガイドライン』第4.0版を公開」（2026年3月27日）。

同じ第4.0版で、基本行動指針が5か条から6か条に増えました。出典: 同プレスリリース。基本方針を新しく作るなら、第4.0版の付録を基にしてください。

### サイトに載せるときの表記の注意

文言を誤ると、第三者に誤解を与えます。IPAは不適切な表現の例を示しています。

- 使ってよい: 「SECURITY ACTIONを宣言しました」
- 使ってはいけない: 「一つ星（二つ星）の認定を受けました」「取得しました」

出典: IPA「SECURITY ACTIONとは?」。SECURITY ACTIONは、情報セキュリティ対策状況等をIPAが認定するものではありません。

- また、一つ星と二つ星を同時に申し込むことや、双方のロゴマークを同時に使用することはできません。出典: 同ページ。
- つまずきやすいのは、制作会社にロゴの掲載を依頼するときです。「認定」という言葉が原稿に混ざりやすいため、文言を御社から渡してください。

### 宣言事業者として公開される情報

宣言すると、IPAのホームページにも情報が載ります。自社サイトの記載と食い違わないようにしてください。

| 区分 | IPAのホームページで公開される情報 |
| --- | --- |
| 法人 | 事業者名、都道府県、市区町村、業種、取組段階（一つ星または二つ星） |
| 個人事業主 | 代表者名、屋号、都道府県、市区町村、業種、取組段階 |

出典: IPA「SECURITY ACTION 自己宣言の申込方法」。

実装者として申し上げると、ここで効くのは事業者名の表記です。登記名と、サイトで使っている社名の表記が違う会社は珍しくありません。取引先が照合したときに別の会社に見えますので、申込の前に表記をそろえておいてください。

## 制度の資料はどこまで出そろっていますか？

2026年のうちに、要求事項・評価基準から料金設定、評価用ガイドまで順に公開されています。読む順番を決めておけば、受付開始に慌てずに済みます。

逆に言えば、2026年の前半に調べただけでは情報が足りません。料金が分かったのは9月、評価用ガイドが出たのは10月です。

### 公開の経緯を時系列で確認する

IPAのお知らせに、公開の経緯が残っています。主なものを並べます。

| 日付 | 公開されたもの |
| --- | --- |
| 2026年4月21日 | ★3・★4 要求事項・評価基準 |
| 2026年9月18日 | 料金設定のお知らせ |
| 2026年10月26日 | 評価機関・技術検証事業者・研修事業者の新規申請の指定申請の受付終了 |
| 2026年10月28日 | 評価用ガイド、解説書 |

出典: IPA「SCS評価制度」のお知らせ、および「要求事項・評価基準」の更新履歴。

この並びから分かることが1つあります。評価する側の指定申請の受付が2026年10月26日に終わっている一方、御社が登録する側の受付開始は2027年3月以降の予定です。評価の受け皿が先にそろう順番になっています。

### いま読むべき資料の優先順位

全部を読む必要はありません。御社が★3を前提に準備するなら、次の順で足ります。

1. ★3・★4 要求事項・評価基準（目安: 通読に半日）。何を求められるかの本体です。
2. ★3・★4 自己評価等ガイド（目安: 2時間）。自己評価の進め方が書かれています。
3. 料金設定のお知らせ（目安: 10分）。1枚の文書です。
4. ★3・★4 要求事項・評価基準 解説書（目安: 必要な箇所だけ）。要求事項で迷った箇所を引くために使います。

★4の第三者評価ガイドと技術検証ガイドは、取引先から★4を求められた段階で読めば足ります。

つまずきやすいのは、1番を飛ばして自己評価のガイドから読むことです。要求事項を知らないまま進め方を読んでも、何を評価するのか分かりません。

なお、資料は更新されます。IPAのお知らせは更新履歴とあわせて公開されていますので、準備を始める前に最新の日付を確認してください。

## 準備を進めるときのつまずきやすい点はどこですか？

GビズIDの取得と、基本方針のページの作り方でつまずく例が多いです。どちらも着手から公開までに社内の決裁が挟まります。

技術的に難しい作業はありません。難しいのは、誰が決めて誰が出すかを先に決めておくことです。

### GビズIDの取得にかかる時間

手続き自体は短く終わります。IPAの案内では、GビズIDの取得からロゴマークの使用までが最短1日で実施可能とされています。出典: IPA「SECURITY ACTION 自己宣言の申込方法」。

ただし、前提が2つあります。

1. 取得するのはGビズIDプライムアカウントです。法人、個人事業主ともに必要です。出典: 同ページ。
2. システムメンテナンス等で利用できない期間もあるため、余裕を持って手続きを進めるよう案内されています。出典: 同ページ。

- つまずきやすいのは、代表者名義の手続きである点です。印鑑や本人確認の書類が必要になる場面があり、代表が不在だと止まります。
- 介護施設で自己宣言する場合は、介護施設ごとにGビズIDメンバーアカウントを作成するとされています。出典: 同ページ。複数拠点を持つ事業者は、数を先に数えてください。

### 基本方針を公開した後の更新

公開して終わりではありません。基本方針は、組織や取り扱う情報が変わったときに見直す文書です。

- 更新の担当を決める。制作会社に依存すると、軽微な文言の修正でも都度の依頼になります。
- 自社で直せる形にしておく。基本方針は1ページの文書ですので、CMSの固定ページで持てば社内で更新できます。
- 公開日と改定日をページに記載する。取引先が見たときに、いつの版かが分かります。

実装者として申し上げると、ここは作りを少し変えるだけで後の手間が大きく変わります。当社がサイトを作る際も、方針や規程の類は社内で更新できる場所に置き、本体のデザインとは切り離しています。

もう1つ、費用面の注意があります。★3の登録料は1年分ですので、毎年の支出になります。初年度の予算だけで通すと、翌年に説明が必要になります。前述の料金の表を使って、複数年の見通しで社内に出してください。

準備の進め方や、基本方針を社内で更新できる形に整える部分は当社でもお手伝いできます。[DXガイドブック](/guidebook)に要件整理の進め方をまとめていますので、あわせてご利用ください。

付きません。SECURITY ACTIONとSCS評価制度は別の制度です。

SECURITY ACTIONは中小企業が自ら取り組みを宣言する制度で、IPAが対策状況を認定するものではありません。出典: IPA「SECURITY ACTIONとは?」。ただし、二つ星の条件である自社診断と基本方針の整備は、★3の準備と重なります。

### SECURITY ACTIONの申込にGビズIDは必要ですか？

必要です。2026年4月1日に申込方法が変わり、SECURITY ACTION管理システムの利用にはGビズIDプライムまたはメンバーのアカウントが必須になりました。出典: IPA「SECURITY ACTION 自己宣言の申込方法」。

法人、個人事業主ともにGビズIDプライムアカウントを取得します。取得からロゴマークの使用までは最短1日で実施可能とされていますが、代表者名義の手続きが挟まる点に注意してください。

### 情報セキュリティ基本方針は自社サイトのどこに置けばよいですか？

置き場所に決まりはありません。取引先が探して見つけられる位置であれば足ります。

会社概要の配下か、フッタからたどれる独立したページが現実的です。二つ星の宣言では、自社診断の実施と基本方針の外部公開が事前の条件とされています。出典: IPA「SECURITY ACTIONとは?」。社内で更新できる場所に置いておくと、改定のたびの依頼が不要になります。
