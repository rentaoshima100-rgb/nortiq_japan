# 補助金でマニュアルと研修は対象？役務の上限200万円

## マニュアル作成と導入研修は補助の対象ですか？

役務として対象になります。ただしソフトウェアと対になっていることが条件です。研修だけを単独で申請する形は想定されていません。

### 役務は3つのカテゴリに区分されている

デジタル化・AI導入補助金2026の公募要領 (通常枠) では、補助対象経費の大分類Ⅲ「役務」が3つのカテゴリに区分されています (出典: デジタル化・AI導入補助金2026 公募要領 (通常枠))。

| カテゴリ | 内容 |
|---|---|
| 導入コンサルティング・活用コンサルティング | 導入前後の助言 |
| 導入設定・マニュアル作成・導入研修 | 初期設定、手順書の作成、操作の研修 |
| 保守サポート | 導入後の問い合わせ対応や修正 |

御社が気にしているマニュアル作成と導入研修は、2番目のカテゴリに入ります。つまり補助の対象です。

### ソフトウェアと対である要件

役務はソフトウェアの導入に付随する経費として扱われます。そのため、ソフトウェアの申請がない状態で役務だけを申請することはできません。

あわせて補助の枠組みも押さえておきます。通常枠の補助率は2分の1以内で、一定の賃金の条件を満たす場合は3分の2以内です。補助額の範囲は、1プロセス以上の場合が5万円以上150万円未満、4プロセス以上の場合が150万円以上450万円以下です (出典: デジタル化・AI導入補助金2026 通常枠)。

クラウドのサービスを使う場合も対象です。通常枠のクラウド利用料が補助対象になる期間の上限は2年分です (出典: 同 通常枠)。

- 役務だけの申請はできません
- 役務の上限は別に定められています (次のセクションで扱います)
- 対象外になる費目もあります

申請の前に、見積書をソフトウェアと役務に分けてもらうことが出発点です。分け方は後のセクションで具体的に示します。

## 役務の上限はいくらですか？

公募要領では、大分類Ⅲ「役務」の補助対象経費の上限額が200万円と定められています (出典: デジタル化・AI導入補助金2026 公募要領 (通常枠))。補助額ではなく、対象になる経費の上限です。

### 上限額と補助の対象範囲

200万円は3つのカテゴリの合計に対する上限です。導入コンサルティング、導入設定とマニュアル作成と導入研修、保守サポートを合わせた金額で見ます。

計算の順番は次のとおりです。

1. 役務の見積額を合計する
2. 200万円を超える分は補助対象経費から外れる
3. 残った対象経費に補助率を掛ける

通常枠の補助率は2分の1以内で、一定の賃金の条件を満たす場合は3分の2以内です (出典: デジタル化・AI導入補助金2026 通常枠)。つまり役務の経費が200万円であれば、補助される額は補助率に応じて小さくなります。上限額と補助額を混同しないよう注意してください。

補助額の範囲も決まっています。1プロセス以上の場合は5万円以上150万円未満、4プロセス以上の場合は150万円以上450万円以下です (出典: 同 通常枠)。ソフトウェアと役務を合わせた全体がこの範囲に収まるかを確認します。

### 保守サポートは最大2年

保守サポートについては期間の上限があります。公募要領では、カテゴリー7 (保守サポート) が補助対象になる期間の上限は、ソフトウェアの利用範囲内で2年分とされています (出典: デジタル化・AI導入補助金2026 公募要領 (通常枠))。

クラウドのサービスも同様です。通常枠のクラウド利用料が補助対象になる期間の上限は2年分です (出典: 同 通常枠)。

| 費目 | 期間の上限 |
|---|---|
| 保守サポート | 2年分 (ソフトウェアの利用範囲内) |
| クラウド利用料 | 2年分 |

3年分の保守契約を結ぶ場合、補助の対象になるのは2年分までです。残りは自己負担として見込んでおきます。見積書では年数を明記してもらうと、対象範囲の判断が容易になります。

## 対象にならない費用は何ですか？

交通費と宿泊費は補助対象外です。公募要領が補助対象外の経費として挙げています (出典: デジタル化・AI導入補助金2026 公募要領 (通常枠))。研修を対面で行う場合に影響します。

### 対象外になる費目

講師が出張して現地で研修を行う場合、その移動と宿泊の費用は補助の対象になりません。研修費そのものは対象でも、付随する旅費は自己負担になります。

もう1つ注意したい条項があります。申請要件には「導入するＩＴツールに比して役務費用が占める割合が著しく高額でないこと」という記載があります (出典: 同 公募要領)。つまり研修やコンサルティングの比率が過大な見積もりは、制度上も問題になります。

上限の計算例も公募要領に示されています。カテゴリー5が70万円、カテゴリー6が70万円、カテゴリー7が70万円で合計210万円になる場合、補助対象経費は200万円までになるという例です (出典: 同 公募要領)。超えた分は申請しても対象から外れます。

| 費目 | 扱い |
|---|---|
| 研修の実施費用 | 対象 (役務カテゴリー6) |
| マニュアル作成 | 対象 (役務カテゴリー6) |
| 講師の交通費 | 対象外 |
| 講師の宿泊費 | 対象外 |
| 役務の合計が200万円を超える分 | 対象外 |

### 見積書で分けて書いてもらう

対象と対象外が1行にまとまっていると、申請の際に切り分けられません。見積書の段階で分けてもらいます。

依頼の仕方は次のとおりです。

1. 研修費と旅費を別の行にする
2. 研修費は回数または日数の単価で示す
3. 保守サポートは年数を明記する
4. 役務の3カテゴリごとに小計を出す

4番目があると、200万円の上限に収まるかを御社側で確認できます。

オンラインでの研修に切り替えれば旅費は発生しません。ただし操作の習得に対面が向く場面もあります。費用だけで決めず、定着に必要な形を選んでください。

## 見積書はどう分けてもらいますか？

ソフトウェア、役務、対象外の費用の3つに分けた見積書を依頼します。1行にまとまっていると、申請の際に切り分けられません。

### 見積書の分け方の例

依頼するときは、次の構成を示すと伝わります。

| 区分 | 行の例 |
|---|---|
| ソフトウェア | ソフトウェアのライセンス費用、クラウド利用料 (年数を明記) |
| 役務 カテゴリー5 | 導入コンサルティング、活用コンサルティング |
| 役務 カテゴリー6 | 導入設定、マニュアル作成、導入研修 |
| 役務 カテゴリー7 | 保守サポート (年数を明記) |
| 補助対象外 | 講師の交通費、宿泊費 |

役務の3カテゴリごとに小計を出してもらうと、合計が200万円の上限に収まるかを御社側で確認できます。公募要領では、役務の補助対象経費の上限は200万円と定められています (出典: デジタル化・AI導入補助金2026 公募要領 (通常枠))。

また、カテゴリー6とカテゴリー7については「ＩＴツール登録申請時に選択したカテゴリー１（ソフトウェア）と対になっている役務を導入する場合に限り、申請可能とする」と定められています (出典: 同 公募要領)。研修やマニュアルだけを別の会社に切り出して頼むと、この補助金では対象になりません。費用を抑えたい場合でも、どこまでをソフトウェアの導入と一体で発注するかが分かれ目になります。

### 申請後に内訳を変える場合

申請した内訳を後から変える場合は、手続きが必要になることがあります。交付決定の後に仕様を変えるときの確認手順は別の記事で扱っています。

実務上は、申請前に次を確定しておくほうが手戻りが少なくなります。

1. 研修の回数または日数
2. マニュアルの対象範囲 (全機能か、使う機能に限るか)
3. 保守サポートの年数
4. 実施方法 (対面かオンラインか)

4番目は旅費の有無に直結します。見積書の対象外の行が変わるため、申請前に決めておきます。

## 研修とマニュアルはどこまで頼むべきですか？

社内に専任の担当者がいない場合は、運用を続けるために必要な範囲を見極めて頼みます。補助の対象だからと全部を頼むと、上限の200万円を圧迫します。

### 担当者が不在または兼任の場合

まず御社の体制を確認します。中小企業では、システムを見る人がいない状態が珍しくありません。

株式会社kubellの調査では、社外委託と兼務を含めてもシステム担当者がいない中小企業の割合は27.5%でした (従業員10名から299名、有効回答1093サンプル)。従業員規模別では、10名から29名で48.2%、30名から49名で29.8%、50名から99名で20.1%、100名から299名で13.2%です。日常の取引や情報管理にデジタルを使っていない企業は全体で46.0%でした (出典: 株式会社kubell「中小企業のデジタル化に関するアンケート調査」2025年12月発表)。

兼任の実態も報じられています。ノークリサーチの2025年5月調査では、情報システムを1人で担う状態の割合は2025年が24.5%、2023年が21.3%でした。年商5億円から50億円の企業で、情報システム担当が他業務と兼任である割合は61.1%です (出典: ノークリサーチ 2025年5月調査の報道)。

| 体制 | 頼む範囲の考え方 |
|---|---|
| 担当者が不在 | 操作手順書に加えて、障害時の連絡手順まで文書化を依頼する |
| 1人で兼任 | その人が不在のときに代わりが操作できる範囲まで作る |
| 複数名で担当 | 初期研修に絞り、以後は社内で引き継ぐ |

### 引き継ぎを前提にした範囲

マニュアルは、作れば終わりではありません。システムの更新で手順が変わります。だから依頼の範囲には、御社が後から更新できる形で納品してもらうことを含めます。

依頼に含める項目は次のとおりです。

1. 編集できる形式での納品 (画面の画像を差し替えられる形)
2. 使う機能に絞った手順書 (全機能の網羅は量が増える)
3. 新しく入った職員が1人で読める説明の粒度

実装の側から見ると、全機能のマニュアルは分量が増えるうえ、使われない部分が多くなります。日常業務で使う画面に絞るほうが定着します。研修も同じで、回数を増やすより、運用開始後に1回追加するほうが質問が具体的になります。

## 申請前に確認する項目は何ですか？

役務の区分、上限、対象外費用、ソフトウェアとの対応関係の4点を公募要領で確認します。制度は公募回ごとに更新されるため、最新版で確認します。

### 確認する4点

| 確認する項目 | 何を見るか |
|---|---|
| 役務の区分 | 依頼する作業が3カテゴリのどこに入るか |
| 上限 | 役務の合計が200万円に収まるか |
| 対象外費用 | 交通費と宿泊費が見積書で分かれているか |
| ソフトウェアとの対応関係 | カテゴリー6と7が、申請するソフトウェアと対になっているか |

4番目は見落としやすい項目です。公募要領では、カテゴリー6とカテゴリー7は「ＩＴツール登録申請時に選択したカテゴリー１（ソフトウェア）と対になっている役務を導入する場合に限り、申請可能とする」と定められています (出典: デジタル化・AI導入補助金2026 公募要領 (通常枠))。

あわせて、役務費用の割合についての申請要件も確認します。「導入するＩＴツールに比して役務費用が占める割合が著しく高額でないこと」という条項です (出典: 同 公募要領)。

### 公募要領の版を確認する

公募要領は公募回ごとに更新されます。本記事の数値はデジタル化・AI導入補助金2026 通常枠の公募要領と事務局の公式ページによるものです。実際に申請を検討する際は、中小機構の事務局サイトで最新版の該当箇所を確認してください。

申請の流れそのものや、交付決定の前に発注してよいかという論点は、別の記事で扱っています。本記事の範囲は役務の区分と上限です。

御社のシステム導入で、どこまでを役務として依頼し、どこを自社で持つかの切り分けに迷う場合は、無料診断でご相談いただけます。当社は業務システムの構築と導入後の伴走支援を行っており、定着に必要な範囲から逆算して見積もりの内訳を整理できます。

## よくあるご質問

この記事に関して多い質問と回答をまとめます。

### ソフトウェアを買わずに研修だけを補助の対象にできますか

できません。公募要領では、カテゴリー6 (導入設定・マニュアル作成・導入研修) とカテゴリー7 (保守サポート) は「ＩＴツール登録申請時に選択したカテゴリー１（ソフトウェア）と対になっている役務を導入する場合に限り、申請可能とする」と定められています (出典: デジタル化・AI導入補助金2026 公募要領 (通常枠))。

### 役務の200万円は補助額ですか、それとも補助の対象になる経費の上限ですか

補助対象経費の上限です。公募要領では大分類Ⅲ「役務」の補助対象経費の上限額が200万円とされています。ここに補助率を掛けた額が補助されます。通常枠の補助率は2分の1以内で、一定の賃金の条件を満たす場合は3分の2以内です (出典: デジタル化・AI導入補助金2026 公募要領 (通常枠)、同 通常枠の公式ページ)。

### オンラインで研修を行えば交通費の問題は避けられますか

移動が発生しないため、交通費と宿泊費は生じません。公募要領は補助対象外の経費として交通費と宿泊費を挙げています (出典: 同 公募要領)。ただし操作の習得に対面が向く場面もあります。費用だけでなく、定着に必要な形で選んでください。

### 保守サポートは3年分をまとめて申請できますか

補助の対象になるのは2年分までです。公募要領では、カテゴリー7 (保守サポート) が補助対象になる期間の上限は、ソフトウェアの利用範囲内で2年分とされています。クラウド利用料も通常枠で2年分が上限です (出典: 同 公募要領、同 通常枠の公式ページ)。3年目以降は自己負担として見込みます。

### 公募要領はどの版を見ればよいですか

申請する公募回の最新版です。公募要領は公募回ごとに更新されます。本記事の数値はデジタル化・AI導入補助金2026 通常枠の公募要領と事務局の公式ページによるものです。申請前に、中小機構の事務局サイトで該当箇所を確認してください。
