# 小売業の39.0%が口頭と電話と帳簿中心｜公的データ

## 小売業では39.0%が口頭と電話と帳簿での業務が中心です

東京商工会議所の2026年の調査では、小売業で口頭と電話と帳簿での業務が中心と回答した割合は39.0%でした。4割近くが店頭の台帳を前提に回っています（出典: 東京商工会議所『中小企業のデジタルシフト・DX実態調査』（2026年））。

この数字は、業種別で最も高い値です。全体では24.3%なので、小売業は全体より15ポイント近く高い位置にあります。

### 調査の概要と回答数

調査の条件は次のとおりです。数字を社内で使う前に、ここを押さえてください。

| 項目 | 内容 |
| --- | --- |
| 調査名 | 中小企業のデジタルシフト・DX実態調査 |
| 実施機関 | 東京商工会議所 |
| 実施期間 | 2026年3月25日から4月15日 |
| 対象 | 主に東京23区内の中小企業 |
| 回答数 | 1,272社 |
| 方法 | 郵送とメールによる調査票送付 |
| 小売業の回答数 | 105社 |

同調査はデジタルシフトの状況を4段階に分けており、39.0%という値は最も低い「口頭連絡、電話、帳簿での業務が多い」（レベル1）と回答した割合です。

業種別に並べると、位置関係が見えます。

| 業種 | レベル1の割合 | 回答数 |
| --- | --- | --- |
| 小売業 | 39.0% | 105 |
| 卸売業 | 33.3% | 225 |
| 建設業 | 28.2% | 202 |
| サービス業 | 26.7% | 455 |
| 製造業 | 19.6% | 281 |
| 全体 | 24.3% | 1,272 |

グラフにすると、小売業から製造業へ向かって右肩下がりの棒が並び、小売業と製造業の間に19.4ポイントの差が開く形になります（出典: 東京商工会議所『中小企業のデジタルシフト・DX実態調査』（2026年））。

### この数字が意外である理由

小売業は、レジや決済の仕組みが早くから入っている業種です。POSレジもキャッシュレス決済も、店頭に当たり前のように置かれています。

それでも39.0%がレベル1に該当するのは、仕組みが入っている業務と入っていない業務が分かれているためだと読めます。会計の瞬間はデジタル、来店の予約と顧客の記録は紙と電話、という組み合わせです。

製造業の19.6%と比べると、差はちょうど2倍近くになります。製造業は生産管理の仕組みが業務の流れそのものを覆うのに対し、小売業は会計の点だけが先に電子化された、という違いとして説明がつきます。

なお、この調査は主に東京23区内の中小企業を対象としており、全国の数値ではありません。地方の小売業に当てはめる場合は、その前提を添えてください。

## この数字は何を測ったものですか

業務の進め方として口頭と電話と帳簿が中心かを尋ねた回答の割合です。デジタル化の進み方を業種別に比べられる数字です。

設問が尋ねているのは、導入しているツールの数ではありません。業務がどの手段で回っているかという、現場の実態の側です。

### 調査の対象と回答数n=1,272

同調査はデジタルシフトの状況を4段階に分けています。39.0%は、その最も低い段階に該当した小売業の割合です（出典: 東京商工会議所『中小企業のデジタルシフト・DX実態調査』（2026年））。

段階の区切り方を知っておくと、自社がどこに当たるかを判断できます。レベル1の定義は「口頭連絡、電話、帳簿での業務が多い」です。次の2点を満たす御社は、この段階に該当します。

1. 来店の予約や問い合わせを、電話と口頭で受けている
2. 顧客の名前や履歴を、紙の台帳かノートで管理している

会計にPOSレジを使っていても、1と2が当てはまればレベル1です。ここが、小売業の39.0%という値を理解する鍵になります。

回答数は全体で1,272社、小売業は105社です。調査は郵送とメールによる調査票送付で、2026年3月25日から4月15日に実施されました。

### 数字の読み方の注意点

この数字を使うときに、押さえておく点が3つあります。

| 注意点 | 内容 |
| --- | --- |
| 対象の地域 | 主に東京23区内の中小企業です。全国の数値ではありません |
| 回答数の違い | 小売業は105社で、サービス業の455社より少なく、業種間で回答数に差があります |
| 自己申告である点 | 自社がどの段階かという回答者の判断に基づく数値です |

3つ目は、数字を小さく見せる方向にも大きく見せる方向にも働きます。デジタル化に前向きな担当者が回答した場合、実態より上の段階を選ぶことがあります。逆に、現場の非効率を強く感じている担当者は下の段階を選びます。

つまずきやすい点は、この種の調査の数値を「小売業の39.0%は紙だけで営業している」と読み替えてしまうことです。レベル1の定義は口頭と電話と帳簿が多いことで、他の手段を一切使っていないという意味ではありません。社内で共有するときは、定義をそのまま添えてください。

## 社内の説明にこの数字をどう使いますか

投資の是非を争う場面ではなく、現状の位置を共有する場面で使ってください。4割近くが同じ状態であることは、急がない理由にも、動く理由にもなります。

同じ数字が両方の結論を支えるという点が、この種の統計の扱いの難しさです。使う場面を限定するほうが、話が前に進みます。

### 使い方の3つの型

実務で使える型は3つです。

1. 自社の位置を確かめる型（所要時間の目安: 30分）。自社がレベル1に当たるかを、来店予約と顧客記録の2点で判定します。当たっていれば、小売業の39.0%の側にいることになります（出典: 東京商工会議所『中小企業のデジタルシフト・DX実態調査』（2026年））
2. 業種の差を示す型（目安: 資料1枚、1時間）。小売業39.0%、卸売業33.3%、建設業28.2%、サービス業26.7%、製造業19.6%、全体24.3%という並びを示し、小売業が最も高い位置にあることを共有します
3. 取引先の視点を持ち込む型（目安: 30分）。製造業の19.6%という値は、取引先の多くが仕組みを前提に動いていることを示します。紙と電話で受ける側が残っていることを、相手の立場から説明できます

2の型で資料を作る場合は、業種別の棒グラフを1枚入れてください。数字を並べた表より、小売業が右端から最も離れた位置にあることが伝わります。

### 使い方を誤ると逆の結論になります

よくある誤りは、39.0%を「まだ4割が紙だから急がなくてよい」と読むことです。この読み方自体は数字に反していません。

ただし同じ調査は、全体で24.3%、製造業で19.6%という値も示しています。小売業が業種別で最も高いという事実のほうが、自社の判断には効きます。

| 読み方 | 導かれる結論 | 妥当性 |
| --- | --- | --- |
| 小売業の4割が同じ状態 | 急がなくてよい | 数字に反しませんが、業種間の差を無視しています |
| 小売業は業種別で最も高い | 業種として遅れている | 同じ調査で確認できます |
| 全体の24.3%より15ポイント近く高い | 他業種との差が開いている | 同じ調査で確認できます |

つまずきやすい点は、1行目だけを引用した資料が社内に出回ることです。表の3行を並べて示せば、議論の土台が揃います。

数字の役割は、ここまでです。何を先に仕組みに移すかという判断は、この調査からは出てきません。その判断については後述します。

## 顧客の記録を仕組みに移すと義務になる項目があります

来店予約や顧客対応の記録を仕組みで扱う場合、個人情報保護委員会のガイドラインが求める技術的および組織的な安全管理措置の項目が義務として関わります。紙の台帳のときには表に出なかった部分です。

同ガイドラインは、安全管理措置を組織的、人的、物理的、技術的の4区分で定めています（出典: 個人情報保護委員会『個人情報の保護に関する法律についてのガイドライン（通則編）』（平成28年11月、令和8年6月一部改正））。

### 求められる措置の項目

技術的安全管理措置は4項目です。同ガイドラインが挙げているのは次のとおりです。

1. アクセス制御。担当者および取り扱う個人情報データベース等の範囲を限定するために適切なアクセス制御を行うこと
2. アクセス者の識別と認証。個人データを取り扱う情報システムを使用する従業者が正当なアクセス権を有する者であることを識別した結果に基づき認証すること
3. 外部からの不正アクセス等の防止
4. 情報システムの使用に伴う漏えい等の防止

組織的安全管理措置は5項目で、組織体制の整備、個人データの取扱いに係る規律に従った運用、取扱状況を確認するための手段の整備、漏えい等事案に対応する体制の整備、取扱状況の把握および安全管理措置の見直しです。

同ガイドラインは、規律に従った運用の状況を確認するため、利用状況等を記録することも重要であると記載しています。誰がいつどの顧客の記録を見たかを仕組み側で残せるかどうかが、発注前に確認する項目になります。

### 紙の台帳のままなら不要というわけではありません

安全管理措置は、紙で管理している場合にも適用されます。4区分のうち物理的安全管理措置は、紙の書類の保管や持ち出しの管理を含みます。

仕組みに移すことで変わるのは、求められる内容が技術的な設計の側に広がる点です。紙の台帳では「鍵のかかる引き出しに入れる」で済んでいた管理が、「誰がどの画面を見られるか」という設定の話になります。

事業者の規模による扱いの違いもあります。同ガイドラインは中小規模事業者を従業員の数が100人以下の個人情報取扱事業者と定義し、保有する個人情報の数が過去6月以内のいずれかの日において5,000を超える者と、委託を受けて個人データを取り扱う者を除いています。

そのうえで、中小規模事業者についても法第23条に定める安全管理措置を講じなければならないとし、別に「中小規模事業者における手法の例示」を示しています。義務そのものが軽くなるのではなく、実施しやすい手法が例示される位置づけです。

### 発注要件に落とすときの対応

発注書に書く形にすると、次の3点になります。

1. 画面を見られる人の範囲を、役職または店舗の単位で設定できること（技術的安全管理措置のアクセス制御に対応）
2. 誰がいつどの顧客の記録を開いたかの記録が残ること（組織的安全管理措置の取扱状況の確認に対応）
3. 退職した従業員のアカウントを止める手順が、既存の退職手続きに組み込めること（アクセス者の識別と認証に対応）

つまずきやすい点は、1を「管理者と一般」の2段階だけで作ってしまうことです。店舗が複数ある御社では、他店の顧客の記録まで見えてしまいます。発注の段階で、店舗単位の区切りが必要かを決めてください。要件の詳細な決め方は、小売業の来店予約と顧客記録の外注要件を扱った記事で別に整理しています。

## 中小の小売業にとっての示唆

紙の台帳を一度に全部やめる必要はありません。来店予約の受付だけを先に仕組みに移し、顧客の記録は紙のまま残す進め方が現実的です。

小売業の39.0%という値は、全部を一度に変えようとして止まっている御社が多いことの裏返しだとも読めます（出典: 東京商工会議所『中小企業のデジタルシフト・DX実態調査』（2026年））。

### 先に移す業務の選び方

判断の基準は2つです。店の外にいる人が関わるか、そして個人情報の扱いが増えないかです。

1. 来店予約の受付: 先に移す価値が高い業務です。店の外にいるお客様が関わるため、電話がつながらない時間帯の取りこぼしがそのまま売上に効きます（所要時間の目安: 要件を決めるのに半日）
2. 問い合わせの受付: 同じ理由で優先度が高くなります。予約と同じ画面で受けられる構成にすると、作る範囲が広がりません
3. 顧客の記録（購入履歴、好み、対応の経緯）: 後に回します。個人情報の扱いが増え、前のセクションで挙げた措置が本格的に関わるためです
4. 在庫と発注: 業務の流れ全体に関わるため、予約が回り始めてから検討します

3を最初に手がける御社が多いのですが、作る範囲が広く、義務も増えます。1から始めて、紙の台帳はそのまま残すほうが、止まりません。

つまずきやすい点は、予約の仕組みを入れたのに電話の受付をやめないことです。両方を受けると、どちらにも反映されていない予約が生まれます。予約を仕組みで受けると決めた時点で、電話で受けた分を誰がいつ入力するかを決めてください。

### 当社のサービスとの接続

当社は、Web制作と業務システムの開発を手がけています。小売業の案件では、来店予約の受付から始めて、顧客の記録は紙を残す構成を提案することが多くあります。

理由は、作る範囲が小さいほど早く動き始められるためです。予約の受付だけであれば、既存のホームページに画面を1つ足す形で済む場合があります。顧客の記録まで含めると、権限の設計と記録の保存が加わり、決めることが増えます。

一方で、予約と顧客の記録を最初からつなぐ構成が合う御社もあります。常連のお客様が売上の大半を占める業態では、予約の時点で過去の対応の経緯が見えることに価値があるためです。どちらが合うかは、売上の構成で変わります。

自社がどちらかの判断が付かない場合は、[無料診断](/diagnostic)で現在の受付の流れを整理します。先に移す業務を1つ決めるところまでが、最初の目標です。

## よくあるご質問

この数字と、顧客記録の仕組み化について多い質問をまとめます。

### 39.0%は多いのですか少ないのですか

業種別では最も高い値です。同じ調査の全体は24.3%で、製造業は19.6%です（出典: 東京商工会議所『中小企業のデジタルシフト・DX実態調査』（2026年））。

多いか少ないかは、何と比べるかで変わります。小売業どうしで比べれば4割弱は少数派ですが、業種を横に並べれば小売業が最も遅れた位置にあります。社内で使うときは、両方の見方を並べてください。

### 他の業種はどうなっていますか

同じ調査では、卸売業33.3%、建設業28.2%、サービス業26.7%、製造業19.6%です。全体は24.3%です。

小売業と製造業の差は19.4ポイントです。取引先が製造業である小売業の御社では、相手のほうが仕組みを前提に動いている可能性が高いという読み方ができます。

### 紙の台帳を残したままでも予約だけ仕組みにできますか

できます。予約の受付と顧客の記録は、別の業務として切り離せます。

実務では、予約の画面で受けた内容を印刷して台帳に挟む運用から始める御社もあります。この形であれば、顧客の記録を仕組み側に持たないため、前述の安全管理措置の範囲も限定されます。ただし予約の内容自体に氏名と連絡先が含まれるため、措置がまったく不要になるわけではありません。

### 個人情報の安全管理措置は小さな店でも必要ですか

必要です。個人情報保護委員会のガイドラインは、従業員の数が100人以下の中小規模事業者についても、法第23条に定める安全管理措置を講じなければならないとしています。

中小規模事業者には別に「中小規模事業者における手法の例示」が示されていますが、これは実施しやすい手法が例示される位置づけで、義務そのものが軽くなるわけではありません。

### この数字は補助金の申請に使えますか

申請書の背景の説明に使うことはできます。ただし、この調査は主に東京23区内の中小企業を対象としており、全国の数値ではありません。

自社が東京23区外にある場合は、出典とともに対象の範囲を明記してください。数値の前提を書かずに引用すると、審査の場で根拠の確かさを問われることになります。補助金の対象経費や申請の要件そのものについては、[補助金を使ったホームページ制作の解説](/subsidy)で別に整理しています。
