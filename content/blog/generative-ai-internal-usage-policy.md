# 中小企業の生成AI利用ルール｜1日で作る7項目

## 生成AIの社内ルールは何から決める？

入力してよい情報の線引きから決めてください。使ってよいツールの選定より先に、情報の区分を決める方が手戻りが少なくなります。

社員がどのツールを使うかは、後から変わります。情報の区分は変わりません。

### ツールの選定を先にすると起きること

よくあるのは、製品を1つ決めて導入した後に、「この情報を入れてよいのか」という質問が現場から出てくる進め方です。

このとき、答える側に判断の基準がありません。結果として、質問のたびに個別に判断することになります。判断が人によって変わり、ルールとして機能しません。

順序を逆にすると、ツールが変わっても判断の基準は残ります。

### 最初の1枚に書く3項目

何を書くか迷う場合は、社内の懸念から考えると決まります。総務省の令和7年版情報通信白書は、生成AI導入にあたっての懸念事項を調査しています。

日本で最も多かったのは「効果的な活用方法がわからない」で30.1%でした。次に「社内情報の漏洩などのセキュリティリスクがある」が27.6%です（出典: 総務省「令和7年版情報通信白書」図表Ⅰ-1-2-15）。

コスト面の懸念も挙がっています。「ランニングコストが掛かる」が24.9%、「初期コストが掛かる」が22.1%です（出典: 同）。

上位2つは、ルールで答えられる内容です。最初の1枚には次の3項目を書いてください。

1. 使ってよいツールと、使ってよい業務の例（所要時間の目安: 1時間）
2. 入力してはいけない情報の区分（所要時間の目安: 2時間）
3. 判断に迷ったときの問い合わせ先（所要時間の目安: 10分）

1番目が「活用方法がわからない」への答えになり、2番目が漏えいへの懸念への答えになります。

3番目を省くと、現場は結局自分で判断します。担当者の名前を1つ書くだけで足ります。

情報の区分の決め方は、後述の見出しで扱います。

## どれくらいの企業がルールを作っている？

方針を定めている企業は、日本全体で約半数です。企業規模によって差があります。

数値は総務省の令和7年版情報通信白書が示しています。

### 規模別の方針策定率

生成AIを活用する方針を定めている企業の比率は、2024年度の調査で約50%でした。2023年度の調査では約43%でしたので、1年で増えています（出典: 総務省「令和7年版情報通信白書 (概要)」）。

大企業では約56%です（出典: 同）。全体の約50%という水準と比べると、規模が大きい企業の方が先に方針を整えている形になります。

| 区分 | 方針を定めている企業の比率 |
| --- | --- |
| 日本全体 (2023年度調査) | 約43% |
| 日本全体 (2024年度調査) | 約50% |
| 日本の大企業 | 約56% |

半数が定めていないという読み方もできます。御社がまだ作っていないとしても、遅れているわけではありません。

企業規模による活用率そのものの差は、別記事「中小企業の生成AI活用率｜大企業との差を統計で解説」で扱っています。

### 策定していない企業で起きていること

方針がない状態で問題になるのは、禁止していないことが許可と受け取られる点です。

社員は目の前の仕事を進めるために、使えるツールを使います。禁止の指示もなければ、個人のアカウントで業務の文章を処理することになります。

この状態は、会社として何が入力されたかを把握できません。後から確認しようとしても、個人のアカウントの履歴は会社が見られません。

ですから最初の1枚は、禁止事項を並べるためではなく、把握できる状態にするために作ります。使ってよいツールを決めて、そこに集めるという考え方です。

運用の具体は後述します。

## 入力してよい情報の線引きはどう決める？

自社の情報を3区分に分け、区分ごとに可否を決めます。個人情報と取引先の非公開情報は、原則として入力しない区分に置いてください。

項目を細かく列挙するより、区分で決める方が運用できます。新しい書類が出てきても、どの区分かを判断すれば済みます。

### 情報を3区分に分ける手順

1. すでに公開している情報を洗い出す（所要時間の目安: 30分）。自社サイトやカタログに載っている内容です。この区分は入力して構いません。
2. 社内だけで使っている情報を洗い出す（所要時間の目安: 1時間）。手順書、議事録、社内の数値です。使ってよいツールに限って入力を認める区分にします。
3. 他者の情報を洗い出す（所要時間の目安: 30分）。個人情報と、取引先から受け取った非公開の情報です。原則として入力しない区分にします。

3番目を最初に決めると、残りの線引きが楽になります。

### 個人情報保護委員会が注意喚起している点

個人情報保護委員会は、生成AIサービスの利用に関する注意喚起等を令和5年6月2日に公表しています（出典: 個人情報保護委員会「生成AIサービスの利用に関する注意喚起等について」）。

個人情報を取り扱う場面では、この注意喚起の内容を踏まえた判断が必要です。社内ルールに「個人情報は入力しない」と1行書く場合も、根拠としてこの公表資料を挙げておくと、社内の説明が通りやすくなります。

国の考え方の全体像は、総務省と経済産業省の「AI事業者ガイドライン」が示しています。第1.2版が令和8年3月31日に公表されています（出典: 総務省・経済産業省「AI事業者ガイドライン（第1.2版）」）。

### つまずきやすい点: 「社外秘」の定義が社内で揃っていない

区分を決める作業でつまずくのは、2番目の社内情報です。

実際に洗い出すと、「社外秘」と書かれた書類と、書かれていないが社外に出せない書類が混在しています。表示の有無で判断すると、表示のない書類が公開扱いになります。

ですから、表示ではなく置き場所で決めてください。共有フォルダのどこに置かれているかで区分すると、判断が揺れません。

新しい書類の扱いは、置き場所を決めた時点で自動的に決まります。

## データの保管場所は何を確認する？

入力したデータがどこに保存され、学習に使われるかを、利用するサービスの公式ドキュメントで確認します。提供元の紹介ページや営業資料だけでは足りません。

確認した内容は、社内ルールの「使ってよいツール」の根拠として残してください。

### 確認する4項目

1. 入力したデータが保存される国または地域（所要時間の目安: 30分）
2. 入力したデータが学習に使われるかどうか、使われない設定があるか（所要時間の目安: 30分）
3. 保存される期間と、削除を依頼できるか（所要時間の目安: 30分）
4. 管理者が利用状況を確認できる機能があるか（所要時間の目安: 30分）

4番目は見落としやすい項目です。誰がどのツールを使っているかを会社が把握できるかどうかは、ルールが守られているかの確認に直結します。

各項目の詳しい確認手順と、確認した内容の記録の仕方は、別記事「AIツール導入前のデータ保管場所の確認方法」で扱っています。本記事では、社内ルールの1項目としての位置づけに留めます。

なお、国の考え方の枠組みとしては、総務省と経済産業省の「AI事業者ガイドライン」第1.2版が参照できます。令和8年3月31日に公表されています（出典: 総務省・経済産業省「AI事業者ガイドライン（第1.2版）」）。

### 実装者としての注意点: 無料版と法人向けプランで扱いが変わる

ここで実務上つまずくのは、同じサービス名でもプランによって扱いが違う点です。

無料版と法人向けプランでは、入力したデータの取り扱いが別の条件になっていることがあります。無料版の規約を読んで判断し、現場が法人向けプランを使っていた、またはその逆という食い違いが起きます。

ですから確認するときは、サービス名ではなくプラン名で記録してください。社内ルールにも、プラン名まで書いておきます。

もう1つは、設定の既定値です。学習に使わない設定が用意されていても、既定では有効になっていないことがあります。契約した時点で設定を確認し、誰が確認したかを残してください。

プランを変更したときは、同じ4項目をもう一度確認する必要があります。

## ルールの文書には何を書く？7項目の雛形

目的、対象者、使ってよいツール、入力してよい情報、出力の扱い、問い合わせ先、見直しの時期の7項目で足ります。最初から詳細にする必要はありません。

分量はA4で1枚を目安にしてください。読まれない文書は、ないのと同じです。

### 7項目の書き方と記載例の考え方

| 項目 | 書く内容 | 分量の目安 |
| --- | --- | --- |
| 目的 | 禁止ではなく、安全に使えるようにするためだと書く | 2行 |
| 対象者 | 誰に適用するか。業務委託や派遣の方を含めるかを明示する | 1行 |
| 使ってよいツール | サービス名とプラン名まで書く | 3行 |
| 入力してよい情報 | 前述の3区分で書く。例を1つずつ添える | 5行 |
| 出力の扱い | そのまま社外に出さない、確認する人を決める | 3行 |
| 問い合わせ先 | 判断に迷ったときの担当者名 | 1行 |
| 見直しの時期 | 次に見直す月を具体的に書く | 1行 |

出力の扱いは、書き忘れやすい項目です。生成された文章をそのまま見積書やお客様への返信に使うと、誤りが外に出ます。

誰が確認するかを1行決めてください。確認者を決めない運用は、確認しない運用と同じ結果になります。

見直しの時期は、「適宜」と書かないでください。具体的な月を書くと、その時期に実際に見直す動機が生まれます。

### 1枚に収める理由

長い文書を作ると、2つの問題が起きます。

1つは、読まれないことです。現場は使う前に読みません。困ったときに探して読みます。そのとき、1枚なら見つかります。

もう1つは、更新されないことです。詳細に書くほど、サービスの変更に合わせた修正の手間が増えます。手間が増えると、古い内容のまま残ります。

ですから、1枚に収めて、判断の基準だけを書いてください。個別のツールの設定手順は、別の資料に分けます。

ルールの中身が決まったら、次は運用です。

## 決めた後はどう運用する？守られているかの確認

ルールを配るだけでは守られません。使ってよいツールを会社が契約して配る形にすると、個人判断での利用が自然に減ります。

禁止で止めるのではなく、使える場所を用意して集める考え方です。

### 運用で決める3点

1. 会社が契約したアカウントを配る（所要時間の目安: 1週間）。個人のアカウントでの業務利用をやめてもらう前提として、代わりを先に用意します。
2. 管理者が利用状況を確認する頻度を決める（所要時間の目安: 30分）。月1回で足ります。誰が使っているかだけを見ます。
3. 入力してよい情報の判断で迷った事例を記録する（つまずきやすい点: 記録する場所を決めないと、担当者の記憶だけに残ります）。

3番目は見直しのための材料になります。同じ質問が3回来たら、ルールの書き方が曖昧だという合図です。

記録は専用の仕組みを作らなくて構いません。共有のファイルに1行ずつ足すだけで足ります。

### 見直しの頻度の目安

半年に1回を目安にしてください。加えて、次の3つが起きたときは時期を待たずに見直します。

- 使ってよいツールのプランを変更したとき
- 新しいツールを使いたいという申し出があったとき
- 国のガイドラインが改訂されたとき

3番目については、AI事業者ガイドラインが版を重ねています。改訂のたびにルール全体を作り直す必要はありません。自社の判断の基準が、改訂された考え方と食い違っていないかを見るだけです。

見直しのときに確認するのは、次の2点に絞ってください。使ってよいツールのプラン名が実際と合っているか、入力してよい情報の区分が現場の判断と合っているかです。

この2点が合っていれば、文書はそのままで構いません。

社内の体制づくりが難しい場合の進め方は、次の見出しで扱います。

## 自社で作るのが難しい場合は？

情報の区分と文書化は社内でしかできませんが、ツールの選定と保管場所の確認は外部に任せられます。この2つは調べる作業であって、自社の判断を必要としません。

分担を決めてから着手すると、1日で形になります。

社内で決めることと、外部に任せられることを分けると次のようになります。

| 作業 | 担当 |
| --- | --- |
| 情報を3区分に分ける | 社内。何が社外に出せないかは社内しか判断できません |
| 使ってよいツールの候補を調べる | 外部に任せられます |
| データの保管場所の4項目を確認する | 外部に任せられます |
| 7項目の文書にまとめる | 社内。最終的な判断は会社が行います |
| アカウントの契約と配布 | 外部に任せられます |

社内で決めるのは、1番目と4番目だけです。この2つに集中できれば、半日から1日で終わります。

### ご相談をお受けしている範囲

ご相談で多いのは、「社員がすでに使っているが、何を禁止すべきか分からない」という状態です。原因は、禁止事項から考え始めている点にあります。情報の区分から入ると、禁止すべき対象は自然に決まります。

当社はDXコンサルと機械学習開発を500,000円から承っており、代表自身がAIの実装を担当しています。そのため、ツールの一般的な比較ではなく、入力したデータがどう扱われるかという技術側の観点から選定をお手伝いできます。

社内ルールの雛形が必要な段階でも構いません。[無料診断](/diagnostic)では、御社の情報の区分と、使ってよいツールの候補を整理いたします。

AI活用の進め方を先に把握したい場合は、[DXガイドブック](/guidebook)をご覧ください。生成AIの導入手順と、社内で決めておく事項をまとめています。

## よくあるご質問

この記事に関して多い質問と回答をまとめます。作成の順に並べました。

### 生成AIの社内ルールは、どれくらいの分量で作ればよいですか？

A4で1枚を目安にしてください。目的、対象者、使ってよいツール、入力してよい情報、出力の扱い、問い合わせ先、見直しの時期の7項目が入れば足ります。

長い文書は読まれず、更新もされません。個別のツールの設定手順は、別の資料に分けてください。

### 社員が個人のアカウントで生成AIを使っている場合、どうすればよいですか？

禁止を先に出すより、会社が契約したアカウントを配る方が確実です。代わりがない状態で禁止すると、申告されないまま利用が続きます。

個人のアカウントでは、会社が履歴を確認できません。把握できる場所に集めることが、運用の出発点になります。

### お客様の名前や取引先の情報を生成AIに入力してよいですか？

原則として入力しない区分に置いてください。個人情報保護委員会は、生成AIサービスの利用に関する注意喚起等を令和5年6月2日に公表しています（出典: 個人情報保護委員会「生成AIサービスの利用に関する注意喚起等について」）。

個別の取り扱いについては、この公表資料の内容と、利用するサービスの条件の両方を確認してください。判断に迷う場合は、専門家にご相談ください。

### 無料版と法人向けプランで、入力したデータの扱いは変わりますか？

変わる場合があります。同じサービス名でも、プランによって条件が別になっていることがあります。

ですから社内ルールには、サービス名ではなくプラン名まで書いてください。学習に使わない設定が既定で有効になっていないこともありますので、契約時に設定を確認してください。

### ルールはどのくらいの頻度で見直せばよいですか？

半年に1回を目安にしてください。加えて、使ってよいツールのプランを変更したとき、新しいツールの申し出があったとき、国のガイドラインが改訂されたときは時期を待たずに見直します。

見直しで確認するのは、プラン名が実際と合っているか、情報の区分が現場の判断と合っているかの2点です。
