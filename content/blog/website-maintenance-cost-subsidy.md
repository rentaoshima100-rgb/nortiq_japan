# ホームページの保守費は補助金の対象か

## 毎年の保守費とサーバ費は、原則として補助の対象外です

公開後に毎年かかる保守費とサーバ費は、原則として補助の対象になりません。補助の対象は、補助事業の期間内に行う制作や改修の費用です。ただし例外があります。クラウドの利用料については、補助金の枠によって一定の年数分まで対象になります。

中小企業デジタル化・AI導入支援事業の「デジタル化・AI導入補助金2026」(旧IT導入補助金) の通常枠では、補助対象経費がソフトウェア購入費、クラウド利用費、導入関連費と定められています。クラウド利用費として補助に乗るのは最大2年分までです (デジタル化・AI導入補助金2026 公募要領 通常枠)。つまり、年額で払い続ける利用料のうち3年目以降は自社の負担として見込む必要があります。枠によって扱いは異なり、複数者連携枠の消費動向等分析経費ではクラウド利用料が1年分に限られます。以下の金額と要件は本記事の基準日時点のものです。最新は公式サイトで確認してください。

### 対象になる費用と対象外になる費用の線

線引きは、補助事業の期間内に行う作業かどうかで考えます。

| 費用 | 扱い |
|---|---|
| 制作と改修の作業費 | 補助事業の期間内であれば対象になり得ます |
| クラウドの利用料 | 枠により最大2年分まで対象になり得ます |
| 期間の終了後に毎月払う保守費 | 対象外です |
| 期間の終了後に発生する軽微な修正 | 対象外です |

### 公募要領で確認する箇所

公募要領は全体を読む必要はありません。次の3か所を見ます。

1. 補助対象経費の費目の一覧を見ます。自社が払う費用がどの費目に入るかを当てます。所要時間の目安は30分です。
2. 費目ごとの条件を見ます。つまずきやすい点は、費目に名前があっても年数や上限の条件が付く場合です。クラウド利用費はその例にあたります。
3. 補助事業の期間の定義を見ます。期間の外で行った作業は対象になりません。

中小企業庁が公表した事業概要では、通常枠の補助額は350万円以下、中小企業・小規模事業者等が申請する場合の補助率は2/3以内と整理されています (中小企業庁「中小企業デジタル化・AI導入支援事業 デジタル化・AI導入補助金2026の概要」令和8年4月)。これも基準日時点の内容です。最新は公式サイトで確認してください。

## 補助の対象になる範囲は、公募要領の費目で決まります

対象かどうかは費目で決まります。ウェブサイト関連費には上限があり、その費目だけでの申請はできません。費目の名前と自社の払う費用が一致するかを、公募要領の文言で突き合わせます。

### ウェブサイト関連費の上限と単独申請の禁止

小規模事業者持続化補助金 (一般型 通常枠) 第20回公募の公募要領 (第7版、2026年5月27日) は、ホームページやECサイト、システムの開発、構築、更新、改修、運用に要する経費を「ウェブサイト関連費」と定めています。この経費の補助金交付申請額の上限は30万円 (税込) です。

あわせて「ウェブサイト関連費のみによる申請はできません。必ず、ほかの経費と一緒に申請してください」と記載されています。ホームページ制作費だけを並べた申請はできません。なお、補助金交付申請額の4分の1かつ最大50万円と説明している解説も見られますが、第20回公募の公募要領の記載は30万円 (税込) です。

補助金全体の枠は次のとおりです。以下は本記事の基準日時点の内容です。最新は公式サイトで確認してください。

| 項目 | 内容 |
|---|---|
| 補助率 | 3分の2 (賃金引上げ特例のうち赤字事業者は4分の3) |
| 補助上限 | 50万円 |
| インボイス特例 | 要件を満たす場合は50万円を上乗せ |
| 賃金引上げ特例 | 要件を満たす場合は150万円を上乗せ |
| ウェブサイト関連費の上限 | 30万円 (税込) |

### 制作の費用に含められるものと含められないもの

費目の区分も公募要領で決まっています。補助対象経費は機械装置等費、広報費、ウェブサイト関連費、展示会等出展費、旅費、新商品開発費、借料、委託・外注費の8区分です。ウェブサイトやシステム開発等に関連するソフトウェアは機械装置等費ではなくウェブサイト関連費に計上します。自社ホームページやECサイトで使用する動画や写真の制作費用等も、広報費ではなくウェブサイト関連費に計上するよう指示されています。

対象となる経費例と対象とならない経費例は、同じ公募要領に並んでいます。

| 対象となる経費例 | 対象とならない経費例 |
|---|---|
| 商品販売のための自社ウェブサイトの作成や更新 | ウェブサイトおよびシステムに関連するコンサルティングやアドバイス費用 |
| 効果や作業内容が明確なウェブサイトのSEO対策 | 補助事業期間内に運用に至らなかったホームページやランディングページ |
| 顧客管理システムの構築、アプリケーション開発 | 既に導入しているソフトウェアの更新料、家庭および一般事務用ソフトウェア |

つまずきやすい点は、右側の「既に導入しているソフトウェアの更新料」です。毎年払う保守費のうち、既存のソフトウェアの更新に相当する部分は、この記載に当たる可能性があります。自社の見積書で保守費が何の対価になっているかを確認します。

## サーバの契約料は、期間の切り方で扱いが変わります

サーバやドメインの費用は、補助事業の期間に対応する分だけが対象になるかどうかを確認します。年額の一括払いは、期間の対応を示せるかが分かれ目です。クラウドの利用料として扱える場合も、年数の上限が付きます。

デジタル化・AI導入補助金2026の通常枠では、クラウド利用費として補助に乗るのは最大2年分までです (デジタル化・AI導入補助金2026 公募要領 通常枠)。複数者連携枠の消費動向等分析経費では1年分に限られます。これは本記事の基準日時点の内容です。最新は公式サイトで確認してください。

### 期間の対応を示す書類

示すものは見積書と請求書です。小規模事業者持続化補助金 (一般型 通常枠) 第20回公募の公募要領 (第7版、2026年5月27日) によると、採択発表後から交付決定までに、経費の価格の妥当性を証明できる見積書等 (相見積を含む) の提出が必要です。支出内容が不明確なものは認められないと記載されています。見積金額に複数の項目が含まれる場合は、内訳を示すことも求められます。

準備する順番は次のとおりです。

1. 契約の期間を書面で確認します。開始日と終了日が入っているかを見ます。所要時間の目安は15分です。
2. 見積書に期間を書いてもらいます。つまずきやすい点は「サーバ費用 一式」とだけ書かれた見積書です。期間と月額が分からないと、対応する分を示せません。
3. 補助事業の期間と重なる範囲を計算します。重ならない月の費用は自社の負担として分けます。
4. 請求書の記載を見積書と揃えます。期間の表記が違うと、確認に時間がかかります。

### 複数年の契約を結ぶ場合の注意

複数年の契約は、割安になる代わりに期間の対応が複雑になります。判断の材料は次の3つです。

| 論点 | 確認する内容 |
|---|---|
| 年数の上限 | 申請する枠がクラウド利用費を何年分まで認めるか |
| 期間の対応 | 補助事業の期間に重なる月を分けて示せるか |
| 支払の時期 | 一括払いの時期が補助事業の期間内に入るか |

もう1つ、公開後の制約も関わります。同じ公募要領によると、ウェブサイトおよびシステムを50万円 (税抜き) 以上の費用で作成、更新した場合、そのウェブサイトおよびシステムは処分制限財産に該当します。補助事業が終了して補助金の支払を受けた後も、通常は取得日から5年間、補助事業目的外での使用や譲渡、担保提供、廃棄等が制限されることがあるとされています。ただし、補助金の交付を受けた補助事業の目的を遂行するために必要なホームページの改良や機能強化は、事前承認申請等が必要となる処分には該当しないと明記されています。

## 公開後も費用が発生し続ける理由を、予算に織り込みます

公開後も、脆弱性の修正と表示性能の計測は続きます。これらは補助の対象外として、自社の毎年の予算に入れておきます。補助金で制作費を抑えられても、翌年からの費用は変わりません。

### 公開後に見つかる脆弱性の実態

公開したら完成ではありません。IPAの「ソフトウェア等の脆弱性関連情報に関する届出状況」によると、2026年第2四半期 (4月から6月) にウェブアプリケーション (ウェブサイト) について届出があったのは65件でした。ソフトウェア製品の182件と合わせて247件です。届出受付開始からの累計は20,315件で、そのうちウェブサイトに関するものが13,599件を占めています。直前の2026年第1四半期のウェブサイトの届出は69件でした (IPA「ソフトウェア等の脆弱性関連情報に関する届出状況 2026年第2四半期」)。

これらの数値は、届出があったものの件数です。自社のサイトで何件起きるかを示すものではありません。ただし、公開後に修正の作業が発生し続けるという前提を置く根拠にはなります。

### 表示性能の計測を続ける必要

表示性能にも、公開後に満たし続けることが前提の基準があります。Googleが示すCore Web Vitalsで良好とされる水準は次のとおりです。

| 指標 | 良好とされる水準 |
|---|---|
| Largest Contentful Paint (LCP) | 2.5秒以内 |
| Interaction to Next Paint (INP) | 200ミリ秒以下 |
| Cumulative Layout Shift (CLS) | 0.1以下 |

判定はページ読み込みの75パーセンタイルで行い、モバイルとデスクトップを分けて測ります (web.dev「Web Vitals」)。写真や機能を足していくと値は悪くなる方向に動きます。したがって、計測と改修の手間が公開後の作業として残ります。

予算への織り込みは次の順で行います。

1. 補助の対象になる費用と、翌年以降の費用を分けて書き出します。所要時間の目安は1時間です。
2. 翌年以降の費用に、脆弱性の修正と表示性能の改修の枠を入れます。つまずきやすい点は、保守契約の月額にこれらが含まれているかが曖昧な場合です。契約書の作業範囲を確認します。
3. 3年分を並べて見ます。クラウド利用費が補助の対象になる年数を超えたあとの負担が見えます。

## 申請の流れと、保守費を見積書でどう分けるか

申請では、対象になる費用と対象外の費用を見積書の段階で分けておきます。分けていないと、対象外の費用が混ざった見積書として扱われます。制作会社に見積もりを頼む前に、分け方を伝えておくほうが早く済みます。

### 申請までの手順

小規模事業者持続化補助金 (一般型 通常枠) 第20回公募の公募要領 (第7版、2026年5月27日) によると、第20回公募の日程は次のとおりです。以下は本記事の基準日時点の内容です。公募要領には予定は変更する場合があるとの付記があるため、申請前に公式サイトで最新版を確認してください。

| 項目 | 日程 |
|---|---|
| 申請受付開始 | 2026年11月5日 |
| 事業支援計画書 (様式4) 発行の受付締切 | 2026年12月4日 |
| 申請受付締切 | 2026年12月15日 17時00分 |

手順は次の順で進めます。

1. ＧビズＩＤプライムのアカウントを取得します。同公募要領によると、申請にはこのアカウントが必要です。つまずきやすい点は、取得までに日数がかかることです。日程の逆算に入れます。
2. 制作会社に見積もりを依頼します。このとき、補助の対象にする作業と対象外の保守を分けて記載するよう伝えます。所要時間の目安は依頼の説明に30分です。
3. 事業支援計画書の発行を商工会または商工会議所に依頼します。発行の受付締切は申請の締切より前に設定されています。
4. 申請します。採択発表後から交付決定までに、経費の価格の妥当性を証明できる見積書等 (相見積を含む) の提出が必要です。支出内容が不明確なものは認められないと記載されています。

### 見積書で分ける費目の書き方

分け方は、1枚の見積書の中で行を分けるだけで足ります。同公募要領は、見積金額に複数の項目が含まれる場合は内訳を示すことを求めています。

| 記載の例 | 扱い |
|---|---|
| サイト制作 一式 | 内訳が不明なため、確認に時間がかかります |
| サイト制作 (設計、デザイン、実装) | ウェブサイト関連費として申請できます |
| 保守費 (月額、公開後12か月分) | 対象外として自社の負担に分けます |
| サーバ利用料 (期間と月額を明記) | 期間の対応を示せる形になります |

### 当社の支援範囲

当社がお手伝いできるのは、見積書を費目ごとに分けて出すこと、補助事業の期間に合わせて作業の順番を組むこと、公開後の保守の範囲を契約で明確にすることです。申請書の作成代行や採択の保証は行いません。補助金の対象可否の最終的な判断は事務局が行うため、公募要領の読み合わせまでをご一緒する形になります。

## 対象外になりやすい費用の一覧

保守費、サーバ費、広告の運用代行費、既存サイトの軽微な更新は、対象外になりやすい費用です。対象外を先に把握しておくと、見積書を受け取ってから予算を組み直す手間が減ります。

### 一覧と、その理由

| 費用 | 対象外になりやすい理由 |
|---|---|
| 公開後に毎月払う保守費 | 補助事業の期間の外で発生する作業にあたります |
| 既存のソフトウェアの更新料 | 公募要領が対象とならない経費例に挙げています |
| コンサルティングやアドバイスの費用 | 同じく対象とならない経費例に挙げられています |
| 運用に至らなかったページ | 補助事業期間内に運用に至らなかったホームページやランディングページは対象外とされています |
| 家庭および一般事務用ソフトウェア | 同じく対象とならない経費例に挙げられています |
| サーバの年額のうち期間外の分 | 補助事業の期間に対応しない月の費用にあたります |

このうち、見積書で見落とされやすいのが月額の保守費です。ドメイン費用、サーバ費用、CMSライセンス、セキュリティ対応、コンテンツ更新などが含まれます。あきばれホームページおよびWeb幹事の公開情報によると、月額の管理・保守費用の相場は小規模サイトで月額5,000円から3万円前後、更新作業込みのフルサポートプランでは月額3万円から10万円程度とされています。これらは制作会社各社の公開データにもとづく目安で、本記事の基準日時点のものです。

金額の規模で言えば、初期の制作費も幅があります。Web幹事やNTTタウンページ デジタルリード等の複数の制作会社が公開する相場データによると、小規模なコーポレートサイト (5ページから10ページ程度) はフリーランスへの依頼で10万円から30万円前後、中小規模の制作会社への依頼で30万円から100万円前後が目安とされています。補助の対象になるのはこちら側の費用です。

### 判断に迷った場合の確認先

自社の費用がどちらに入るか判断できない場合の確認先は次のとおりです。

1. 公募要領の対象とならない経費例を読みます。自社の費用に近い記載があるかを探します。所要時間の目安は20分です。
2. 補助金の事務局に問い合わせます。つまずきやすい点は、制作会社の見解だけで判断してしまうことです。対象可否の判断は事務局が行います。
3. IT導入支援事業者に確認します。中小企業庁の公式資料によると、ホームページ制作単体が補助対象に該当するかどうかは申請するITツールの登録状況により異なるため、見積書を取得する前の確認が必要とされています。

## 補助金に頼らずに年額を抑える順番

年額を抑えるなら、保守の範囲を契約で絞ることから始めます。補助金の有無で毎年の費用は変わりません。対象外の費用を減らすほうが、効果が続きます。

### 保守契約で見直す項目

保守契約は、作業の範囲が書かれていないまま月額だけが決まっている場合があります。次の順で確認します。

1. 月額に含まれる作業を一覧にしてもらいます。更新の作業が何件まで含まれるかを数で確認します。所要時間の目安は依頼に15分です。
2. 含まれない作業の単価を聞きます。つまずきやすい点は、含まれない作業が発生するたびに見積もりを取り直す運用になっている場合です。年間で何回発生しているかを振り返ります。
3. サーバの契約を分けられるかを確認します。制作会社がまとめて契約している場合、自社で直接契約するほうが安くなることがあります。ただし、障害時の連絡先が自社に移ります。
4. 使っていない機能を外します。問い合わせフォームの多言語対応や、更新していない機能が月額に含まれている場合があります。

### 自社でできる作業に移す判断

作業を自社に移すかどうかは、頻度と危険度で分けます。

| 作業 | 自社に移す判断 |
|---|---|
| 文章や写真の差し替え | 頻度が高く危険度も低いため、移す候補になります |
| ページの追加 | 体裁が崩れやすいため、型が決まっているなら移せます |
| CMSやプラグインの更新 | 失敗するとサイトが止まるため、制作会社に残します |
| サーバやセキュリティの設定変更 | 同じく制作会社に残します |

移す場合は、操作の手順書と、戻し方を先に受け取ります。戻し方がないまま自社で触ると、復旧の費用が月額の節約分を超えます。

費用の見方としては、初期の制作費と年額を3年分で並べるのが実務的です。制作費が補助の対象になっても、年額は毎年そのままかかります。補助金を前提に初期の仕様を増やすと、翌年からの保守費も増える方向に動きます。仕様を決める段階で、年額への影響を制作会社に確認しておくことをおすすめします。

この記事に関して多い質問と回答をまとめます。以下の内容は本記事の基準日時点のものです。最新は公式サイトで確認してください。

### 毎月の保守費は補助金で見てもらえますか

補助事業の期間の外で発生する保守費は対象外です。小規模事業者持続化補助金 (一般型 通常枠) 第20回公募の公募要領 (第7版、2026年5月27日) は、対象とならない経費例として、既に導入しているソフトウェアの更新料や、ウェブサイトおよびシステムに関連するコンサルティングやアドバイス費用を挙げています。月額の保守費が何の対価になっているかを、見積書で確認してください。

### サーバの年額の契約料は補助金の対象になりますか

枠によっては対象になります。デジタル化・AI導入補助金2026の通常枠では、補助対象経費がソフトウェア購入費、クラウド利用費、導入関連費と定められており、クラウド利用費として補助に乗るのは最大2年分までです (デジタル化・AI導入補助金2026 公募要領 通常枠)。複数者連携枠の消費動向等分析経費では1年分に限られます。期間と月額が分かる見積書を用意してください。

### 公開後の軽微な修正も補助事業の経費に入れられますか

補助事業の期間内に行う改修であれば、費目に合えば入ります。期間の外で行う修正は対象外です。なお同公募要領は、ウェブサイトおよびシステムを50万円 (税抜き) 以上の費用で作成、更新した場合、そのウェブサイトおよびシステムが処分制限財産に該当するとしています。ただし、補助事業の目的を遂行するために必要なホームページの改良や機能強化は、事前承認申請等が必要となる処分には該当しないと明記されています。

### 保守費を初期費用に含めて見積書を作ってもよいのですか

分けて記載してください。同公募要領は、採択発表後から交付決定までに経費の価格の妥当性を証明できる見積書等の提出を求めており、支出内容が不明確なものは認められないとしています。見積金額に複数の項目が含まれる場合は内訳を示すことも求められます。保守費を制作費に混ぜると、内訳の確認に時間がかかります。

### 補助金の対象外になった費用は、あとから申請し直せますか

同じ補助事業の中で対象外とされた費用を後から対象にすることはできません。別の公募に申請する場合も、補助事業の期間と費目の条件を改めて満たす必要があります。対象可否の判断は事務局が行うため、申請の前に公募要領の対象とならない経費例を読み、判断が難しい部分は事務局に問い合わせてください。
