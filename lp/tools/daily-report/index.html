Daily Report / 登録不要

帰ってから書いていた日報を、現場でスマホから。

開始・終了の時刻と作業内容を入れるだけ。実働時間を自動で計算し、印刷できるA4の作業日報と、LINE・メールにそのまま貼れる文面が同時にできます。月末に足していけるCSVも出せます。

スマホで入力できる実働時間を自動で計算A4・文面・CSVの3つが残る入力した内容はサーバーに送りません
Step 1

いつ・だれが・どこで

氏名や現場名は日報に印字するためだけに使い、どこにも保存しません。空欄のままでも作れます。

Step 2

今日やった作業

作業ごとに開始・終了の時刻と内容を入れます。最大20行。時刻が分からない作業は、内容だけでも載せられます。

実働時間＝（最初の開始〜最後の終了）−休憩。昼休みを作業の行に書かなくても、二重には引きません。

Step 3

連絡・明日の予定

引き継ぐこと、気づいたこと、明日の段取り。箇条書きのままで構いません。

初期値はサンプルです。今日の内容に書き換えてください。

このツールについて

2026年11月4日・5日に求人票と公開されている投稿を調べたところ、「帰る前に日報」「日報を出してから帰る」「日報と出勤登録の修正をやってから」といった当事者の投稿が7件、求人票では2日間の255件のうち8件に「日報」の入力がありました。現場が終わってから事務所に戻って書く、家に帰ってから思い出して書く。その時間を、作業の合間にスマホで入れておくだけにするためのツールです。

出てくるもの

A4の作業日報：日付（曜日）・氏名・所属・現場・天気、作業ごとの時刻と時間数、休憩と実働時間、連絡・引き継ぎ事項、明日の予定、使った材料・経費、確認印の欄。そのまま印刷するか、印刷画面でPDFに保存できます。LINE・メールに貼る文面：同じ内容を、チャットで読みやすい箇条書きにしたもの。ボタン1つでコピーできます。CSV：「1日1行」と「作業の明細」の2種類。1日1行のCSVを月末につなげれば、そのまま月報の表になります。

使い方

1. 日付・氏名・現場を入れる　2. 作業ごとに開始・終了の時刻と内容を入れる（「＋ 作業を追加」で行を足す）　3. 休憩の分数、連絡事項、明日の予定を入れて「日報を作る」　4. 「文面をコピー」でLINEやメールに貼る。紙で出す会社は「日報を印刷・PDF保存」。入力した内容はこのページの中だけで処理し、サーバーには送りません。

時間の計算と休憩の目安（2026年11月時点）

実働時間は「最初の作業の開始から最後の作業の終了まで」から休憩を引いて出します。8時間を超えた分は時間数だけを表示します（残業代の計算や、週40時間・深夜・法定休日の区分は タイムカード集計・残業時間計算表 で行えます）。休憩については、労働基準法34条1項は、労働時間が6時間を超える場合は少なくとも45分、8時間を超える場合は少なくとも1時間の休憩を、労働時間の途中に与えなければならないと定めています。入力した休憩がこの目安より短いときは、結果に確認の一文を出します。実際の労働時間の取り扱いは、会社の就業規則と勤怠の記録に従ってください。

関連：タイムカード集計、予約表メーカー、注文集計・出荷指示書メーカー、請求書・見積書メーカー。日報を自動でためて現場別・人別に集計するところまで仕組みにしたいときは 業務システム開発 や ひと業務AI をご覧ください。

よくある質問

保存しません。氏名・現場名・作業内容はお使いのブラウザの中だけで処理し、サーバーには送りません。ページを閉じると消えるので、文面のコピー・印刷（PDF保存）・CSVのどれかで手元に残してください。

使えます。時刻は時計の選択で入り、作業の行は縦に並びます。「文面をコピー」を押してLINEやメールに貼り付ければ提出まで終わります。紙で出す場合は、スマホの印刷画面からPDFに保存して送るか、事務所のパソコンで印刷してください。

最初の作業の開始から最後の作業の終了までの時間から、休憩（分）を引いた時間です。昼休みを作業の行に書かなくても二重には引きません。終了が開始より前の時刻のときは翌日として計算します。8時間を超えた分は時間数だけを表示し、残業代の計算はしません。

現場ごとに提出するなら現場の数だけ作り、1枚にまとめるなら「現場・案件名」に主な現場を入れて、作業内容の頭に現場名を書いてください（例：「A邸：給湯器交換」）。明細のCSVは作業の行ごとに出るので、あとで現場別に集計できます。
