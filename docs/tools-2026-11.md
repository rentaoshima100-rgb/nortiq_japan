## 送信

すべて `/api/contact`（Resend）。kind は `tools-estimate` / `tools-ai-fit` / `tools-manual-cost` / `tools-ai-risk` / `tools-document-demo`、PDF希望は `-pdf` を付ける。結果のメモは message に、要点は extra[] に入る。**PDFは自動では作らない**：メールが来たら、本文のメモをPDF化して返信する運用（または本文を貼って返す）。

## 単価・係数の出典

- `estimate.js` の `CATS`：公開価格（Web 30/60/120万〜、AI活用 10/25/50万〜、PoC 50万〜、保守 月2万〜、チャット月額 API実費＋2万）。**AIセキュリティ（sec）の価格は仮置き**。
- `manual-cost.js`：時給初期値 1,300円（求人票の時給 1,150〜1,500円）、自動化率は業務別の標準値、導入費 1業務35万円、月額は 1.2万円＋2つ目以降1万円の目安。
- `ai-fit.js` の `USECASES`：効果・容易さ・1件の分数・月の標準件数・費用レンジ。業種一致で加点。

## 自社画像の読み取り（api/ocr-demo.js）

env `ANTHROPIC_API_KEY` が無いと 503 を返し、ページは「準備中」と表示してサンプルだけで動く。設定すれば `claude-sonnet-4-5`（`OCR_DEMO_MODEL` で変更可）で読み取る。画像は保存しない。クライアント側で1日3回（localStorage）。

## 評価（ユーザー評価）

結果画面ごとに評価ウィジェット（`NTOOLS.renderRating`、`renderCtas` が自動で CTA の上に置く）。「役に立った／物足りない」と★5段階、任意の200字コメント。`navigator.sendBeacon` で `/api/tool-rating` に送り、Supabase の `tool_ratings` に入る（`supabase/tools_schema.sql`。週次の集計ビュー `tool_ratings_weekly` も同じファイル）。コメントはAPI側でメール・電話・URLを落とす。IP・UA・Cookieは保存しない。

**初回だけ**：`supabase/tools_schema.sql` を Supabase（プロジェクト dhfzmtcexfajzgzdjfvm）の SQL Editor で1回流す。流すまでは API が 204 を返すだけで記録されない。

## 検査（push 前に必ず）

```
npm run tools:verify   # build → scripts/tools-check.js --dist → scripts/tools-e2e.js → scripts/tools-shots.js
```

- `scripts/tools-check.js`：セキュリティ（インラインイベント・外部ホスト・eval・esc無しのinnerHTML・APIのメソッド/上限/ログ/外部接続・キーの直書き・評価APIの許可リスト）、導線（ハブ・メガメニュー・フッター・/sitemap・台帳）、SEO（title/description の長さ・canonical・h1・robots・OG・alt・JSON-LD の WebPage/BreadcrumbList/SoftwareApplication/FAQPage・内部リンク・本文量）。不備があれば exit 1。
- `scripts/tools-e2e.js`：dist/ を配信して各ツールの結果画面まで操作し、1280/1100/768/390px でコンソールエラー0・横スクロール無し・画面幅をはみ出す要素が無い（本体トップのヘッダー含む）・評価が /api/tool-rating に届く・相談フォーム送信で「受け付け」表示を確かめる。新しいツールは `FLOWS` に操作を足す。
- `scripts/tools-shots.js`：390/768/1280px で各ツールの入力前・結果画面、/tools、本体トップ（ヘッダー・ドロワー）を画像にして `.tools-shots/`（git 管理外）に出す。数値では拾えない「詰まり・重なり・切れ・読みにくさ」は、この画像を**全部開いて目で**確かめる。確認せずに push しない。
