# CV改善 2026-11（Clarity のヒートマップから）

2026-11-10。Clarity（2026-11-10 時点の過去14日）のヒートマップと録画のイベント記録をもとにした修正の記録。
件数が少ない（トップPC 87表示、料金PC 18表示）ので、数字は傾向として読む。

## 1. 直した不具合

### 資料請求モーダルが送信できなかった（app.jsx）

- **症状:** トップの「無料で資料請求する」、各ページ冒頭の「資料請求はこちら」、題つきの赤い帯の「資料請求はこちら」から開いたモーダルは、全項目を入れても「送信に失敗しました」になり、`/api/contact` が呼ばれなかった。
- **原因:** これらのボタンは `onClick={onContact}` で `handleContact` を呼ぶ。第1引数にクリックイベントが入り、それを「相談の種別」として保持して `categories` に入れていた。送信データを作る `JSON.stringify` が循環参照で失敗する。
- **送れていた入口:** ヘッダー、フッター、スマホ下部ナビ、追従バー、バナー、サービスページ（`() => onContact('web')` の形で呼ぶ）、トップ下部のフォーム。
- **修正:** `handleContact` と `ContactModal` が文字列以外を種別として受け取らない。
- **いつからかは未確認。**

### 紹介パートナー募集フォーム（assets/lp/common/lp.js。全LP共通）

11/9 の録画（スマホ）で、送信ボタンが3回押され、「個人情報の取扱い」を開いて戻ったあと全項目を入れ直していた。

- エラー文に未入力の項目名を出す（例「未入力の項目があります（施工できるエリア、個人情報の取り扱いへの同意）」）。
- 未入力の項目まで移動する。チェックボックスは `focus()` だけでは画面が動かない端末がある。
- 直した項目はエラー文から消える。全部直ればエラー文も消える。
- エラー文を押すと未入力の項目へ移動する。
- 同意のチェックにも赤い枠を出す（以前は文字が赤くなるだけ）。
- 入力をタブの `sessionStorage` に控え、ページが読み直されても元に戻す。`<form data-persist>` のLPだけ（`/partner/energy`、`/service/kanri-dantai`、`/service/recruit-site`）。hidden とハニーポットは控えない。送信が届いたら消す。

ページが読み直された原因（アプリ内ブラウザか、タブの破棄か）は特定していない。どちらでも入力は残る。

## 2. 資料請求フォームの軽量化（components.jsx）

Clarity: PCトップの資料請求ボタンは4回押されて送信0件（上の不具合の影響も含む）。

| | 以前 | 今 |

| 任意 | 相談内容ほか | ご相談内容（1欄）。担当者名・電話・カテゴリーなどは「詳しく伝える」に畳む |
