# 実績ページの刷新（2026-11）

対象: `/works`、`/works-<業種>`（7ページ）、`/works-lp-corp`、`/works-lp-recruit`、`/works-lp-ec`、`/works-video`

## なぜ直したか

GA4（2026/11/11〜11/24）で、実績系ページは合計54PV、1PVあたりの滞在は約9秒だった。
来ても冒頭で離脱しているので、最初の画面で次の3点が分かるようにした。

1. 自社と同じ業種の事例があること
2. 費用と期間の目安
3. 相談の条件（無料・返信の早さ・契約前のデザイン案）

発注者調査（PRIZMA 2026、THINkBAL 2026 ほか）では、事例が参考になる理由の上位は
「同じ課題を解決したプロセス」「業種・規模の近さ」、制作会社の決め手は「費用」と「制作実績」だった。
そのため、実績と料金を同じページに置き、件数より1件の深さを出す構成にしている。

## どこを直せばよいか

- 文言・データ: `content-data.jsx` の `WORKS_HERO` / `WORKS_WORRIES` / `WORKS_CASES` / `WORKS_FEATURED` / `worksFlowSteps` / `worksIndexFaqs`
- 部品: 同ファイルの `WorksFacts` `WorksWorries` `WorksCaseFeature` `WorksFlow` `WorksPrice` `WorksEntry` `WorksCta`
- ページ: `info-pages.jsx` の `WorksPage`、`detail-pages.jsx` の `WorksVariantPage`
- 見た目: `styles.css` 末尾の「実績ページ」ブロック（`.wk-*`）
- 金額・期間は `NORTIQ_PRICING` から作っている。ここに数字を直書きしない
