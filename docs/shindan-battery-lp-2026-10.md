## 2. 診断の仕組み（shindan.js）

計算はブラウザの中だけで行い、サーバーには送らない（「結果まで連絡先なし」の約束どおり）。

| 入力 | 使い方 |
|---|---|
| Q1 お住まいの地域（必須） | 補助金の文言（京都府だけ府の補助金を案内）、紹介先のエリア |
| Q2 太陽光の状況（必須） | 結果の冒頭のひとこと（卒FIT済み／買取期間中／なし）、京都府の「同時導入」条件 |
| Q3 蓄電池の容量（必須） | 相場レンジと国の補助金の計算 |
| 手元の見積もり（任意、万円・税込） | 相場との差、国の補助金の対象判定（目標価格） |
| 月の電気代（任意） | 結果のラベルに表示するだけ（計算には未使用） |

### 数字（本文 S3・S7 と同じ。変えたら shindan.js・本文・説明図をそろえる）

| 項目 | 値 | 出典 |
|---|---|---|
| 相場 | 1kWh あたり 15〜22万円（工事費込み）。5kWh 80〜110万円、7kWh 110〜150万円（5と10の間）、10kWh 150〜200万円 | EcoFlow「蓄電池の価格相場」2025-11-24 |
| 国（DR補助金、令和7年度補正） | 3.45万円/kWh、設備費＋工事費の 3/10 以内、上限 60万円。**設備費＋工事費が目標価格 12.5万円/kWh（税抜）以下が条件** | 補助金ポータル 2026-04-20 |
| 京都府（令和8年度） | 蓄電池 1万円/kWh（上限 5万円）。太陽光と同時導入のみ。市町村経由 | 京都府 2026-07-01 |

### 判定

- 見積もりとの差: 上限超え（赤いカード）／範囲内／下限未満（安い理由の確認を促す）／見積もりなし／容量が分からない。
- 国の補助金: 容量が分かれば `min(3.45×kWh, 60)` を「最大◯万円程度（計算例）」。見積もりがあるときは `見積もり÷1.1÷kWh ≤ 12.5` で対象を判定し、超えていれば「対象外の見込み（対象の価格で出し直せるか施工店に相談を）」と出す。
  納品のサンプル表示（125万円／5kWh → 最大17万円）は目標価格を超えているので、実装では「対象外の見込み」になる（本文 S7 にはこの条件を書いていない。公開前に S7 への追記を検討）。
- 京都府: 京都で太陽光なし（新設も検討）のときだけ「同時導入なら最大5万円」。京都で太陽光ありなら「後付けだけでは対象外の見込み」。他府県は「施工店が確認・代行」。

GA4: `shindan_result`（area / solar / capacity / has_quote / verdict）、`shindan_again`、`shindan_lead_open`（refer / mail）、CTA は `shindan_cta`（header / fv / result-sample / subsidy / band / spbar）、`shindan_flow`、`shindan_mail`。送達で `generate_lead`（form_kind=shindan-battery）。

## 3. 紹介希望・結果メールのフォーム（#contact-form）

結果画面の「施工店からの連絡を希望する」「結果をメールで受け取る」で開く。ご希望（radio）・お名前・メール（必須）、電話・市区町村・伝えておきたいこと（任意）、同意（必須。施工店1社への提供を明記）。
診断の回答と結果は hidden（`data-label` 付き）に写し、lp.js が「ラベル: 値」の `extra[]` にしてメールの表に出す。

| メールの行 | 中身 |
|---|---|
| ご希望 | 施工店からの連絡を希望する ／ 診断結果をメールで受け取るだけ |
| お住まいの地域／太陽光パネル／蓄電池の容量／手元の見積もり／月の電気代 | 診断の回答 |
| 診断結果（相場）／（見積もり）／（補助金） | 結果の見出し3つ |
| 市区町村 | 任意入力 |

「結果をメールで受け取る」は自動返信ではない（api/contact.js はオーナー宛に送るだけ）。**担当が営業日24時間以内に結果をメールで返す運用**。画面の文言もそう書いてある。
